Use **Cloud > Posture** to read the latest stored security posture for Microsoft 365 and Google Workspace. This page is for MSP staff and company users. The scores come from the last sync. They are not a live security audit.

## Before you start

- You need Cloud read access (the **Cloud** resource with **Read** access in the role editor).
- Microsoft 365 or Google Workspace must be connected for the company in **Settings > Integrations**.
- For Google Workspace, **Daily security posture** must be turned on under **Sync settings** for the Google Workspace connection. Google posture is calculated once a day.
- Company users see only their own company.

## Read one company's posture

<Steps>
  <Step title="Open Cloud > Posture">
    Click **Cloud** in the sidebar. The **Posture** tab opens first when you have Cloud read access.
  </Step>
  <Step title="Pick one company">
    Use the company selector in the top bar and choose a company. The page shows that company's posture directly. There is no company table.
  </Step>
  <Step title="Read the Google Workspace card">
    If the company uses Google Workspace, a card shows the company name, the snapshot date, the score, and the six calculated checks. See [Understand Google posture checks](/user-guides/cloud/google-posture-checks).
  </Step>
  <Step title="Read the Microsoft Secure Score">
    If the company uses Microsoft 365, the Microsoft Secure Score page appears below. Use the **Secure Score** and **Current Posture** buttons to switch views.
  </Step>
</Steps>

If the company has no stored posture, the page reads **No cloud posture snapshot has been recorded for this company yet.**

## Read the portfolio overview

<Steps>
  <Step title="Pick several companies">
    Use the company selector in the top bar. Choose **Global View** or **Assigned Companies**. The overview table appears.
  </Step>
  <Step title="Read the score">
    The **Secure score** column shows a percentage bar for each company and provider. Microsoft rows use Microsoft Secure Score. Google rows use the MSPortal calculation.
  </Step>
  <Step title="Open a row">
    Click a Microsoft 365 row, or its score bar, to open that company's Secure Score. Click a Google Workspace row to open its checks in a dialog.
  </Step>
  <Step title="Check the snapshot date">
    Read **Snapshot date** before you compare scores. To see when the data last synced, show **Last synced** with **Columns > Save Changes**.
  </Step>
</Steps>

The table shows the latest snapshot for each company and provider, 20 rows per page. A company that uses both providers has two rows.

| Column | What it shows |
| --- | --- |
| **Company** | The company. Hidden when one company is selected. |
| **Provider** | Microsoft 365 or Google Workspace. Shown only when both appear in the results. |
| **Secure score** | The score as a rounded percentage. |
| **MFA**, **Domains**, and **Devices** | Percentages from Current Posture. Shown only when your MSP has the CIPP integration and the page has values. Click a percentage to open that company's Current Posture. |
| **Snapshot date** | The date of the stored snapshot. |
| **Checks** | The number of calculated checks for Google Workspace, or **Microsoft controls** for Microsoft 365. |
| **Last synced** | Hidden by default. When the snapshot last synced. |

When Microsoft 365 is connected, buttons above the table switch views.

## Ask for help with a finding

<Steps>
  <Step title="Company users: open a ticket">
    [Open a ticket](/user-guides/ticketing/open-a-ticket) with the company, the provider, the snapshot date, the check or control, and your concern.
  </Step>
  <Step title="MSP staff: confirm in the provider">
    Check the evidence in Microsoft 365 or Google Workspace, then plan the change. The new score appears after the next daily sync.
  </Step>
</Steps>

This page cannot change security settings, run a sync, export a file, or show past days.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The **Posture** tab is missing | Your role does not have Cloud read access. |
| A company has no row | The company has no stored snapshot yet. For Google Workspace, ask MSP staff to turn on **Daily security posture** under **Sync settings** on the Google Workspace connection. |
| You see **No daily cloud posture snapshots match these filters.** | Click **Clear Filters** and check the company selector. |
| **Current Posture** is missing | It needs the CIPP integration. Ask your MSP. |
| **MFA**, **Domains**, and **Devices** are missing | They need the CIPP integration and values on the current page. A missing column is not a passing result. |
| The snapshot date is old | Google usage reports can be late and delay a new snapshot. Ask your MSP to check the integration. |
| You see **You do not have access to this Cloud data.** | Your role lacks Cloud read access. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why do I see details instead of a company table?">
    You selected exactly one company. With more than one company, the overview table appears.
  </Accordion>
  <Accordion title="Do Microsoft and Google use the same score?">
    No. Microsoft uses Microsoft Secure Score. Google uses an MSPortal calculation with six checks and 100 points. Do not compare the two percentages directly.
  </Accordion>
  <Accordion title="Where did the Score source column go?">
    The overview has one **Secure score** column. Use **Provider** to tell the source. The Google detail shows **MSPortal** as its score source.
  </Accordion>
  <Accordion title="Can I see past days?">
    No. The page shows the latest snapshot for each company and provider.
  </Accordion>
  <Accordion title="Does a new Snapshot date mean every input is current?">
    No. Google usage reports run about three days behind. Directory data is read at sync time.
  </Accordion>
  <Accordion title="Can I fix a setting from this page?">
    No. Ask your MSP.
  </Accordion>
</AccordionGroup>
