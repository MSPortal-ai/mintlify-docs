Use the **Client visible** switch and the **Hide all security groups** button on **Cloud > Groups** to hide groups from your clients. This page is for MSP staff. Company users should ask their MSP for visibility changes.

## Before you start

- You need Cloud write or manage access (the **Cloud** resource with **Write** or **Manage** in the role editor). Without it, the **Client visible** column and the **Hide all security groups** button do not appear.
- Hiding a group changes what clients see in MSPortal. It does not delete the group, remove members, or change access in Microsoft 365 or Google Workspace.
- MSP staff always see hidden groups, so your own view does not show what clients see.
- New groups start visible. Later syncs keep your visibility choices.

## Hide or show one group

<Steps>
  <Step title="Open Cloud > Groups">
    Click **Cloud** in the sidebar, then click the **Groups** tab. Check the company selector in the top bar.
  </Step>
  <Step title="Find the group">
    Use the filters under the column headings. Check the company, email, and type before you change anything.
  </Step>
  <Step title="Flip the Client visible switch">
    In the **Client visible** column, turn the switch off to mark the group **Hidden**. Turn it on to mark it **Visible**. The change saves right away. There is no Save button.
  </Step>
  <Step title="Check the result">
    The label next to the switch changes to **Hidden** or **Visible**. If you see **Could not update group visibility**, check the label, then try again.
  </Step>
</Steps>

If you do not see the **Client visible** column, click **Columns**, turn it on, and click **Save Changes**.

## Hide all security groups at once

<Steps>
  <Step title="Set the company scope">
    Use the company selector in the top bar to choose the companies to change. **Global View** applies to every company you can access.
  </Step>
  <Step title="Click Hide all security groups">
    Click **Hide all security groups** above the table. It runs right away with no confirmation.

    <Frame caption="The button uses the company selector in the top bar.">
      <img src="/images/product/cloud-groups-hide-security-control.png" alt="Hide all security groups button in Cloud Groups." width="354" height="64" />
    </Frame>
  </Step>
  <Step title="Check the result">
    A message tells you how many groups were hidden from clients. A count of 0 means every group in scope was already hidden.
  </Step>
</Steps>

<Warning>
This button hides every **Security** and **Mail-enabled security** group in the selected companies, on every page. Table filters, the page you are on, and the **Company** column filter do not narrow it. It does not hide Google groups, Microsoft 365 groups, or Distribution groups. There is no bulk undo. To bring a group back, turn on its own **Client visible** switch.
</Warning>

## How visibility affects ticket forms

The Cloud Group field on ticket forms lists groups for the selected company. For company users it shows only groups marked **Visible**. The field's own provider and group type settings narrow the list further, so a **Visible** group can still be missing from a form. A group hidden after someone picked it no longer shows its name to company users.

This is a presentation control. For real membership or access changes, use Microsoft 365 or Google Workspace.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The **Client visible** column is missing | Your role does not have Cloud write or manage access, or the column is hidden. Check **Columns**. |
| **Hide all security groups** is missing | Your role does not have Cloud write or manage access. |
| You see **Could not update group visibility** | Check the switch label for the real state, then try again. If it keeps failing, tell your administrator. |
| You can still see a group you hid | MSP staff always see hidden groups. |
| A **Visible** group is missing from a ticket form | Check the form field's provider and type settings, the selected company, and the last sync. |
| The bulk button hid more than expected | It uses the company selector, not the table filters. Turn **Client visible** back on for any group that should stay visible. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does hiding a group delete it or remove its members?">
    No. Only MSPortal client visibility changes.
  </Accordion>
  <Accordion title="Do I need to click Save after changing Client visible?">
    No. The switch saves immediately. **Save Changes** in the **Columns** panel only saves which columns you see.
  </Accordion>
  <Accordion title="Does Hide all security groups respect my table filters?">
    No. It uses the company selector in the top bar and covers every page.
  </Accordion>
  <Accordion title="How do I undo a bulk hide?">
    Turn on **Client visible** for each group that should be visible. There is no bulk undo.
  </Accordion>
  <Accordion title="Will the next sync undo my choices?">
    No. Syncs keep existing visibility settings. Newly imported groups start visible.
  </Accordion>
</AccordionGroup>
