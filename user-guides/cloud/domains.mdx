Use **Cloud > Domains** to see the domains synced from Microsoft 365, Google Workspace, and DNSimple (the registrar) for your companies. This page is for MSP staff and company users who need to check verification, primary domains, or expiry dates.

## Before you start

- You need Cloud read access. In the role editor this is the **Cloud** resource with **Read** access. It covers all three providers on this page.
- Company users see only their own company. MSP staff see the companies selected in the company selector.
- Each provider must be connected in **Settings > Integrations**, and each domain must be mapped to a company. DNSimple domains that are not mapped to a company do not appear.
- Domains are synced data. They are not a live registrar lookup.

## Open the domain list

<Steps>
  <Step title="Open Cloud > Domains">
    Click **Cloud** in the sidebar, then click the **Domains** tab.
  </Step>
  <Step title="Pick the company">
    Use the company selector in the top bar. MSP staff can pick one company, **Global View**, or **Assigned Companies** if their access is limited. With one company selected, the **Company** column is hidden.
  </Step>
  <Step title="Read the summary">
    The row above the table shows **Total domains**, **Verified**, **Primary domains**, **Secondary domains**, and **Companies**. With one company selected, **Primary domain** shows that company's primary domain name instead of a count.
  </Step>
  <Step title="Find a domain">
    Type in the filter box under the **Domain** column heading. If your scope has more than one provider, a **Provider** column appears. Open its filter to pick Microsoft 365, Google Workspace, or DNSimple.

    <Frame caption="The Provider filter lists only the providers that have domains in your current scope.">
      <img src="/images/product/cloud-domain-provider-options.png" alt="Cloud Domains Provider filter with DNSimple, Google Workspace, and Microsoft 365 options." width="480" height="344" />
    </Frame>
  </Step>
  <Step title="Page through the results">
    The table shows 50 domains per page. Use the page controls under the table to move between pages.
  </Step>
</Steps>

The same domain name can appear more than once. A Microsoft row describes the Microsoft 365 tenant, and a DNSimple row describes the registrar record. Compare **Provider** and **Company** before you treat two rows as duplicates.

Company users see DNSimple rows labeled **Managed by** followed by their MSP name.

## Show more columns

<Steps>
  <Step title="Open the column list">
    Click **Columns** above the table.
  </Step>
  <Step title="Turn on the columns you want">
    Check the columns to show. You can drag a column to change its order.
  </Step>
  <Step title="Save">
    Click **Save Changes**. Click **Cancel** to discard your changes.
  </Step>
</Steps>

## What each column shows

| Column | What it shows |
| --- | --- |
| **Domain** | The domain name. A **Primary** badge marks a cloud primary domain. A **Secondary** badge marks a DNSimple domain that is not in any synced Microsoft 365 or Google Workspace tenant. |
| **Provider** and **Company** | The source and the mapped company. **Provider** appears only when your scope has more than one provider. |
| **Verification** | **Verified** or **Unverified**. |
| **Services** | The services Microsoft reports for the domain. Google and DNSimple rows show a dash. |
| **Authentication** | The Microsoft authentication type, such as Managed or Federated. Other providers show a dash. |
| **Expires** | The DNSimple expiry date. Microsoft and Google rows show a dash. |
| **Primary** | Hidden by default. **Primary** or **Secondary** for the domain's role in its cloud tenant. |
| **Cloud presence** | Hidden by default. **In cloud tenant** or **Secondary domain**. |
| **Auto-renew** | Hidden by default. **On** or **Off** for DNSimple domains. |
| **Registrar status** | Hidden by default. The DNSimple state of the domain. |
| **Aliases** | Hidden by default. Google domain aliases. Microsoft and DNSimple rows show a dash. |
| **Created** | Hidden by default. When the domain was created or registered. |
| **Last synced** | Hidden by default. When MSPortal last refreshed the record. |

<Note>
DNSimple does not report a verification flag, so every DNSimple row shows **Unverified**. That label does not mean the domain failed verification. Check the matching Microsoft 365 or Google Workspace row for the real verification state.
</Note>

## Tell the two kinds of Secondary apart

- **Primary = Secondary** means the domain is not the primary domain in its cloud tenant. It is still a normal domain in Microsoft 365 or Google Workspace.
- **Cloud presence = Secondary domain** means a DNSimple domain has no matching name in any synced Microsoft 365 or Google Workspace tenant under your MSP. The same name also gets a **Secondary** badge next to it.
- **In cloud tenant** means the name was found in some Microsoft 365 or Google Workspace tenant under your MSP. It can be a different company's tenant.

## Summary counts and filters

The summary counts follow the company selector and the **Provider** filter. They do not follow the **Domain**, **Verification**, **Primary**, **Cloud presence**, or **Authentication** filters. The table can be empty while the summary still shows domains. The summary counts rows, not unique domain names.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The **Domains** tab is missing | Your role does not have Cloud read access. Ask your MSP to add it. |
| You see **No cloud domains match these filters.** | Clear the column filters and check the company selector. |
| A DNSimple domain is missing | The domain is not mapped to a company yet. MSP staff map it in **Settings > Integrations**. |
| A DNSimple domain shows **Secondary domain** but the domain is in use | The Microsoft 365 or Google Workspace tenant has not synced that domain yet. Check **Last synced** on the matching row, or ask your MSP to check the integration. |
| A recently verified domain still shows **Unverified** | The list shows the last sync. Check **Last synced**, then ask your MSP to confirm the connection is healthy. |
| You see **You do not have access to this Cloud data.** | Your role lacks Cloud read access. |
| You see **Cloud data is temporarily unavailable. Try again shortly.** | Reload the page after a minute. If it persists, tell your MSP. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I add, verify, renew, or delete a domain here?">
    No. This page is read only. Make domain changes in the provider, then wait for the next sync.
  </Accordion>
  <Accordion title="Why does the same domain appear twice?">
    Each provider and each company mapping creates its own row. Compare **Provider** and **Company**.
  </Accordion>
  <Accordion title="Does Unverified on a DNSimple row mean my email is broken?">
    No. DNSimple rows always show **Unverified** because DNSimple does not report that flag.
  </Accordion>
  <Accordion title="Why do the summary counts not change when I filter by Verification?">
    The summary follows only the company selector and the **Provider** filter.
  </Accordion>
  <Accordion title="Can I export the domain list?">
    Yes. See [Find and export domains](/user-guides/cloud/filter-domains).
  </Accordion>
  <Accordion title="I am a company user and a domain looks wrong. What do I do?">
    [Open a ticket](/user-guides/ticketing/open-a-ticket) with the domain name, the provider, and what looks wrong.
  </Accordion>
</AccordionGroup>
