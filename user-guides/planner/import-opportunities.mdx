Turn PSA opportunities that MSPortal has already synchronized into Planner items. This guide is for MSP staff. Company users do not import opportunities or set import mappings.

## Before you start

- You need **Manage Planner** and a connected **Halo**, **ConnectWise** or **Autotask** integration. **Import** does not appear without both.
- Opportunity sync must be on for the PSA connection, and each opportunity must be mapped to the right company. The dialog reads opportunities already synced into MSPortal. It does not upload a spreadsheet.
- Imported items are visible to company users by default. The dialog has no visibility switch, so import only work that is ready to share. A company user still needs company scope and Planner access to see an item.
- **Import** is separate from templates, Apply to Companies and **Relationships > Create**, which creates a new opportunity in the PSA.

## Import opportunities

<Steps>
  <Step title="Open Import">
    On any Planner page, set the company selector and click **Import** in the page header. The **Import opportunities** dialog opens.
  </Step>
  <Step title="Search">
    Type in **Search by summary or ID**.
  </Step>
  <Step title="Check the date range">
    **Due date range** starts with the past year through today. Widen it, or click its clear (X) button, to include older or future opportunities. The range filters on the opportunity's target date, or its deadline when there is no target date. It is not a creation date. Opportunities with neither date always stay in the list.
  </Step>
  <Step title="Review Hide already imported">
    It is ticked by default. Untick it to see opportunities you imported before. They show an **Imported** badge and cannot be selected again.
  </Step>
  <Step title="Select the opportunities">
    Check each row's company, provider, value and due date, then tick the ones you want. The count shows beside **Select all**. **Select all** ticks the eligible rows on the current page, up to 200.
  </Step>
  <Step title="Map the statuses">
    Under **Status mapping**, choose the Planner status for each opportunity category.

    | Opportunity category | Default Planner status |
    | --- | --- |
    | **Open** | Not Started |
    | **Won** | Completed |
    | **Lost** | Cancelled |

    Each list offers **Not Started**, **In Progress**, **Completed**, **On Hold**, **Cancelled** and **Pending Approval**. A row can show your PSA's own status name. The mapping works on the Open, Won and Lost category.

    <Frame caption="Planner status choices for an import mapping. The mapping sets the new Planner item's status. It does not change the PSA opportunity.">
      <img src="/images/product/planner-import-status-options.png" alt="Available Planner statuses in the opportunity import mapping." width="312" height="396" />
    </Frame>
  </Step>
  <Step title="Click Import N opportunities">
    Wait for the result. Messages report how many were imported and how many were skipped. Skipped rows may already be imported or may have no company mapped.
  </Step>
  <Step title="Verify the new items">
    Open **Planner Menu > List View** and check each new item's company, title, description, status, due date, cost and visibility. Open **Relationships** to see the linked opportunity.
  </Step>
</Steps>

These mapping choices apply to this import only. Closing the dialog resets them to the defaults. They are not the integration's ongoing status mappings.

**Next** and **Previous** move between pages of 200 opportunities. Changing page, search, dates, company selection or **Hide already imported** clears your ticks, so tick again after the new results load. Wait for the search to settle before you import.

**Cancel** before you click Import closes the dialog and discards your choices. Once Import has started, wait for the result before you try again.

## What the new item contains

- **Title** is the opportunity summary, or "Opportunity" plus its ID when there is no summary.
- **Description** is the opportunity's details.
- **Due Date** is the target date, or the deadline when there is no target date.
- **Costs** is one One-time row with the adjusted opportunity value, or 0 when there is none.
- **Status** comes from your mapping.

A new item does not prove that the commercial details are complete or approved.

## Later PSA updates

Imported items stay linked to the opportunity. Later syncs can overwrite the Planner fields your integration is set to refresh. By default those are Title, Description, Due Date and Cost Estimate. The integration's **Linked planner item refresh** settings can add Public notes, Start date, Estimated hours, Probability, Status and Planner type, and can map PSA statuses and types to Planner values.

Turning off **Auto-import opportunities into the Planner** stops new items from being created. It does not stop linked items from refreshing. Ask the integration administrator to check **Opportunity Settings** if a value changes back after you edit it.

Import does not edit, accept or close the opportunity in the PSA. To attach an existing Planner item to an opportunity without making a new item, see [Link supporting records to Planner items](/user-guides/planner/link-supporting-records). A manual link is not the same as a PSA-managed import, and it does not show as **Imported** here.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Import** is missing | You need Manage Planner and a connected Halo, ConnectWise or Autotask integration. |
| An opportunity is missing | Check its company mapping, that opportunity sync is on, the search text, the due date range and **Hide already imported**. |
| An undated opportunity shows inside a date range | Opportunities with no dates always stay in the list. |
| A row is grayed out | It already has a PSA-managed Planner link. Find that item instead. |
| Your ticks disappeared | A search, filter, page or company change reset them. Tick again. |
| Some opportunities were skipped | Read the messages. Check the company mapping and look for the existing Planner item before you retry. |
| **Next** opens an empty page | The last page held exactly 200 rows. Click **Previous** or narrow the search. |
| A field changed back later | Check **Linked planner item refresh** in the PSA integration's **Opportunity Settings**. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Which providers can I import from?">
    Halo, ConnectWise and Autotask.
  </Accordion>
  <Accordion title="Is Import a spreadsheet upload?">
    No. It selects opportunities already synced from your PSA.
  </Accordion>
  <Accordion title="Why can I not find an older opportunity?">
    The date range starts at one year ago. Widen or clear it, then check the company selector, the search and **Hide already imported**.
  </Accordion>
  <Accordion title="Does the date range hide opportunities with no date?">
    No. They always stay in the list.
  </Accordion>
  <Accordion title="Does Select all include later pages?">
    No. It selects the current page, up to 200 rows.
  </Accordion>
  <Accordion title="Do status mappings change the PSA opportunity?">
    No. They set the new Planner item's status only.
  </Accordion>
  <Accordion title="Are imported items hidden from company users?">
    No. They are visible by default, within company access and Planner permissions. Check each new item.
  </Accordion>
  <Accordion title="Why is an opportunity marked Imported?">
    It already has a PSA-managed Planner link. It cannot be selected again.
  </Accordion>
  <Accordion title="Does linking an opportunity by hand count as importing it?">
    No. **Imported** tracks PSA-managed imports only.
  </Accordion>
  <Accordion title="Can an import partly succeed?">
    Yes. Read the imported and skipped messages and check List View before you rerun.
  </Accordion>
</AccordionGroup>
