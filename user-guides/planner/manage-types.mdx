Planner types classify planned work, such as Hardware, Software or Professional Services. They also supply the budget categories in Budgets. This guide is for MSP staff. These are shared settings for all your companies. Company administrators do not manage them.

## Before you start

- Open **Settings > Customization > Types** and choose the **Planner Types** tab. The other tab, **Device Types**, has its own **Add** menu, so check the selected tab first.
- Your Planner Types permissions decide what you can do:

| Planner Types permission | What you can do |
| --- | --- |
| **Read** | View the list. |
| **Write** or **Manage** | Add and edit types and change the default. |
| **Manage** | Delete a type, with reassignment when needed. |

- Changes also need active billing. If a button works but saving is refused, ask your MSP administrator to check your Planner Types permissions and billing.
- An older page at `/settings/planner-types` shows the same list but has no **Add** menu. Use **Settings > Customization > Types** to add types.

## Add one type

<Steps>
  <Step title="Open Add">
    Click **Add** in the page header, then choose **Add Planner Type**.

    <Frame caption="Choose Add Planner Type for one row, or Add Multiple to enter several names.">
      <img src="/images/product/planner-types-add-options.png" alt="Planner Types Add menu offering Add Planner Type and Add Multiple." width="336" height="148" />
    </Frame>
  </Step>
  <Step title="Fill in the new row">
    A new row appears at the top of the list. Type a **Name**, and optionally a description.
  </Step>
  <Step title="Save the row">
    Click the green check to save, or the red cross to cancel.
  </Step>
  <Step title="Confirm">
    Wait for the success message and check that the row stays in the list.
  </Step>
</Steps>

A new row is not saved until you click the green check. Names are required, trimmed when saved and limited to 255 characters. A name that already exists is rejected.

## Add several types

<Steps>
  <Step title="Open Add Multiple">
    Click **Add > Add Multiple**. The **Add Multiple Planner Types** dialog opens.
  </Step>
  <Step title="Enter the names">
    Type one name per line. Empty lines are ignored. The dialog counts the items to create.
  </Step>
  <Step title="Click Create All">
    Click **Cancel** instead to leave without creating anything.
  </Step>
  <Step title="Read the messages">
    You get a success message and, if any failed, a failure message. Check the list before you retry missing names.
  </Step>
</Steps>

Each name is created on its own, so one failure does not stop the others. The dialog clears when it finishes, so keep your list until you have checked the result. **Add Multiple** does not set descriptions. Add them afterward with the pencil.

## Rename or describe a type

<Steps>
  <Step title="Click the pencil">
    Find the row and click its pencil button.
  </Step>
  <Step title="Edit the name and description">
    Change the text in the row.
  </Step>
  <Step title="Save">
    Click the green check, or the red cross to cancel.
  </Step>
</Steps>

Renaming changes the live label everywhere the type is used, including Planner and budget forecasting. It does not create a second type or move any item to a different type. Approved budget snapshots keep the name that was recorded when they were approved.

## Set or remove the default

<Steps>
  <Step title="Click the star">
    Click the star on a row (**Set as default**). It saves at once, the row shows **Default** and the star fills in. Choosing another type replaces the previous default.
  </Step>
  <Step title="Remove the default (optional)">
    Click the filled star (**Remove as default**) to clear it. Nothing else becomes the default.
  </Step>
</Steps>

There is no **Save** button for the default. The default is the starting **Type** on a new Planner item that has none. Review the **Type** before you save, because templates and other ways of creating items can supply a different one. Changing the default does not reclassify existing items.

To delete a type, see [Delete or reassign Planner types](/user-guides/planner/retire-types).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Add** is missing | Use **Settings > Customization > Types** with the **Planner Types** tab selected. |
| **Add**, the pencil or the star is turned off | You need Write or Manage for Planner Types. |
| Saving is refused although controls work | Check that the name is filled in and not a duplicate, that billing is active and that you have Planner access. |
| Some pasted names are missing | Read the failure message, look at the list and retry only the missing names. |
| The name looks different after reopening | Saved names and descriptions are trimmed. |
| Existing items kept their old type after you changed the default | The default affects new items only. |
| A budget still shows an older category name | It may be an approved snapshot. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I add a Planner type?">
    **Settings > Customization > Types**, the **Planner Types** tab, then **Add > Add Planner Type**.
  </Accordion>
  <Accordion title="Is a Planner type specific to one company?">
    No. The list is shared across all your companies.
  </Accordion>
  <Accordion title="Does Add Planner Type save right away?">
    No. It opens a new row. Click the green check to save.
  </Accordion>
  <Accordion title="Can I add several names at once?">
    Yes. Use **Add Multiple**, one name per line, then **Create All**.
  </Accordion>
  <Accordion title="Does Add Multiple roll back if one name fails?">
    No. Names save independently.
  </Accordion>
  <Accordion title="Can I use the same name twice?">
    No. An exact duplicate name is rejected.
  </Accordion>
  <Accordion title="Does renaming a type affect budgets?">
    Yes, live budget forecasting uses the new label. Approved snapshots keep the old one.
  </Accordion>
  <Accordion title="Can more than one type be the default?">
    No. Setting a new default replaces the old one. You can also clear the default.
  </Accordion>
  <Accordion title="Why can I edit but not delete a type?">
    Delete needs Manage for Planner Types and can require reassignment.
  </Accordion>
</AccordionGroup>
