Fill a new or existing Planner item from a template, and choose which fields the template overwrites. This guide is for MSP staff with Planner editing access. To make the template first, see [Create and manage Planner templates](/user-guides/planner/manage-templates).

## Before you start

- You need **Write Planner** or **Manage Planner**. The **Apply Template** button is turned off when no templates exist.
- Set the item's **Company** first if you want **Compliance auto-link** to work.
- Applying a template changes the item's form. Nothing is saved until you click **Save**.

## Apply a template

<Steps>
  <Step title="Open the item">
    Open an item from List View or the timeline. For a new item, click **Add Item**, then set its company and title.
  </Step>
  <Step title="Click Apply Template">
    Click **Apply Template** beside **Description**. On a new item the button says **Use Template**.
  </Step>
  <Step title="Pick a template">
    Search under **Select Template** and click the template you want. Clicking a name only selects it.
  </Step>
  <Step title="Choose the fields to copy">
    Review **Fields to Apply**. Every field starts ticked. Click **None** to clear them all and tick only what you need, or **All** to tick every field.

    <Frame caption="Example: copy Estimated Hours, Cost Rows and the template's visibility setting. The other item fields stay as they are.">
      <img src="/images/product/planner-template-field-selection.png" alt="Fields to Apply with only Estimated Hours, Cost Rows and Hide from company users selected." width="696" height="892" />
    </Frame>
  </Step>
  <Step title="Click Apply Template">
    The dialog's **Apply Template** button is turned off until a template and at least one field are chosen. The values now appear in the item form.
  </Step>
  <Step title="Review the item">
    Check the title, notes, costs, relationships and the **Hide from company users** box.
  </Step>
  <Step title="Click Save">
    Wait for the success message, then reopen the item to confirm.
  </Step>
</Steps>

To throw the result away, close the item and choose **Discard**. If no template appears in the list, clear the search box and ask your MSP to check the template catalog and your access.

## Know what each field replaces

| Field | What happens |
| --- | --- |
| **Title**, **Description**, **Type**, **Status**, **Business Value** | Copies the template's value. Leave a field unticked to keep the item's own value. |
| **Estimated Hours**, **Probability of Success** | Replaces the item's estimate. It does not add to it. |
| **Cost Rows (one-time / monthly / annual)** | Replaces the whole cost list with the template's rows, including quantity and unit amount. A template with no rows adds its legacy estimate as one One-time row. |
| **Public Notes**, **Private Notes** | Replaces the notes when the template has them. It does not append. |
| **Hide from company users** | Copies the template's visibility setting. The item can end up visible or hidden. |
| **Compliance auto-link** | Replaces the item's compliance links with the newest matching assignment in the item's company for each check. |

Unticked fields keep their current values. A template field that is empty (null) leaves the item's value alone. A field that holds empty text can clear the item's value, so check the result.

**Company**, **Due Date** and **Assignee** are not part of the choices. Set them on the item. Custom field values and uploaded files are not copied.

To copy only an estimate, click **None**, tick **Estimated Hours** and **Cost Rows**, then click **Apply Template**.

## Review compliance links

**Compliance auto-link** looks for the newest assignment of each configured check in the item's company. It does not create a missing assignment, fix a finding or copy another company's assignment.

If no company is set on the item, no links are added. If some checks have no matching assignment, a message says so and the other fields still apply. Check **Relationships** before you save. If the lookup fails, the dialog keeps your template and field choices so you can try again.

## Review costs, notes and visibility

- Public Notes are visible to anyone who can read the item. Private Notes stay MSP-only.
- Ticking **Hide from company users** copies the template's saved setting. Check the checkbox at the bottom of the item afterward.
- Compare the cost rows with what you expect before you save.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Apply Template** is grayed out on the item | No templates exist yet. Ask someone with Manage Planner to create one. |
| The dialog's **Apply Template** is grayed out | Choose a template and tick at least one field. |
| No compliance links were added | Set the item's company first, and check that the company has matching assignments. |
| Costs look different | **Cost Rows** replaces the list. Compare the quantity, amount and recurrence of each row. |
| Notes were overwritten | Public and Private Notes replace the existing text. Untick them to keep your notes. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I apply a template to an existing item?">
    Open the item and click **Apply Template** beside **Description**. Pick the template and fields, apply, review and **Save**.
  </Accordion>
  <Accordion title="Does clicking a template name apply it?">
    No. Choose fields and click **Apply Template**. The item's **Save** keeps the result.
  </Accordion>
  <Accordion title="How do I copy estimates without changing the title?">
    Click **None**, tick **Estimated Hours** and **Cost Rows**, apply and **Save**.
  </Accordion>
  <Accordion title="Are all fields ticked at first?">
    Yes. Review them each time.
  </Accordion>
  <Accordion title="Does applying costs add rows to the existing list?">
    No. It replaces the list.
  </Accordion>
  <Accordion title="Does applying Public Notes append the template text?">
    No. It replaces the notes when the template has text.
  </Accordion>
  <Accordion title="Does Hide from company users always hide the item?">
    No. It copies the template's setting, which can be visible or hidden.
  </Accordion>
  <Accordion title="Can a template change the company, due date or assignee?">
    No. Set them on the item.
  </Accordion>
  <Accordion title="Can I undo a template before saving?">
    Yes. Close the item and choose **Discard**. File changes you already made stay.
  </Accordion>
  <Accordion title="Is this the same as Apply to Companies?">
    No. This changes fields on one item. Apply to Companies creates new items.
  </Accordion>
</AccordionGroup>
