Attach files to a Planner item, download them and delete them. Company users and MSP staff can download. Uploading and deleting are for MSP staff.

## Before you start

- Downloading needs Planner read access to the item.
- Uploading needs **Write Planner** or **Manage Planner**.
- Deleting an uploaded file needs **Manage Planner**. Staff with only Write Planner can see a delete button, but the delete is refused.
- Files belong to a saved item. A new, unsaved item and a Planner template have no **Uploads** section.

## Download a file

<Steps>
  <Step title="Open the item">
    Click the item's title in List View or on the timeline.
  </Step>
  <Step title="Expand Uploads">
    Click **Uploads** in the right column. The number beside it is the file count. When files exist, the paperclip beside the title jumps to this section.
  </Step>
  <Step title="Click Download">
    Click **Download** beside the file name, then open the file from your browser's downloads.

    <Frame caption="Example with a demo handover file. Read-only users see Download but not the upload area or Delete.">
      <img src="/images/product/planner-file-controls.png" alt="Planner Uploads section showing a demo handover text file with Download and Delete controls." width="1368" height="666" />
    </Frame>
  </Step>
</Steps>

The list shows file names only. There is no inline preview. Planner Analytics exports and provider documents are separate from these files.

## Upload files

<Steps>
  <Step title="Save the item first">
    For a new item, click **Save**, then reopen it.
  </Step>
  <Step title="Expand Uploads">
    Click **Uploads** in the right column.
  </Step>
  <Step title="Add files">
    Click **Click to upload**, or drag files into the box. You can add several files. The box says **Any file format (max. 10MB)**.
  </Step>
  <Step title="Wait for each file">
    Each file shows under **Uploaded files** when it finishes. If one fails, read its message and click **Try again**.
  </Step>
  <Step title="Confirm">
    Close and reopen the item. Check that the file is still listed, and download it if you need to confirm its contents.
  </Step>
</Steps>

Uploading starts the moment you choose or drop files. It does not wait for the item's **Save** button. Closing the item and choosing **Discard** for other edits does not remove an upload that already finished.

A progress percentage does not confirm the file is attached. Check the file name under **Uploaded files**. Removing a failed row from the progress list does not cancel a transfer that is still running. Wait for it to finish, then delete an unwanted file from the saved list.

## Delete an uploaded file

<Steps>
  <Step title="Open the saved item">
    Expand **Uploads**.
  </Step>
  <Step title="Check the file name">
    Make sure it is the file you want to remove.
  </Step>
  <Step title="Click Delete">
    Click the **Delete** button beside that file. It runs at once, with no confirmation and no **Save** step.
  </Step>
  <Step title="Confirm">
    Wait for the row to disappear, then reopen the item to check.
  </Step>
</Steps>

**Discard** does not bring back a deleted file. If you still have the original, upload it again. Deleting a file does not delete the Planner item or its relationships.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Uploads** is missing | Save the new item first. Templates never have uploads. |
| Only **Download** shows | You have read access only. Ask your MSP for Write Planner. |
| An upload failed | Read the message, check the 10MB limit and your connection, check **Uploaded files**, then click **Try again**. |
| A delete failed, or the file is still there | Ask your MSP to check that you have Manage Planner. Reopen the item and check the file name before you try again. |
| The file name shows but the download fails | Tell your MSP the item and the file name. |
| You selected several files | Check each one. One success does not mean the rest finished. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I download a file attached to an item?">
    Open the saved item, expand **Uploads** and click **Download** beside the file name.
  </Accordion>
  <Accordion title="Can I preview an attachment in the dialog?">
    No. Download the file and open it in an app.
  </Accordion>
  <Accordion title="Why can I not upload while creating a new item?">
    Save the item first, then reopen it.
  </Accordion>
  <Accordion title="Does uploading wait for Save?">
    No. It starts as soon as you choose the files.
  </Accordion>
  <Accordion title="Does Discard remove an upload?">
    No. Uploads and deletions are separate from the form's **Save** and **Discard**.
  </Accordion>
  <Accordion title="Can I add more than one file?">
    Yes. Check each file's result.
  </Accordion>
  <Accordion title="What is the size limit?">
    The upload box says **Any file format (max. 10MB)**.
  </Accordion>
  <Accordion title="Which permission deletes a file?">
    Manage Planner.
  </Accordion>
  <Accordion title="Does deleting a file delete the item or its relationships?">
    No. Only the attachment is removed.
  </Accordion>
</AccordionGroup>
