Each company needs its own URL before its users can open an external dashboard. This guide is for MSP staff with Dashboards access under Settings.

## Before you start

- Add the external dashboard first. See [Configure external dashboards](/user-guides/dashboards/configure-external-dashboards).
- Company users always use their company's URL. A company with no URL never falls back to the default URL, and the dashboard is hidden from it. The default URL is used for MSP staff in **Global View**.
- Every URL must start with `https://`.

## Add a company URL

<Steps>
  <Step title="Open Company URLs">
    Go to **Settings > Dashboards > External Dashboards**. On the item's row, open **... > Company URLs**. The **Company-Specific URLs** dialog opens.
  </Step>
  <Step title="Choose the company">
    Under **Add Manually**, pick a company in **Company**. The list shows only companies that do not have a URL for this item yet.
  </Step>
  <Step title="Enter the URL">
    Type the company's `https://` dashboard address in **URL**.
  </Step>
  <Step title="Click Add Company URL">
    The URL is saved at once and appears under **Assigned URLs**.
  </Step>
  <Step title="Test it">
    Open the dashboard with that company selected, or as a user of that company, and confirm it loads. The embedding check covers the default URL only, so test each company URL yourself.
  </Step>
</Steps>

## Edit or remove an assignment

<Steps>
  <Step title="Find the company">
    The right side lists **Assigned URLs (n)**. Use **Filter by company or URL...** to narrow it.
  </Step>
  <Step title="Edit the URL">
    Click the pencil icon, change the URL, then click the check mark to save. The **X** cancels the edit.
  </Step>
  <Step title="Or remove the assignment">
    Click the trash icon. The assignment is removed at once with no confirmation. That company no longer sees the dashboard.
  </Step>
</Steps>

Removing a URL does not delete the company or the dashboard in the external service. **Close** only closes the dialog. It does not undo saved changes. To restore a removed assignment, add the company and URL again.

## Import and export with CSV

The dialog works on one external item at a time.

<Steps>
  <Step title="Export the current list">
    Click **Export CSV** above the list. Choose **Export Current (n)** for assigned URLs only. Choose **Export All Companies (n)** for every company, with a blank URL for those not assigned. The filter box does not narrow either export.
  </Step>
  <Step title="Edit the file">
    Keep the header `"Company Name","URL"`. Put both values in double quotes, one company per line. Match the company's name. Use `https://` addresses.
  </Step>
  <Step title="Upload it">
    Under **Import from CSV**, click **Upload CSV** and choose the file. It processes as soon as you pick it. There is no preview.
  </Step>
  <Step title="Read the result">
    A message reports how many rows were added, updated, skipped or failed. Open **Assigned URLs** to check the actual result.
  </Step>
</Steps>

The import matches company names without regard to case. It skips rows with a blank URL and rows whose URL has not changed. Blank rows never remove an assignment. Use the trash icon for that. Rows are saved one at a time, so some can save while others fail. A failed import does not roll back rows that already saved. For a company name that contains a quotation mark, or when two companies share a name, add the URL manually.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The company is not in the **Company** list | It already has a URL. Edit it under **Assigned URLs**. |
| A company cannot open the dashboard | Check its assigned URL, that the item is **Active**, that the user's Company role is allowed, and that the user can sign in to the external service. |
| The URL saves but does not load in the frame | Open the URL on its own. The embedding check covers only the default URL. |
| Closing the dialog did not undo a change | Each change saves on its own. Edit the value back or add the assignment again. |
| A CSV import changed only some rows | Read the message and check **Assigned URLs**. Unchanged and blank rows are skipped and other rows can fail alone. |
| A URL is rejected | It must be a full `https://` address. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I give a company its own dashboard URL?">
    **Settings > Dashboards > External Dashboards**, then the item's **... > Company URLs**.
  </Accordion>
  <Accordion title="Does the default URL give unassigned companies access?">
    No. Each company needs its own URL. The default URL is for MSP staff.
  </Accordion>
  <Accordion title="Can two companies use different links for the same item?">
    Yes. Assign each company its own URL under the same item.
  </Accordion>
  <Accordion title="Does Add Company URL save at once?">
    Yes. **Close** is not an undo.
  </Accordion>
  <Accordion title="Does removing a URL ask for confirmation?">
    No. The trash icon removes it right away.
  </Accordion>
  <Accordion title="Does Export All Companies assign every company?">
    No. It only creates a list. Blank rows do nothing when you import them.
  </Accordion>
  <Accordion title="Does CSV upload have a preview?">
    No. Choosing the file starts the import and saves valid rows.
  </Accordion>
  <Accordion title="Can Company users change these assignments?">
    No. Ask the MSP.
  </Accordion>
</AccordionGroup>
