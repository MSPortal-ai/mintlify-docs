Use **Export PDF** on an internal dashboard to download a static PDF of its current content. It is not an interactive dashboard and not an export of every underlying record. This guide is for Company users and MSP staff.

## Before you start

- You need access to the dashboard you are exporting.
- **Export PDF** downloads a file to your browser. It does not email or publish anything.
- External dashboards have no **Export PDF** button. Use the export or print options of the external service.

## Export a dashboard

<Steps>
  <Step title="Set the view">
    Open the dashboard. Choose the company in the company selector and a preset in the date menu. The export uses your current date choice and widget width.
  </Step>
  <Step title="Wait for the charts to load">
    Check for errors or missing-data messages before you export.
  </Step>
  <Step title="Choose the widget width">
    Use the **½**, **⅓** or **¼** button to set the layout. The PDF uses the same number of columns.
  </Step>
  <Step title="Click Export PDF">
    Click **Export PDF** in the page header. The button reads **Exporting...** while the file is built. Large dashboards can take a while.
  </Step>
  <Step title="Open the file">
    The file is named after the dashboard, for example `Ticketing_Dashboard_Dashboard_2026-10-01.pdf`. The date in the name is the export date.
  </Step>
  <Step title="Review every page">
    Check each chart, label and value. Confirm the company and period before you share the file.
  </Step>
</Steps>

## What the PDF contains

- Landscape pages. US regions use Letter paper and EU regions use A4.
- A header on the first page with your logo, the dashboard title, the date choice and the export date. When exactly one company is selected, the header also shows that company's name and logo.
- The summary cards under the header on the first page, when the dashboard has them.
- Widgets spread over as many pages as they need.
- A footer on every page with your company name, the dashboard title and the page number.

Summary cards keep their own periods, and a widget with its own date setting can differ from the header choice. The PDF is not clickable. To inspect tickets, use the live dashboard and [ticket drilldown](/user-guides/dashboards/inspect-dashboard-tickets). It is not a CSV export and does not hold every ticket row.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No file appears | Wait for **Exporting...** to finish. Check your browser's downloads and any download-blocking message. |
| **Export Failed** appears | Try again. If it repeats, send your MSP the error text, the dashboard, the company and the date choice. |
| The header shows no company name | The header names a company only when exactly one is selected. Select one company and export again. |
| A chart looks wrong in the PDF | Check the same chart in the live dashboard. Report the chart name to your MSP. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Export PDF email or publish the dashboard?">
    No. It downloads a file in your browser. Sharing the file is a separate step.
  </Accordion>
  <Accordion title="Is the PDF interactive?">
    No. It is a static snapshot. Use the live dashboard for drilldowns and filters.
  </Accordion>
  <Accordion title="Does the export date in the file name describe the reporting period?">
    No. It is the export date. Check the date choice in the PDF header, the fixed periods on summary cards and any widget date settings.
  </Accordion>
  <Accordion title="Can I export an external dashboard?">
    No. External dashboards use the options of the external service.
  </Accordion>
  <Accordion title="What should I report when export fails?">
    The dashboard name, the company, the date choice and the visible error.
  </Accordion>
</AccordionGroup>
