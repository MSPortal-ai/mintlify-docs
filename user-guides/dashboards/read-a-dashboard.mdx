Open **Dashboards** to review the charts and summary cards available to you. This guide is for Company users and MSP staff who read dashboard data.

## Before you start

- You need **Dashboards** read access. Your MSP controls which dashboards each role can open.
- Dashboard access does not give access to every module behind a widget.
- Company users cannot change dashboard settings. Ask your MSP.

## Open a dashboard

<Steps>
  <Step title="Open Dashboards">
    Click **Dashboards** in the main navigation. A default or first available dashboard opens automatically.
  </Step>
  <Step title="Switch dashboards">
    Use the icon rail on the left of the page. Hover over an icon to see the dashboard name. The outlined icon is the dashboard you have open, not necessarily the default.
  </Step>
  <Step title="Check the title">
    Read the page title and description before comparing numbers. System dashboards include **Ticketing Dashboard** and **Risk Dashboard**.
  </Step>
</Steps>

## Choose the company

<Steps>
  <Step title="Open the company selector">
    Use the company selector at the top of the portal.
  </Step>
  <Step title="Pick a company or group">
    Choose one company, **Assigned Companies**, or **Global View** if your role allows it. Company users see only their own company.
  </Step>
  <Step title="Wait for the charts to load">
    A single company can show fewer widgets and records than **Global View**.
  </Step>
</Steps>

An empty chart means no records match the company and dates. It does not mean all work is done. Check the dates on the chart and your access before you conclude anything.

## Change the dates

<Steps>
  <Step title="Open the date menu">
    Select the date button in the page header. It shows the current choice, for example **Widget Defaults**.
  </Step>
  <Step title="Choose a preset">
    Pick one of the presets in the table below. The check mark shows the active choice and **Default** marks the dashboard's saved default.
  </Step>
  <Step title="Check each chart">
    Read the dates printed on each chart. A widget can have its own date setting.
  </Step>
</Steps>

<img src="/images/product/dashboard-date-menu.png" alt="Dashboard date menu with Widget Defaults, weekly and monthly presets, and All Time" width="360" height="616" />

| Preset | What it covers |
| --- | --- |
| **Widget Defaults** | Each widget's own date setting. Widgets without one show the last 12 months. |
| **This Week** | The current Sunday to Saturday week. |
| **Previous Week** | The week before, Sunday to Saturday. |
| **Previous 2 Weeks** | The two complete weeks before the current week. |
| **Last 30 days** | The last 30 days up to now. |
| **Last 3 months**, **Last 6 months**, **Last 12 months** | From the first day of the month that many months ago, up to now. These are not fixed 90, 180 or 365 day windows. |
| **All Time** | All available history. |

The menu has no custom start and end date picker. Current-state widgets may not use dates at all. Summary cards keep their own windows and ignore this menu.

Some users also see **Save as dashboard default** at the bottom of the menu. It saves the current choice as the date range the dashboard opens with, for everyone who uses it. Shared and system dashboards need Dashboard settings write access. A personal dashboard needs you to be its owner with write access to Dashboards.

## Change the widget width

<Steps>
  <Step title="Find the width button">
    It sits beside the date menu and shows **½**, **⅓** or **¼**.
  </Step>
  <Step title="Click it to cycle">
    Each click changes the layout to two, three or four columns.
  </Step>
</Steps>

<img src="/images/product/dashboard-display-actions.png" alt="Export PDF, half-width widget control, and Widget Defaults in the dashboard reader" width="730" height="66" />

The date and width controls change only your current view. Permanent layout changes use the [dashboard editor](/user-guides/dashboards/create-and-edit-dashboard).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No dashboards available | Ask your MSP to check dashboard access, active and shared status, role restrictions and Company visibility. |
| A dashboard is missing | Personal dashboards belong to their owner. Shared dashboards can be limited to roles, and internal-only dashboards are hidden from Company users. |
| A widget is missing | Check its module permission, the integration, the selected company and the saved dashboard. |
| No **Edit** button | System dashboards cannot be edited from the reader. Editing a custom dashboard needs write access to Dashboards. |
| Loading or an error | Wait for loading to finish. An error is not a zero result. Note the dashboard, company, dates and message for your MSP. |
| Your numbers differ from a coworker's | Compare the dashboard, company, role visibility, dates and [exclusions](/user-guides/dashboards/understand-dashboard-exclusions). |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does the outlined dashboard icon mean it is the default?">
    No. It marks the dashboard you have open. The default is shown in the date menu and in **Settings > Dashboards**.
  </Accordion>
  <Accordion title="Why did Dashboards open a different dashboard?">
    The portal opens the default dashboard, then the first available one. It can also remember the last dashboard you used. A saved link opens another dashboard if the first is no longer available.
  </Accordion>
  <Accordion title="Why do I not see ticket summary cards?">
    Cards appear only on dashboards set up with them. Risk and other dashboards use different widgets.
  </Accordion>
  <Accordion title="Does the date menu change every metric?">
    No. Date-aware charts follow it unless a widget has its own date setting. Current-state widgets and summary cards keep their own periods.
  </Accordion>
  <Accordion title="Is Last 3 months exactly 90 days?">
    No. It starts on the first day of the month three months ago and ends now. Check the dates printed on the chart.
  </Accordion>
  <Accordion title="Does changing a filter change tickets or risks?">
    No. The date, company and width controls change only what you see.
  </Accordion>
  <Accordion title="Can Company users see an internal-only dashboard?">
    No. Ask your MSP for a dashboard shared with Company users. A direct link does not grant access.
  </Accordion>
  <Accordion title="Can a Company administrator change dashboard permissions?">
    No. Ask your MSP to change user permissions or dashboard access.
  </Accordion>
</AccordionGroup>
