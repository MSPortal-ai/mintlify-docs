Dashboards bring charts and summary cards together in one place. Company users see the dashboards and data available to their role. MSP staff can see broader views and configure dashboards when they have the permissions.

## Before you start

- Dashboards appears in the main navigation for roles with **Dashboards** read access. It also needs an active ConnectWise, Halo, Syncro or Autotask integration.
- Widgets depend on module permissions, connected integrations and data for the selected company. Access to Dashboards alone does not make every widget or record available.
- Company users cannot change dashboards or permissions. Ask your MSP.

## Find your dashboards

<Steps>
  <Step title="Open Dashboards">
    Click **Dashboards** in the main navigation. If a default or first dashboard is available, it opens automatically.
  </Step>
  <Step title="Switch dashboards">
    Use the narrow icon rail on the left of the page. Hover over an icon to see the dashboard name. Icons below the divider are external dashboards.
  </Step>
</Steps>

If no dashboard is available to you, the page shows **No Dashboards Available**. Ask your MSP to share one with your role.

## Dashboard types

| Type | What to expect |
| --- | --- |
| **System** | Built-in layouts such as **Ticketing Dashboard** and **Risk Dashboard**. The reader does not offer **Edit** for system dashboards. |
| **Personal** | A dashboard that belongs to its owner. It is not shared with other users. |
| **Shared** | Available to users according to active status, role access and visibility. |
| **Internal only** | Visibility set to **Internal (MSP Team)**. Company users never see it. |
| **External** | A linked or embedded service with its own sign-in and company setup. |

## Summary cards

A dashboard can show ticket summary cards above its charts. Click a card to see the tickets behind it.

| Card | What it counts |
| --- | --- |
| **Current Open Tickets** | Tickets that are open now. |
| **Entered Prev Month** | Tickets created in the last month. |
| **Closed Prev Month** | Closed tickets last updated in the last month. |
| **Entered Prev 3 Months** | Tickets created in the last 3 months. |
| **Closed Prev 3 Months** | Closed tickets last updated in the last 3 months. |

Cards keep their own time windows. The date menu in the page header does not change them.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Dashboards is missing from the navigation | Ask your MSP to check your **Dashboards** permission and that a PSA integration is connected. |
| A dashboard is missing | Personal dashboards belong to their owner. Shared dashboards can be limited to certain roles, and internal-only dashboards are hidden from Company users. |
| A widget is missing or empty | Check module permissions, integrations, the selected company and the dates on the chart. |
| An external dashboard asks you to sign in | The external service has its own accounts. Sign in with your account for that service. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Should Company users start with the dashboard editor?">
    No. Start with [Read and filter a dashboard](/user-guides/dashboards/read-a-dashboard). Ask your MSP for configuration or permission changes.
  </Accordion>
  <Accordion title="Are all dashboards ticket dashboards?">
    No. System and custom dashboards can hold widgets from many modules, including risk. Ticket summary cards appear only when the dashboard is set up with them.
  </Accordion>
  <Accordion title="Do the date and width controls save a layout?">
    No. They change only your current view. Permanent layout changes use the dashboard editor.
  </Accordion>
  <Accordion title="Where does an MSP configure dashboards?">
    Use the dashboard editor for layout and **Settings > Dashboards** for sharing, roles, external dashboards and exclusions.
  </Accordion>
</AccordionGroup>
