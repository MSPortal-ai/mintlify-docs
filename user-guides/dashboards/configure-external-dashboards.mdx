Use **Settings > Dashboards > External Dashboards** to add links to dashboards in other services and decide who sees them. This guide is for MSP staff. Company users should read [Open an external dashboard](/user-guides/dashboards/open-external-dashboard).

## Before you start

- Open **Settings > Dashboards**. You need Dashboards access under Settings. **Add External Item** and **Check All Policies** are enabled for **Write** or **Manage**.
- Adding a link does not connect an API integration or create an account in the external service. Users still sign in to that service themselves.
- Each Company needs its own URL before its users can open the dashboard. See [Assign company URLs](/user-guides/dashboards/assign-external-dashboard-company-urls).
- The default URL must start with `https://`.

## Add an external dashboard

<Steps>
  <Step title="Open the tab">
    Go to **Settings > Dashboards** and click **External Dashboards**. Wait for the table to load.
  </Step>
  <Step title="Click Add External Item">
    The **Add External Item** dialog opens.
  </Step>
  <Step title="Enter the basics">
    Type a **Name** and an optional **Description**. Enter the **URL** with `https://`. This default URL is only used by MSP staff.
  </Step>
  <Step title="Add an icon (optional)">
    Click **Upload Icon** and choose a PNG or JPEG image. 32x32 pixels or larger works well. The icon uploads as soon as you pick the file. Click **Remove** to clear it.
  </Step>
  <Step title="Set the order">
    Enter a **Display Order** number. Lower numbers appear first.
  </Step>
  <Step title="Choose Company Roles">
    Under **Company Roles (Access Control)**, tick the Company roles that may open it. Leave every box clear to allow all Company roles. These choices limit Company users only. MSP staff are not limited by them.
  </Step>
  <Step title="Click Create">
    The item is created as active. Reopen it from the table to check the saved URL and roles.
  </Step>
  <Step title="Assign company URLs">
    Open the row's **... > Company URLs** and add a URL for each Company that should see it.
  </Step>
</Steps>

The table shows **Name**, **URL**, **Roles**, **Frame Policy** and **Status**. **Roles** reads **All roles** when none are chosen. Badges mark **Default** and **Sidebar**.

## Edit an item

<Steps>
  <Step title="Open the dialog">
    Click the item's name, or open **... > Edit** on its row.
  </Step>
  <Step title="Change the fields">
    Editing also shows **Active**, **Pin to Sidebar** and, when pinned, a **Sidebar Label** of up to 30 characters. An inactive item is hidden from the dashboard list.
  </Step>
  <Step title="Click Update">
    Changes are saved only when you click **Update**.
  </Step>
</Steps>

After you change a URL, run **Check Frame Policy** again from the row menu. The old result does not apply to the new URL. Company URLs are saved separately in the Company URLs dialog.

An icon uploads when you choose it, so **Cancel** does not undo an upload.

## Row actions

<img src="/images/product/external-dashboard-row-menu.png" alt="External dashboard actions for editing, company URLs, frame policy, defaults, sidebar pinning and deletion." width="408" height="486" />

Open **...** on a row. These actions apply as soon as you use them.

| Action | Effect |
| --- | --- |
| **Edit** | Opens the dialog. Use **Update** to save. |
| **Company URLs** | Opens the Company-Specific URLs dialog. |
| **Check Frame Policy** | Starts a background check of the default URL. The table updates shortly after. |
| **Force Allow Embedding** | After you confirm, embeds the dashboard even if the check says it is blocked. Use it when the checker cannot reach the URL, for example an IP-restricted dashboard. The external site can still refuse. |
| **Remove Force Allow** | Goes back to the saved check result. |
| **Set as Default** | Shown on active items that are not the default. Replaces the current internal or external default for the whole tenant. |
| **Remove Default** | Clears the default without choosing another. |
| **Pin to Sidebar** / **Unpin from Sidebar** | Adds or removes the shortcut in the main navigation. Pins are limited to 8 across internal and external dashboards. |
| **Delete** | Opens **Delete External Item**. Click **Delete** to remove the item and its company assignments. This cannot be undone. |

Clicking the URL in the table opens the external site in a new tab.

## Check embedding

Each external dashboard is shown inside MSPortal in a frame. Some sites refuse to be framed.

<Steps>
  <Step title="Run the check">
    Open **... > Check Frame Policy** on the row. To check every active item that has no result yet, click **Check All Policies** at the top of the page.
  </Step>
  <Step title="Read Frame Policy">
    The column shows **Not checked**, **Allowed**, **Blocked** or **Force allowed**.
  </Step>
  <Step title="Test the real link">
    Open the dashboard as the intended user, with their company, and confirm it loads.
  </Step>
</Steps>

| Status | Meaning |
| --- | --- |
| **Not checked** | No result yet. Readers see a notice and an **Open in New Tab** button. |
| **Allowed** | No blocking header was found on the default URL. It does not prove sign-in works or that a company URL loads. |
| **Blocked** | The site forbids framing. Readers see why and an **Open in New Tab** button. |
| **Force allowed** | MSPortal tries to embed it regardless of the check. |

**Check All Policies** only checks active items with no result yet. Use the row action to recheck one item. The check covers the default URL, not company URLs.

## Change several items

<Steps>
  <Step title="Select rows">
    Tick the checkbox on each item you want to change.
  </Step>
  <Step title="Open Actions">
    Click **Actions (n)** at the top of the page.
  </Step>
  <Step title="Choose an action">
    **Edit Permissions** opens a dialog with **Assign Roles (optional)**. Click **Update Permissions** to replace the selected items' roles. **Enable** and **Disable** change availability. **Delete** asks you to confirm and shows the count.
  </Step>
</Steps>

Edit Permissions replaces existing roles. It does not add to them. Leave every box clear to allow all roles. Deleting removes the item in MSPortal only, not the dashboard in the external service. To keep the setup for later, disable the item instead.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The **Add External Item** button is disabled | Ask an admin to give your role **Write** or **Manage** for Dashboards under Settings. |
| The URL is rejected | It must be a full `https://` address. |
| Frame Policy says **Blocked** | The site forbids framing. Readers get an **Open in New Tab** button. If the checker cannot reach the site, use **Force Allow Embedding**. |
| A Company cannot see the dashboard | Check the item is **Active**, the Company has a URL, and the user's Company role is allowed. |
| **Set as Default** is missing | The item is inactive or already the default. |
| The icon looks wrong | Upload a small PNG or JPEG and check the saved result in the table. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does creating an external dashboard set up an API integration?">
    No. It creates a link or embedded view. Set up API integrations separately.
  </Accordion>
  <Accordion title="Which URL format is accepted?">
    A full `https://` URL, for the default and for each Company.
  </Accordion>
  <Accordion title="What does leaving Company Roles empty mean?">
    All Company roles can open it. The item still needs to be active and the Company needs its own URL.
  </Accordion>
  <Accordion title="Do Company Roles limit MSP staff?">
    No. They limit Company users only.
  </Accordion>
  <Accordion title="Does Check All Policies recheck everything?">
    No. It checks active items that have no result yet.
  </Accordion>
  <Accordion title="Does Allowed prove the dashboard works?">
    No. It means no blocking header was found on the default URL. Sign-in and company URLs still need a test.
  </Accordion>
  <Accordion title="Does Set as Default affect internal dashboards?">
    Yes. It clears any other default, internal or external, for the tenant.
  </Accordion>
  <Accordion title="Does deleting an item delete the dashboard in the other service?">
    No. It removes the link and company assignments in MSPortal.
  </Accordion>
  <Accordion title="What is the difference between Active and pinned?">
    **Active** controls availability. A pin only adds a navigation shortcut and grants no access.
  </Accordion>
</AccordionGroup>
