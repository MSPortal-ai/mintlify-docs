This page shows MSP staff how to keep a project's plans, quotes, contracts, and supporting files together in **Files & Forms > Documents**. The same workspace also lists client uploads and document requests for projects with a client onboarding portal. For files attached to one deliverable, use [Deliverable documents](/user-guides/projects/manage-deliverable-documents).

## Before you start

- Documents is for MSP staff. You need project read permission to view files and project write permission to upload, rename, move, or delete them.
- A file you upload is internal. Uploading a file does not share it with the client.
- Files must have content and be 50 MB or smaller. Accepted types are PDF, DOCX, XLSX, XLS, CSV, PPTX, PNG, JPG, and JPEG.
- PDFs, Word files, spreadsheets, CSV files, and images preview inside MSPortal. Other accepted files, such as PowerPoint, offer a download.

## Upload files

<Steps>
  <Step title="Open Documents">
    Open **Projects**, click the project, then click **Files & Forms** and **Documents**.
  </Step>
  <Step title="Pick a folder">
    Click the folder in the list on the left to upload into it. **All documents** lists every file in the project. **Unfiled** lists files with no folder.
  </Step>
  <Step title="Upload">
    Click **Upload** and choose one or more files, or drag files onto the panel. Drop a file on a folder to put it there. Uploading from or dropping onto **All documents** puts files in **Unfiled**.
  </Step>
  <Step title="Check the result">
    Wait for the upload to finish and make sure each file appears in the table. Click a file name to preview it, or open its **...** menu and choose **Download**.
  </Step>
</Steps>

## Organize folders and files

<Steps>
  <Step title="Create a folder">
    Click the new folder button above the folder list and enter a name. A folder's **...** menu lets you add a subfolder, **Rename**, **Move**, or **Delete** it. Selecting a folder also shows the files in its subfolders.
  </Step>
  <Step title="Move files">
    Open a file's **...** menu and choose **Move to folder**, or drag a row onto a folder. To move several files, tick them and click **Move to folder** at the top.
  </Step>
  <Step title="Rename a file">
    Open the file's **...** menu, choose **Rename**, and keep the file extension.
  </Step>
  <Step title="Delete">
    Open the file's **...** menu and choose **Delete**, or tick several files and click **Delete**. Confirm. Deleting a folder moves its files up to its parent folder. Deleting a file removes it for everyone on the project and cannot be undone.
  </Step>
</Steps>

## Email files into a folder

<Steps>
  <Step title="Open the folder menu">
    Click the **...** next to the folder and choose **Email files**.
  </Step>
  <Step title="Enable the address">
    Click **Enable** to create the folder's email address. Click **Copy** to copy it.
  </Step>
  <Step title="Send attachments">
    Send attachments to that address and they land in the folder, still internal. Anyone with the address can send files without signing in, so share it carefully. Click **Disable** to turn it off.
  </Step>
</Steps>

Email uploads accept PDF, Word, Excel, CSV, PowerPoint, PNG, and JPEG files up to 50 MB each.

## Share a file with the client

On a project with a client onboarding portal, you can share a file with its contacts.

<Steps>
  <Step title="Open the file's menu">
    Click the **...** on the file and choose **Client sharing**. You see this only for files you are allowed to share.
  </Step>
  <Step title="Choose where to share">
    Pick the **Client portal**, and the **Phase** if it asks for one.
  </Step>
  <Step title="Share it">
    Click **Share file**. Every contact in that portal can then get the original file. The **Access** column changes from **Internal** to **Client visible**.
  </Step>
  <Step title="Stop sharing">
    Open **Client sharing** again and click **Revoke access**. New downloads stop right away. Links already issued expire within five minutes.
  </Step>
</Steps>

For document requests on a portal, the **Request** and **Status** columns show the request and where it stands, and **Request & review** in the file's menu opens the request.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Documents** is missing | You need MSP staff access and project read permission, and the unified Projects update must be enabled for your portal. |
| An upload was rejected | Check the file type, that it is not empty, that it is 50 MB or smaller, and that you have project write permission. |
| A file is not in the folder you expected | Check **All documents** and **Unfiled**, and the folder you were in when you uploaded. |
| The client cannot see a file | Files you upload are internal. Use **Client sharing** on a project with a client portal. |
| **Email files** is missing | It is part of the folder menu for staff with write access. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Is there a recycle bin?">
    No. Deleted files cannot be restored.
  </Accordion>
  <Accordion title="Does a file in Documents appear on a deliverable?">
    No. Files on a deliverable are managed on the deliverable. See [Deliverable documents](/user-guides/projects/manage-deliverable-documents).
  </Accordion>
  <Accordion title="Can Company users see Documents?">
    No. Company users get files only through sharing, requests, or deliverables.
  </Accordion>
</AccordionGroup>
