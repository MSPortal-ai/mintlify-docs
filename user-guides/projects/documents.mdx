Open a project and select **Documents** to keep internal plans, quotes, contracts, and supporting files together. This is an MSP staff area. Company users do not see it, and uploading here does not share a file with a client.

For client-uploaded onboarding files, use **Client Portal > Documents**. For files attached to a deliverable, use [Deliverable documents](/user-guides/projects/manage-deliverable-documents).

## Access and supported files

Project read permission permits viewing; project write or manage permission permits changes. Files must be non-empty and no larger than **50 MB** each. Accepted extensions are PDF, DOCX, XLSX, XLS, CSV, PPTX, PNG, JPG, and JPEG.

PDFs, Word documents, spreadsheets, CSV files, and images use the in-app preview where supported. Other accepted files, including PowerPoint, offer download. PDF preview offers a fullscreen control. Preview does not edit the source file.

## Upload and organize

1. Select **Upload** or drag files onto the document panel.
2. Choose a folder first to upload into it, or drop directly onto a folder. Uploading from **All documents**, or dropping onto **All documents**, places files in **Unfiled**.
3. Wait for the upload result and confirm the files appear. Open a file to preview it or use its row menu to download.

Create folders with the folder controls. A folder's menu supports subfolders, rename, move, and delete. Selecting a folder includes files in its descendants. **All documents** lists the whole project's files; **Unfiled** lists files without a folder.

Move files using a row's **Move to** action or by dragging a row onto a folder. Select multiple files for bulk move or delete. Filtering removes hidden files from the pending selection; review the remaining selection before confirming a bulk action.

## Delete carefully

Deleting a folder moves its contents up to its parent. Deleting documents removes the files themselves. Review the confirmation; the tab has no recycle bin or restore action for deleted files.

## Troubleshooting

| Problem | Check |
| --- | --- |
| Tab missing | Staff access and project read permission. |
| Load error before rollout | Ask your administrator to complete the Documents database rollout. |
| Upload rejected | File extension, non-empty content, 50 MB limit, and project write permission. |
| File not in the expected folder | Check All documents, Unfiled, and the upload destination. |
| Client cannot see the file | Staff Documents are internal. Use the appropriate client-facing workflow. |
