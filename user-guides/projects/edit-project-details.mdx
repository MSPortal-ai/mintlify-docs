## Update project details

<Steps>
  <Step title="Open Edit Project Details">
    Open **Projects**, select the intended project, and select **Edit Project Details** in the header.
  </Step>
  <Step title="Maintain the narrative">
    Set **Project Goal** to a short outcome title, **Project Description** to explain the scope and result, and **Current Phase** to the label you want in the Overview information bar. The form allows up to 200, 2,000, and 100 characters respectively.
  </Step>
  <Step title="Set health, if needed">
    **Health Status** starts on **Automatic**, which calculates health from the project's dates, hours and hold state. To override it, choose **On Track**, **At Risk** or **Blocked**, then explain why in **Status Note** (up to 500 characters). The note appears beside the health badge on Overview and in the projects health overview. Company users can read it on projects shared with them.

    <img src="/images/product/project-health-editor-preview.png" alt="Branch preview: Edit Project Details with Health Status set to At Risk and a Status Note explaining the override" width="994" height="507" />

    Branch preview of the MSP editor using Demo sample text. Choose **Automatic** again to return to the calculated health; saving clears the note.
  </Step>
  <Step title="Review Company visibility">
    **Hide from company users** is a checkbox: checked hides the project from Company users; unchecked allows it to appear for users who otherwise have access. It does not create users or grant permissions. Shared collaboration items have their own visibility settings too.
  </Step>
  <Step title="Save Changes">
    Select **Save Changes** and wait for success. These fields do not autosave while typing. Revisit Overview and reopen the form to check the saved values. If saving fails, retain your intended text and verify the current record before trying again.
  </Step>
</Steps>

Project Goal appears as **Goal** in the information bar. Project Description appears as **Project Outcome**. **Project Summary** is a separate project summary; this form does not rename the project or replace that summary. Clearing one of these optional fields removes its corresponding narrative value after saving.

Closing the dialog without saving discards the form edits. Current Phase is a descriptive label: changing it does not move tickets, rename a phase in the plan, reschedule work, or change project status. These details stay in MSPortal; do not expect a PSA writeback from this form.

To update names and contact details, use [Overview > Contacts](/user-guides/projects/manage-project-contacts). For the project's work plan, use the relevant [workspace tabs](/user-guides/projects/workspace).

## FAQs

<AccordionGroup>
  <Accordion title="Why did my description not change Project Summary?">
    Project Description is displayed as Project Outcome. The project's separate summary is not edited by this form.
  </Accordion>
  <Accordion title="Does Current Phase move the project into that phase?">
    No. It changes a label in the Overview information bar. Manage the plan and ticket statuses separately.
  </Accordion>
  <Accordion title="Does this form save as I type?">
    No. Select Save Changes. Closing the dialog without saving discards its edits.
  </Accordion>
  <Accordion title="Does unchecking Hide from company users share everything?">
    No. Company users still need project access, and updates, milestones, deliverables, and documents have their own visibility controls.
  </Accordion>
  <Accordion title="Can I rename the project or change its status here?">
    This form edits the goal, description, phase label, health override, and Company visibility. Project name, schedule, and status use their own supported workflow.
  </Accordion>
  <Accordion title="Why can't I set health to Completed?">
    Completed comes from closing the project. The override offers On Track, At Risk and Blocked only.
  </Accordion>
  <Accordion title="Where do I change the client sponsor?">
    Use the edit control in Overview's Contacts section, then Save Changes there. See [Manage project contacts](/user-guides/projects/manage-project-contacts).
  </Accordion>
</AccordionGroup>
