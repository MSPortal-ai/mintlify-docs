This page shows MSP staff how to edit a project's goal, description, current phase, health, and client visibility.

## Before you start

- You need permission to edit project collaboration content (project overlay edit).
- Company users cannot edit these details. They [read the Client Dashboard](/user-guides/projects/read-project-overview).
- The **Hide from company users** checkbox is for MSP staff only.

## Update project details

<Steps>
  <Step title="Open Edit Project Details">
    Open **Projects**, click the project, and click **Edit Project Details** in the page header.
  </Step>
  <Step title="Maintain the narrative">
    Type a short outcome title in **Project Goal**, explain the scope and result in **Project Description**, and enter the label you want shown as the current phase in **Current Phase**. The limits are 200, 2,000, and 100 characters.
  </Step>
  <Step title="Set health, if needed">
    **Health Status** starts on **Automatic**, which works out health from the project's dates, hours, and hold state. To override it, choose **On Track**, **At Risk**, or **Blocked**, then explain why in **Status Note** (up to 500 characters). The note shows beside the health badge on the Client Dashboard and in the health overview. Company users can read it on projects shared with them.

    <img src="/images/product/project-health-editor-preview.png" alt="Branch preview: Edit Project Details with Health Status set to At Risk and a Status Note explaining the override" width="994" height="507" />

    Branch preview of the MSP editor using Demo sample text. Choose **Automatic** again to go back to calculated health. Saving then clears the note.
  </Step>
  <Step title="Review Company visibility">
    Tick **Hide from company users** to hide the project from Company users. Untick it to let it appear for users who already have access. It does not create users or grant permissions. Updates, milestones, deliverables, and documents each have their own visibility setting too.
  </Step>
  <Step title="Save Changes">
    Click **Save Changes** and wait for **Project details updated**. The form does not save as you type. Check the Client Dashboard to confirm the values. If saving fails, check the record before you try again.
  </Step>
</Steps>

**Project Goal** shows as **Goal** and **Current Phase** as **Phase** on the Client Dashboard. **Project Description** shows as **Project Outcome**. The form does not rename the project or edit the separate **Project Summary**. Clearing a field removes that text after you save.

Closing the dialog without saving discards your edits. **Current Phase** is only a label. It does not move tickets, rename a plan phase, reschedule work, or change the project status. These details stay in MSPortal and are not written to your PSA.

To change names and contact details, use [Client Dashboard > Contacts](/user-guides/projects/manage-project-contacts). For the work plan, see the [project workspace](/user-guides/projects/workspace).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Edit Project Details** is missing | Ask an admin to give your role the project overlay-edit permission. |
| Saving fails | Check the character limits, then try again. Your text stays in the form until you close it. |
| **Completed** is not in the health list | **Completed** comes from closing the project. The override offers **On Track**, **At Risk**, and **Blocked**. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why did my description not change Project Summary?">
    Project Description is displayed as Project Outcome. The project's separate summary is not edited by this form.
  </Accordion>
  <Accordion title="Does Current Phase move the project into that phase?">
    No. It only changes a label on the Client Dashboard. Manage the plan and ticket statuses separately.
  </Accordion>
  <Accordion title="Does this form save as I type?">
    No. Select Save Changes. Closing the dialog without saving discards its edits.
  </Accordion>
  <Accordion title="Does unchecking Hide from company users share everything?">
    No. Company users still need project access, and updates, milestones, deliverables, and documents have their own visibility controls.
  </Accordion>
  <Accordion title="Can I rename the project or change its status here?">
    No. This form edits the goal, description, phase label, health, and Company visibility. Use your PSA or the project's own workflow for the name, schedule, and status.
  </Accordion>
  <Accordion title="Where do I change the client sponsor?">
    Use the edit control in Client Dashboard's Contacts section, then Save Changes there. See [Manage project contacts](/user-guides/projects/manage-project-contacts).
  </Accordion>
</AccordionGroup>
