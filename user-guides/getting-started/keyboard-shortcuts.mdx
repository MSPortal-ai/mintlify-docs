**Audience:** Company users and MSP staff. Shortcuts do not grant access to a page or enable an action your role cannot perform.

Use the platform-specific key combinations listed below. A shortcut applies only where its corresponding control is available. Finish a pending edit before using a navigation shortcut.

## Portal navigation

| Action | Windows/Linux | Mac | Where it applies |
| --- | --- | --- | --- |
| Open or toggle Search | Ctrl+K | Option+K | Signed-in pages with the portal top bar, outside editable fields |
| Toggle the phone navigation sheet | Ctrl+B | Option+B | Phone layout, when using a hardware keyboard outside an editor |
| Move through Search results | Up / Down | Up / Down | While Search is open |
| Open the selected Search result | Enter | Enter | While a Search result is selected |
| Dismiss Search | Escape | Escape | While Search is open |

For the full search workflow, see [Find pages and records with Search](/user-guides/getting-started/universal-search). On desktop, tab into the sidebar to open it, then use **Keep sidebar expanded** beside the logo to dock it or **Collapse sidebar** to return to the icon rail. See the [sidebar branch preview](/user-guides/getting-started/customizing-the-sidebar#keep-the-desktop-sidebar-expanded). The desktop sidebar does not use Ctrl+B or Option+B.

## Editing and screen-specific controls

| Screen or control | Keys | What happens |
| --- | --- | --- |
| Home assistant message input | Enter | Sends the message when sending is available. |
| Home assistant message input | Shift+Enter | Adds a new line. |
| Budget editor | Ctrl+S / Command+S | Runs the budget Save action when enabled. Wait for validation and the save result. |
| Monthly Breakdown amount input | Enter or Tab | Leaves the field and submits a changed amount. |
| Monthly Breakdown amount input | Escape | Cancels the value currently being edited; it does not undo an earlier save. |
| Calendar grid | Left / Right | Moves to the previous or next displayed period. |
| Calendar grid | T | Returns to today. |
| Report builder | Ctrl+S / Command+S | Saves when the report's Save action is enabled. |
| Report builder | Ctrl+Z / Command+Z | Undoes an available report change. |
| Report builder | Ctrl+Y / Command+Y, or Ctrl+Shift+Z / Command+Shift+Z | Redoes an available report change. |

Calendar period shortcuts apply when you are not typing in an input, text area or editable text, and no dialog is open. They are not instructions to move a meeting. Use the visible calendar controls if focus is elsewhere.

## Work with forms and menus

- **Tab** and **Shift+Tab** move focus between available controls.
- Arrow keys move within controls that offer a selectable list, such as Search and dropdown menus.
- **Enter** activates the focused control or submits a form where that form supports it. Read the focused button before pressing it.
- **Escape** commonly closes the current menu or dialog. It does not universally clear filters, discard all changes or undo saved work.

Rich-text editors can provide formatting shortcuts. Outside editable fields, **Ctrl+B** on Windows/Linux or **Option+B** on Mac toggles the phone navigation sheet; desktop navigation uses the dock controls. Use the editor's visible toolbar if a key combination is handled by the browser or another control.

<Warning>
There is no universal **Ctrl/Command+Enter = Save and close** rule across the portal. Use the screen's labeled Save, Send, Apply or Confirm action unless that specific editor documents a shortcut. Saving, sending an AI message and sending an email are different actions.
</Warning>

## Troubleshooting

| Problem | What to check |
| --- | --- |
| A shortcut does nothing | Check the current screen, focused control, open dialogs, permissions and whether the corresponding button is enabled. |
| The browser handles the key combination | Use the visible app control. Browser, extension and operating-system shortcuts can take precedence. |
| A save shortcut was pressed but changes are missing | Check validation and the save result, then reopen the record. Pressing a key is not confirmation that the save succeeded. |
| Escape did not clear a filter | Use the table's visible clear-filter control. Escape is not a global filter reset. |
| Calendar arrows move the text cursor | Finish editing and move focus outside the text field before using period shortcuts. |

## FAQs

<AccordionGroup>
  <Accordion title="Can I open Search without a keyboard?">
    Yes. Select the Search magnifying glass in the portal top bar.
  </Accordion>
  <Accordion title="Does Ctrl+B make text bold everywhere?">
    No. Formatting shortcuts depend on the editor. The portal's sidebar shortcut applies to the phone navigation sheet outside editable fields; use the desktop dock control to keep navigation expanded.
  </Accordion>
  <Accordion title="Does Escape undo something I saved?">
    No. Escape affects the current editor, menu or dialog. It does not reverse a completed save or submission.
  </Accordion>
  <Accordion title="Can a shortcut bypass a disabled Save button?">
    No. Saving still depends on the screen's validation and permissions. Use the visible result to confirm success.
  </Accordion>
  <Accordion title="How do I write a longer Home assistant message?">
    Use Shift+Enter for a new line. Enter sends the message when sending is available.
  </Accordion>
  <Accordion title="Are these shortcuts available on every public or embedded page?">
    No. The relevant portal layout or editor must be present. Use the controls shown on that page.
  </Accordion>
</AccordionGroup>
