Use the keyboard to open Search, switch company, jump to a sidebar page, and save or send from forms. This page is for company users and MSP staff. A shortcut never grants access to a page or an action your role cannot perform.

## Before you start

- Two modifier keys are used throughout. **App** means **Option** on Mac and **Ctrl** on Windows and Linux. **Mod** means **Command** on Mac (Ctrl also works there) and **Ctrl** on Windows and Linux.
- App shortcuts do nothing while your cursor is in a text field, so they never interfere with typing.
- A shortcut only works where its button exists. If the button is disabled, the shortcut is too.

## See the shortcuts on a screen

<Steps>
  <Step title="Hold Option or Alt">
    Hold **Option** (Mac) or **Alt** (Windows and Linux) for about a second.
  </Step>
  <Step title="Read the badges">
    Small key badges appear next to every control on the screen that has a shortcut, including the numbered sidebar pages.
  </Step>
  <Step title="Release the key">
    Release **Option** or **Alt**, or press **Esc**, to hide the badges.
  </Step>
</Steps>

## Jump to a sidebar page by number

<Steps>
  <Step title="Show the numbers">
    On desktop, hold **Option** (Mac) or **Alt** (Windows and Linux) until the sidebar shows a number beside each page.
  </Step>
  <Step title="Type the number">
    While you still hold the key, type the number of the page you want. Type both digits for numbers above 9.
  </Step>
  <Step title="Release the key">
    Release **Option** or **Alt**. The page opens.
  </Step>
</Steps>

Inside the Settings window, hold **Shift** as well, so the keys are **Option+Shift+number** on Mac and **Alt+Shift+number** on Windows and Linux. Number shortcuts are not available on phones.

## Portal shortcuts

| Action | Windows and Linux | Mac | Where it works |
| --- | --- | --- | --- |
| Open or close Search | Ctrl+K | Option+K | Signed-in pages that show the top bar |
| Open the company selector and start typing | Ctrl+J | Option+J | MSP staff, and company users on a parent company |
| Open the filter panel | Ctrl+Shift+F | Option+Shift+F | Pages with a filter bar |
| Clear all active filters | Esc | Esc | Pages with a filter bar that has active filters, when no dialog is open |
| Start or end a voice conversation | Ctrl+Shift+Space | Option+Shift+Space | Assistant screens that show a voice button |
| Open or close the phone navigation sheet | Ctrl+B | Option+B | Phone layout with a hardware keyboard |
| Move through Search results | Up and Down | Up and Down | While Search is open |
| Open the selected Search result | Enter | Enter | While a result is selected |
| Close Search | Esc | Esc | While Search is open |

On desktop, the sidebar opens when you move the pointer into it or tab into it. Use **Keep sidebar expanded** beside the logo to dock it, and **Collapse sidebar** to return to the icon rail. See [Customize the sidebar](/user-guides/getting-started/customizing-the-sidebar#keep-the-desktop-sidebar-expanded). The desktop sidebar does not use Ctrl+B or Option+B.

For the full Search workflow, see [Find pages and records with Search](/user-guides/getting-started/universal-search).

## Save and send shortcuts

| Where | Windows and Linux | Mac | What happens |
| --- | --- | --- | --- |
| Any dialog with a form | Ctrl+Enter | Command+Enter | Submits the dialog's form when saving is available. |
| Ticket note composer | Ctrl+Enter | Command+Enter | Adds the note when it has content and the time entry is valid. |
| Budget header | Ctrl+S | Command+S | Runs the budget **Save** action when it is enabled. |
| Report builder | Ctrl+S | Command+S | Saves the report when **Save** is enabled. |
| Home assistant message box | Enter | Enter | Sends the message. |
| Home assistant message box | Shift+Enter | Shift+Enter | Adds a new line. |
| Monthly Breakdown amount | Enter or Tab | Enter or Tab | Leaves the field and saves a changed amount. |
| Monthly Breakdown amount | Esc | Esc | Cancels the edit in progress. It does not undo an earlier save. |

## Calendar and review shortcuts

| Where | Keys | What happens |
| --- | --- | --- |
| Calendar | Left and Right arrow | Moves to the previous or next day, week, or month. |
| Calendar | T | Jumps to today. |
| Compliance review list | Down arrow or J | Selects the next item while the review pane is open. |
| Compliance review list | Up arrow or K | Selects the previous item. |
| Compliance review list | Enter | Opens the full editor for the selected item. |
| Compliance review list | Esc | Closes the review pane. |
| Survey questions page | Ctrl+G (Option+G on Mac) | Creates goals from the selected questions or answers. |

Calendar and review keys work only when you are not typing in a field and no dialog is open.

## Rich text editors

In editors with a formatting toolbar, hover a toolbar button to see its shortcut. The common ones are **Mod+B** for bold, **Mod+I** for italic, **Mod+U** for underline, and **Mod+K** for a link.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A shortcut does nothing | Click outside any text field first. Then check that the button it belongs to exists and is enabled on this screen, and that no dialog is open. |
| The browser handles the key combination instead | Use the visible button. Browser, extension, and operating system shortcuts can take precedence. |
| Esc did not close or clear what I expected | Esc closes the current menu or dialog. On pages with a filter bar it also clears active filters. It does not undo a saved change. |
| Calendar arrows move the text cursor | Click outside the text field, then use the arrows. |
| I pressed a save shortcut and my changes are missing | Check the screen for a validation message, then reopen the record. Use the visible **Save** button to confirm. |
| Number badges are missing in the sidebar | Number shortcuts work on desktop only, and not while the Settings window or the account menu is open. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I open Search without a keyboard?">
    Yes. Click the Search control in the top bar.
  </Accordion>
  <Accordion title="Why is Search Option+K on Mac and not Command+K?">
    MSPortal uses Option on Mac for app actions, so they never take over Command shortcuts that your browser and editors use.
  </Accordion>
  <Accordion title="Does Ctrl+Enter save every form?">
    No. It submits forms inside dialogs and sends ticket notes. A full-page form needs its own **Save** button or a screen-specific shortcut from the tables above.
  </Accordion>
  <Accordion title="Can I change the shortcuts?">
    No. The shortcuts are fixed.
  </Accordion>
  <Accordion title="How do I write a longer message to the Home assistant?">
    Press Shift+Enter for a new line. Enter sends the message.
  </Accordion>
  <Accordion title="Do the shortcuts work on public or embedded pages?">
    Only where the same top bar, sidebar, or editor appears.
  </Accordion>
</AccordionGroup>
