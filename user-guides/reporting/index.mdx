The Reporting module lets you create professional reports by combining data blocks from across MSPortal.ai. Build QBR presentations, compliance summaries, budget forecasts, and more with the visual report builder.

## Accessing Reports

1. Click **Reporting** in the sidebar
2. The Reports tab lists reports available in your company scope and permissions. Templates, Scheduled, Approvals, Imports and Settings appear according to your access; provider-specific tabs also depend on connected integrations.


## Reports List

### Reports Table

The reports table displays:

| Column | Description |
|--------|-------------|
| **Report Title** | Name of the report |
| **Company** | Associated company |
| **Creator** | User who created the report |
| **Created** | Creation date |
| **Blocks** | Number of content blocks in the report |
| **Type** | Report category (Quarterly Report, etc.) |
| **Actions** | Edit, duplicate, delete options |

### Filtering and Search

- **Search** - Find reports by title
- **Filter** - Click the filter icon to narrow results
- **Sort** - Click column headers to sort

## Viewing a Report

Click any report to view its contents:


### Report Header

| Element | Description |
|---------|-------------|
| **Back** | Return to reports list |
| **Title** | Report name and company |
| **Date Range** | Data period covered |
| **Edit Report** | Open in report builder |
| **Print/Export PDF** | Generate PDF for sharing |

### Report Content

Reports display content blocks in a paginated format:
- **Text blocks** - Headings, paragraphs, AI-generated summaries
- **Data blocks** - Charts, tables, metrics from MSPortal modules
- **Branding** - Company logos and styling

## Creating a New Report

  </Step>

## Working with Pages

### Block Positioning

- **Drag and Drop** - Move blocks to position them
- **Resize** - Drag block edges to resize
- **Grid Alignment** - Enable grid for precise positioning
- **Split Across Pages** - Use supported block pagination or duplicate/configure blocks across pages; inspect each page for clipped or omitted rows

## Report Actions

### Saving Reports

- **Auto-save** - Eligible report changes save after a delay. Adding content can create the report before you press Save. Wait for the saved state; a new template requires its first manual save before template autosave applies.
- **Manual Save** - Press Ctrl+S (Cmd+S on Mac) or click Save
- **Version** - A version field is report metadata; do not assume it provides a restore-history feature.

## Best Practices

### Report Design

1. **Start with Purpose** - Define what the report should communicate
2. **Use Summaries** - Include AI-generated executive summaries
3. **Balance Content** - Mix charts, tables, and text
4. **Logical Flow** - Organize from overview to details

### Data Freshness

- Data blocks read available portal data for their configured company and period. Provider synchronization can lag, and generated narrative text is not automatically rewritten when the underlying data changes.
- Export PDFs to capture point-in-time snapshots
- Set appropriate date ranges for the reporting period

### Branding

- Upload company logo in Tenant Settings
- Review the selected logo/branding blocks and generated PDF rather than assuming every layout includes a logo
- Consistent branding across all exported PDFs

## Troubleshooting

### Blocks Not Loading

- Verify the company has data for the selected date range
- Check that integrations are connected and synced
- Refresh the page and try again

### Export Issues

- Ensure all blocks have finished loading
- Try a smaller date range for large reports
- Check browser pop-up settings for downloads

### Missing Data

- Verify date range includes relevant data
- Check company selection matches data source
- Ensure required modules are enabled


## Questions and troubleshooting

<AccordionGroup>
  <Accordion title="Why can I view reports but not see Templates or Imports?">
    Tabs depend on permissions. Templates require reporting write or manage access; Imports, Scheduled, Approvals and Settings require manage access. Provider tabs also depend on integrations.
  </Accordion>
  <Accordion title="Does adding a block save a new report?">
    It can. Report autosave starts once eligible content and company context exist. Do not treat a populated new report as an unsaved scratchpad; check the save state and report list.
  </Accordion>
  <Accordion title="Why did my new template not autosave?">
    A new template needs its first manual save. Existing eligible templates can then autosave changes. Wait for success and reopen it to verify the saved content.
  </Accordion>
  <Accordion title="Is the report version field an undo history?">
    Do not assume so. The version value is metadata. Use the editor’s supported undo controls for the current editing session and retain an intended copy before substantial revisions.
  </Accordion>
  <Accordion title="Does changing the reporting period rewrite AI narrative?">
    No. Data blocks and generated text are different. Review or regenerate narrative deliberately and confirm that its claims match the selected period and available data.
  </Accordion>
  <Accordion title="Does a shared report link grant client access?">
    No. The recipient must already have the required portal and company access. A downloaded PDF is a separate copy whose audience you must choose when sharing.
  </Accordion>
  <Accordion title="Why is an exported block missing rows?">
    Check its filters, date range, row limit, pagination and available page space. A successful PDF download does not establish that every source record fits.
  </Accordion>
  <Accordion title="What should I check before sharing a PDF?">
    Wait for blocks to load, verify company scope and period, inspect every exported page for clipping or empty data, and review narrative and branding. Confirm the intended recipient before sending.
  </Accordion>
</AccordionGroup>
