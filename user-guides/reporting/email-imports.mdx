The **Imports** tab on the **Reporting** page stores files that arrive by email or upload: insurance binders, vendor quotes, signed agreements, exported PDFs and tool reports. Each company has its own import address, and you can sort the files into folders. Once imported, a file can be shown in a report with the **Imported Document** or **PDF Viewer** block. This guide is for MSP staff.

## Before you start

- You need **Manage** access to Reporting to see the **Imports** tab. **Write** or **Manage** lets you upload, move and delete files and manage folders.
- Imports follow the company selector. With one company selected you see only its files. With several or **Global View** you see a rail with a section for each company.
- Each company has an import address on `inbox.msportal.ai`. Copy the current address from MSPortal rather than typing it. See [Find a company's import address](#find-a-companys-import-address).

## Open Imports

<Steps>
  <Step title="Open Reporting">
    Click **Reporting** in the main navigation.
  </Step>
  <Step title="Click Imports">
    Click the **Imports** tab at the top of the page.
  </Step>
  <Step title="Choose the scope">
    Use the company selector to pick a company. The rail on the left shows **All files**, then each company with its folders. Click a folder to filter the table to it.
  </Step>
</Steps>

## Find a company's import address

<Steps>
  <Step title="Open Settings > Email">
    Go to **Settings > Email** and click the **Receiving** tab. **Receiving Addresses** lists every company with its address and an **Active** or **Inactive** status.
  </Step>
  <Step title="Copy the address">
    Click **Copy address** on the company's row.
  </Step>
</Steps>

You can also copy a folder's full address from the **...** menu next to the folder in the Imports rail (**Copy email address**). The **Export email addresses (Excel)** button on the Imports tab downloads a spreadsheet of every company's address. On the Receiving tab you can deactivate an address, or regenerate it. A regenerated address replaces the old one, so update any forwarding rules. See [Email settings](/user-guides/settings/email).

An address looks like this, where `acme123` is the company's import code.

```
acme123@inbox.msportal.ai
```

A file emailed to that address lands in that company's **Unfiled** area. MSPortal does not check who the sender is, so keep addresses private and use them only in rules you control.

## Send files in by email

<Steps>
  <Step title="Pick the address">
    Use the company's address, or a folder address from the next section.
  </Step>
  <Step title="Attach the files">
    Attach PDF, Word (.docx), Excel (.xls or .xlsx) or CSV files. Each accepted attachment becomes its own import.
  </Step>
  <Step title="Send the email">
    The `From` address, subject and time are saved with each file.
  </Step>
  <Step title="Wait for Completed">
    New files show **Pending** or **Processing**. When the status reads **Completed** you can open or download the file. **Failed** means it could not be stored.
  </Step>
</Steps>

An email with no accepted attachment is saved as one **Email Body** document. Other file types, such as images or text files, are not imported by email. Use a PDF if you need the message in an exact layout.

## Route a file into a folder with plus-addressing

Add `+folder-slug` after the import code to send the file straight into a folder.

```
acme123+invoices@inbox.msportal.ai      lands in the "Invoices" folder
acme123+contracts@inbox.msportal.ai     lands in the "Contracts" folder
acme123+vendor-quotes@inbox.msportal.ai lands in the "Vendor Quotes" folder
```

This is standard plus-addressing. Mail still goes to `acme123@inbox.msportal.ai`, and MSPortal reads the `+vendor-quotes` part.

If the slug does not match a folder, MSPortal creates a global folder from it, and files the email there. So `acme123+vendor-quotes@inbox.msportal.ai` creates a **Vendor Quotes** folder for every company the first time it is used. Later emails with that tag reuse it. Check the slug for typos, since a typo makes a new folder.

## Create a folder

### A folder for one company

<Steps>
  <Step title="Click + beside the company">
    In the rail, click the **+** button next to the company name. Its tooltip reads **New folder in** and the company name.
  </Step>
  <Step title="Name the folder">
    Type a **Folder name**, for example `Invoices`. The name sets the folder's email slug.
  </Step>
  <Step title="Click Create">
    Leave **Apply to all companies** clear. The folder appears under that company only.
  </Step>
</Steps>

### A folder for every company

<Steps>
  <Step title="Click New Global Folder +">
    Click the folder-plus button at the top of the rail. Its tooltip reads **New Global Folder +**. The dialog opens with **Apply to all companies** ticked. You can also tick that box when creating a folder from any company.
  </Step>
  <Step title="Name the folder">
    For example **Invoices** or **Contracts**.
  </Step>
  <Step title="Click Create">
    The folder now exists under every company. Each company gets its own address for it, such as `acme123+invoices@inbox.msportal.ai` and `globex456+invoices@inbox.msportal.ai`. Each company sees only its own files.
  </Step>
</Steps>

Use global folders when every client should have the same layout. Use a company folder for a one-off category.

## Manage folders

Open the **...** menu next to a folder in the rail.

| Action | What it does |
| --- | --- |
| **Copy email address** | Copies the folder's full address, for forwarding rules. |
| **New subfolder** | Creates a child folder. It inherits its parent's scope, so a subfolder of a global folder is global. |
| **Rename** | Changes the folder name and its email slug. Existing files stay put. Update any forwarding rules to the new address. |
| **Move folder...** | Moves the folder under another one. Parent and child must have the same scope. |
| **Delete** | Deletes the folder and its subfolders. Files inside become unfiled. The files themselves are not deleted. |

## Upload and organize files

<Steps>
  <Step title="Select a company folder">
    Click a company or one of its folders in the rail. Uploading needs a company selected.
  </Step>
  <Step title="Upload">
    Click **Upload** and choose files, or drag files onto the page or onto a folder in the rail. Files can be PDF, DOCX, XLS, XLSX or CSV, up to 50 MB each.
  </Step>
  <Step title="Move files">
    Tick files and click **Move to folder...**, pick a destination and click **Move here**. You can also drag one file onto a folder in the rail.
  </Step>
</Steps>

The table shows **File**, **Company**, **Type**, **From**, **Subject**, **Size**, **Status** and **Received**. Click a completed file's name to preview it. PDFs, Word files, spreadsheets, CSV files and email bodies show inline. If a file cannot be previewed, download it. Open a row's **...** menu for **View**, **Download**, **Move to folder...** and **Delete**.

Tick rows to get a bar with **N selected**, **Move to folder...**, **Download**, **Delete** and **Clear**. **Download** counts only completed files. **Delete** asks you to confirm and removes the files from storage for good.

## Common setups

### Collect client invoices

<Steps>
  <Step title="Create the folder">
    Create a global folder named **Invoices**.
  </Step>
  <Step title="Copy each address">
    Copy the folder address for each client, for example `acme123+invoices@inbox.msportal.ai`.
  </Step>
  <Step title="Send it to the client">
    Ask them to email or forward invoices to it.
  </Step>
</Steps>

### Route signed agreements

<Steps>
  <Step title="Create the folder">
    Create a global folder named **Signed Agreements**.
  </Step>
  <Step title="Set the completion email">
    In your e-signature tool, set the completion email recipient to the client's folder address.
  </Step>
</Steps>

### Use a new tag without setup

Email a new tag such as `+security-reports`. MSPortal creates a **Security Reports** global folder the first time and reuses it after that.

For forwarding rules, Outlook can forward mail that matches a rule to the folder address. Gmail can do the same with a filter.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A file never arrived | Check the company's address on **Settings > Email > Receiving**. It must be **Active** and spelled exactly. Mail must go to `inbox.msportal.ai`. Then look at the Imports table for a **Failed** status. |
| A file landed in a folder you did not expect | The `+slug` did not match your folder, so a new global folder was created from it. Check for typos. Slugs are lowercase with hyphens. |
| A file is stuck on **Pending** or **Processing** | Wait for **Completed**. You cannot open or download it before then. |
| A rename broke a forwarding rule | A rename changes the slug. Copy the new address and update the rule. |
| An image or text attachment did not import | Email imports accept only PDF, DOCX, XLS, XLSX and CSV. Convert the file or attach a PDF. |
| You cannot upload | Select a company or folder first. Files must be PDF, DOCX, XLS, XLSX or CSV and up to 50 MB. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does a global folder mix companies' files?">
    No. It shares the folder name only. Each file stays with its company.
  </Accordion>
  <Accordion title="Can a message without attachments be imported?">
    Yes. It is saved as an **Email Body** document.
  </Accordion>
  <Accordion title="Does deleting a folder delete its files?">
    No. Files become unfiled. Deleting an import is separate and removes the file from storage.
  </Accordion>
  <Accordion title="Does Download produce one combined report?">
    No. It downloads each completed file on its own.
  </Accordion>
  <Accordion title="Can the address change?">
    Yes. Regenerating it on **Settings > Email > Receiving** replaces the old one. Folder renames change folder addresses too.
  </Accordion>
  <Accordion title="Can a Company user send files to their company's address?">
    MSPortal does not check the sender, so anyone who has the address can send to it. Share it only with people you trust.
  </Accordion>
  <Accordion title="How do I use an imported file in a report?">
    Add the **Imported Document** or **PDF Viewer** block in the report builder and choose the file.
  </Accordion>
</AccordionGroup>
