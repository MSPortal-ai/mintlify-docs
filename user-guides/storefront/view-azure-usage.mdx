Use **Storefront > Azure Usage** to see Azure consumption imported from Pax8. This page is for company users and MSP staff. It is a report. It does not change Azure or stop spending.

## Before you start

- Your MSP must have Pax8 connected in **Settings > Integrations**. Without it, the **Azure Usage** tab does not appear.
- You need Storefront read access. In the role editor this is the **Storefront** resource with **Read** access.
- Costs and prices show only for MSP staff with **Manage** access to the **Storefront** resource.
- The view covers the current month and the two months before it.

## Find usage

<Steps>
  <Step title="Open Storefront > Azure Usage">
    Click **Storefront** in the sidebar, then click the **Azure Usage** tab.
  </Step>
  <Step title="Pick the company">
    Use the company selector in the top bar. With several companies selected, a **Company** column and filter appear.
  </Step>
  <Step title="Pick a month">
    Open the filter under the **Month** column heading and choose a month.
  </Step>
  <Step title="Find a resource group">
    Type in the filter under the **Resource Group** column heading.
  </Step>
  <Step title="Read the rows">
    Each row is one resource group in one month. The table shows 25 rows per page. Use the page controls under the table to see more.
  </Step>
</Steps>

If there is no data, the page reads **No Azure Usage Data** and explains that usage appears once Azure subscriptions have synced from Pax8.

## Read the usage lines

<Steps>
  <Step title="Open a row">
    Click a row, or click the eye button on it.
  </Step>
  <Step title="Read the Usage Line Items dialog">
    The dialog shows the month, company, and resource group. Each line shows **Product**, **Date**, **Qty**, and the unit. MSP staff with **Manage** access also see **Unit Price** and **Total**.
  </Step>
  <Step title="Check the units">
    Read the unit before you compare quantities. Different resource types use different units.
  </Step>
</Steps>

## Read the summary

Cards above the table show **Companies** (when several companies are selected) and **Resource Groups**. MSP staff with **Manage** access also see an MSP cost total per currency.

The cards follow the company selector. They do not follow the table filters.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The **Azure Usage** tab is missing | Pax8 is not connected. Ask your MSP. |
| You see **No Azure Usage Data** | No Azure subscriptions have synced from Pax8 for this scope. Check the company selector, then ask your MSP. |
| The usage lines do not load | The detail lookup can fail on its own. Close the dialog and try again, then ask your MSP. |
| A month is missing | The view covers only the last three months. |
| Costs are missing | Only MSP staff with **Manage** access see costs. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I reduce Azure usage or delete a resource here?">
    No. This is a report. Your MSP makes changes in Azure.
  </Accordion>
  <Accordion title="Why can my MSP see costs that I cannot?">
    Costs and prices need **Manage** access to the **Storefront** resource.
  </Accordion>
  <Accordion title="Does this replace my invoice?">
    No. Check your MSP's invoice or the Pax8 statement for billed amounts.
  </Accordion>
  <Accordion title="Can I export this table?">
    No. This table has no export. Ask your MSP for a Pax8 report.
  </Accordion>
</AccordionGroup>
