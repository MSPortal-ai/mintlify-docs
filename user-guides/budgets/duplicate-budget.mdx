Use **Duplicate** to copy a budget and all its lines into a new Draft for the same company. Use it to start next year's plan, or to replace an Approved budget that is locked. This guide is for MSP staff and for company users whose MSP has given them budget write access.

## Before you start

- You need the **write_budgets** or **manage_budgets** permission. The **Duplicate** item is missing from the row menu without it.
- Any budget can be duplicated, including Approved and Archived budgets.
- The copy is created and saved the moment you click **Duplicate**. There is no preview.

## Create the copy

<Steps>
  <Step title="Find the source budget">
    Click **Budgets** and [find the budget](/user-guides/budgets/find-budgets). Check its company, title, fiscal year and status.
  </Step>
  <Step title="Click Duplicate">
    Click **...** at the end of its row, then click **Duplicate** once.

    <Frame caption="Duplicate sits in the row menu between Update Statuses and Export.">
      <img src="/images/product/budget-row-actions.png" alt="Budget row menu with View, Edit, Update Statuses, Duplicate, Export and Delete." width="322" height="422" />
    </Frame>
  </Step>
  <Step title="Wait for the editor">
    A **Budget duplicated successfully** message appears and the new budget opens in the editor.
  </Step>
  <Step title="Rename the copy">
    Open **Budget Details**. The title starts with **Copy of** and the status is **Draft**. Change the title so you can tell the plans apart.
  </Step>
  <Step title="Set the year">
    The **Fiscal Year** is the same as the source. Change it to the year you are planning.
  </Step>
  <Step title="Review every line">
    Check each line and open **Monthly Breakdown** from **View** to review the schedule. All copied lines start with **Pending** status, including lines that were Approved or Rejected in the source. Set each line's status again.
  </Step>
  <Step title="Save">
    Click **Save** to store your edits. The copy already exists. Closing the editor does not remove it.
  </Step>
</Steps>

## What is copied

| Information | Result in the copy |
| --- | --- |
| Company | The same company. Duplicate cannot move a plan to another company. |
| Fiscal year, period type, currency | The source values. |
| Notes and author | Copied. Update them if they describe the old plan. Notes appear in exports. |
| Descriptions, quantities, unit prices, line notes | Copied. |
| Recurrence, start month, custom interval, term | Copied. |
| Monthly overrides | Copied. Review them in **Monthly Breakdown**. |
| Categories and section order | Copied. |
| Links to Planner items, goals and products | Copied. Duplicate does not create new Planner items or products. |
| Budget status | **Draft**. |
| Line statuses | **Pending** on every line. |

The copy is a separate budget. Editing it does not change the source, and the two never sync. To plan for a different company, [create a new budget](/user-guides/budgets/create-and-edit-budgets) in that company.

## Replace a locked budget

An Approved or Archived budget cannot be unlocked. Duplicate it, review and edit the Draft, then approve the copy when it is ready. See [Approve and lock a budget](/user-guides/budgets/approving-and-locking-budgets). The copy does not carry the original's Actuals. It needs its own approval.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Duplicate** is missing from the row menu | Ask your MSP admin for budget write access. |
| **Failed to create duplicate budget** or **Failed to copy budget line items** | Go back to the list and check whether a copy was created. If it is missing lines, delete it and try again. |
| You do not want the copy | [Delete the Draft](/user-guides/budgets/delete-budgets). Leaving the editor does not remove it. |
| The copy shows the wrong year | Change **Fiscal Year** under **Budget Details** and save. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Is the copy saved before I click Save?">
    Yes. **Duplicate** creates it right away. **Save** is only for your later edits.
  </Accordion>
  <Accordion title="Does Duplicate change the original?">
    No. It creates a separate budget.
  </Accordion>
  <Accordion title="Does Duplicate advance the fiscal year?">
    No. Set the year yourself.
  </Accordion>
  <Accordion title="Are Approved and Rejected line statuses copied?">
    No. Every copied line starts Pending.
  </Accordion>
  <Accordion title="Does copying reset monthly overrides?">
    No. Saved overrides come along with the schedule.
  </Accordion>
  <Accordion title="Can I copy a budget into another company?">
    No. The copy stays in the same company.
  </Accordion>
</AccordionGroup>
