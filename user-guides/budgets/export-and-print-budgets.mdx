Use this guide to get a budget out of MSPortal as a PDF, an Excel workbook or a printout. It is for MSP staff and for company users whose MSP has given them budget access. Exporting does not approve a budget.

## Before you start

- You need budget read access to export or print a single budget.
- Selecting several budgets needs the **manage_budgets** permission, because the row checkboxes only appear with it.
- Exports use the saved budget. Save edits first.

## What each output contains

| Action | You get | Not included |
| --- | --- | --- |
| **Export PDF** | A landscape letter document with the budget details, notes, **Total**, **Approved** and **Pending** amounts, and lines by category with **Billing**, **Qty**, **Unit Price**, **Total** and **Status**. | Monthly Breakdown, Actuals, line notes, unsaved changes. |
| **Export Excel** | A `.xlsx` file with one **Budget** sheet. It has the details, totals, budget notes, and lines by category with **Qty**, **Unit Price**, **Recurrence**, **Term**, **Status** and **Line Total**, plus line notes. | Monthly schedule, start month, monthly overrides, formulas. |
| **Print** | The browser print preview of the tab you have open. | Nothing is saved. |
| **Export Selected** | One PDF that joins the selected budgets for one company. | Excel output, a combined total. |

## Download one budget from Budget Details

<Steps>
  <Step title="Open the budget">
    Click **Budgets**, click **...** on the budget's row, then click **View**. Check the title, fiscal year, currency and status.
  </Step>
  <Step title="Open the page menu">
    Click the **...** button in the page header.

    <img src="/images/product/budget-export-actions.png" alt="Budget header menu offering Help, Section order, Print, Export PDF and Export Excel." width="384" height="358" />
  </Step>
  <Step title="Choose a format">
    Click **Export PDF** or **Export Excel**. Keep the page open while the file is prepared. Your browser downloads it.
  </Step>
  <Step title="Check the file">
    Open the file and check the budget name, company, year, amounts, statuses and notes.
  </Step>
</Steps>

The menu works the same on every tab. Choosing **Export PDF** while **Monthly Breakdown** or **Actuals** is open still gives the budget document, not that tab.

## Download from the list or the editor

- **From the list.** Click **...** on a budget's row, then click **Export**. You get a PDF named `budgets.pdf`. This works in Global View too.
- **From the editor.** Open the budget with **Edit**, then click **Export** and choose **Export PDF** or **Export Excel**. A budget you have not saved yet cannot be exported. Save it first.

## Print the current tab

<Steps>
  <Step title="Open the tab you want">
    Open **Overview**, **Monthly Breakdown** or **Actuals** in **Budget Details**.
  </Step>
  <Step title="Click Print">
    Click **...** in the page header, then **Print**. The browser print preview opens. **Monthly Breakdown** prints on a landscape letter page and the other tabs on a portrait letter page.
  </Step>
  <Step title="Check the preview">
    Look at every page, column and total. Choose a printer or **Save as PDF**, then print.
  </Step>
</Steps>

## Combine selected budgets into one PDF

<Steps>
  <Step title="Choose one company">
    Select a single company in the top bar. In Global View the action stops with the message **Select a company first to export budgets**.
  </Step>
  <Step title="Tick the budgets">
    Tick the checkbox on each budget row. Check the count and the titles, because filters can hide selected rows.
  </Step>
  <Step title="Open the actions menu">
    Click the menu button above the table. It shows the selected count and currently reads **Filter (count)**.
  </Step>
  <Step title="Click Export Selected">
    Your browser downloads `budgets.pdf`.
  </Step>
  <Step title="Check the PDF">
    Make sure every selected budget is in the file. If one budget could not be generated, the others are still joined and the missing one is left out without a warning. Export a missing budget by itself.
  </Step>
</Steps>

Each budget in the combined PDF keeps its own amounts and status. The file is not a merged budget.

## Read exported amounts

- A line amount is quantity times unit price. The **Total** includes rejected lines. The list's **Total** leaves them out.
- A recurring line with quantity 1 and price 100 shows 100. Its yearly cost can be higher. Use [Monthly Breakdown](/user-guides/budgets/read-monthly-breakdown) for the schedule.
- Budget notes appear in both the PDF and the Excel file, so write notes for everyone who can open the budget. The notes help text in the editor says notes are not shown on exports. That text is wrong.
- Line notes appear in Excel only.
- Excel amounts are fixed values. Changing a number in the file does not recalculate the totals or change MSPortal.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Recent edits are missing from the file | Save the budget, wait for the saved message, and export again. |
| **Export** in the editor does nothing | The budget is new. Save it once, then export. |
| No file downloads | Check your browser's download settings and any error message, then try again. |
| **Select a company first to export budgets** appears | Pick one company in the top bar and select the budgets again. |
| The selected-budgets menu is missing | Row checkboxes need **manage_budgets**. Export each budget from its **View** page instead. |
| A combined PDF is missing a budget | Export that budget by itself. |
| The total differs from the list or Monthly Breakdown | The file counts rejected lines and does not apply recurrence. Compare the same measure. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where can a company user download a budget?">
    Open **Budgets**, click **...** then **View** on the row, then click **...** in the page header and choose **Export PDF** or **Export Excel**.
  </Accordion>
  <Accordion title="Does exporting save my edits?">
    No. Exports read the saved budget. Save first.
  </Accordion>
  <Accordion title="Does the Excel file include a monthly schedule?">
    No. It has one **Budget** sheet with line items and fixed totals. It has no month columns or overrides.
  </Accordion>
  <Accordion title="What is the difference between Print and Export PDF?">
    **Print** uses the open tab and your browser's print layout. **Export PDF** builds a separate document from the saved budget.
  </Accordion>
  <Accordion title="Can I use the Excel export as an import file?">
    Yes, for line items. See [Import budget line items from Excel](/user-guides/budgets/import-excel). Check each line's start month afterward, because the file does not carry it.
  </Accordion>
  <Accordion title="Does exporting approve a budget?">
    No. Exports and printing change nothing. Approval is a separate step for people with **manage_budgets**.
  </Accordion>
</AccordionGroup>
