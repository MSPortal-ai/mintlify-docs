title: "Import and link budget products from integrations"

Use **Import from Integrations** to turn products your connected PSA or other integrations have already synced into MSPortal into budget catalog products. You can create a new product or link the source to a product you already have. This guide is for MSP staff with budget write access. Company users cannot read the integration product list. They should ask their MSP to import or link products for them, even if the button is visible.

This does not place an order or change a product in the provider. The list only holds products your integration has synced. Connecting an integration does not guarantee there are products to import.

## Before you start

- You need the **write_budgets** or **manage_budgets** permission and an MSP staff account.
- An integration with a finished product sync.
- The list covers the whole MSP. Selecting a company in the top bar does not filter it.

## Create new catalog products

<Steps>
  <Step title="Open the import">
    Click **Budgets**, then **Budgets Menu**, then **Products**. Click **Import from Integrations**. The **Import Products from Integrations** dialog opens.
  </Step>
  <Step title="Find the source products">
    Type in **Search products...** to match names, SKUs and categories. Click **Show Unimported Only** to hide products already linked to a budget product. The button changes to **Show All**. The dialog loads 50 products per page.
  </Step>
  <Step title="Tick the products">
    Tick each product to import. The header box selects every unimported row on the current page. Work one page at a time, and keep the same search and filter until you finish. Rows that are already imported are disabled and show their linked product.
  </Step>
  <Step title="Keep Create New">
    A ticked row shows **Create New** in the **Linked Product** column. Keep it to make a separate catalog product.
  </Step>
  <Step title="Import">
    Click **Import Selected (N)**. A message such as **Successfully imported 3 products.** appears. The products are saved at once.
  </Step>
  <Step title="Check the new products">
    Open the Products page and check the price, category and recurrence before you use a product in a budget. A source with no price makes a zero-price product.
  </Step>
</Steps>

The table shows **Name**, **SKU**, **Category**, **Price** and **Linked Product**. A dash in **Price** means the price is missing or zero.

New products take the source name, SKU, category, vendor, price, group and company where the source has them. The recurrence comes from the synced billing period. A semiannual period becomes Custom every 6 months. A source with no clear period becomes Monthly if it is flagged as recurring, and One-time if not. A source setup price and unit are kept with the product. Check the result instead of assuming the provider data is complete.

## Link a source to an existing product

<Steps>
  <Step title="Tick the source row">
    Tick an unimported source product.
  </Step>
  <Step title="Open the link list">
    Click **Create New** in that row's **Linked Product** column.
  </Step>
  <Step title="Pick the existing product">
    Search and pick the budget product. Only products without an integration link are listed.
  </Step>
  <Step title="Import">
    Click **Import Selected (N)**. Then reopen the dialog with **Show All** to see the link.
  </Step>
</Steps>

Linking attaches the source reference to your product. It does not copy the provider's name, price, category or recurrence onto it. Edit the product yourself if those need to change. See [Create and edit budget products](/user-guides/budgets/manage-products). Pick each existing product for only one source row in a batch.

## Selection limits

<Note>
Import one loaded page at a time. If you change the page, the search or **Show Unimported Only**, the button count can still include earlier ticks. To start clean, click **Cancel**, reopen the dialog and tick the products again.
</Note>

The header checkbox selects the unimported rows on the current page only. **Cancel** closes the dialog and clears the ticks.

An error can happen after some links are already saved. Reopen the dialog and see which products are now linked before you retry. There is no way to unlink a product in this dialog.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **No products found.** | Check that the integration has finished its product sync, and clear the search. |
| **Failed to load products** | Close the dialog and try again. |
| **None of the selected products can be imported.** | Reopen the dialog and tick unimported rows again. |
| **Failed to import products** | Reopen the dialog and check which products are linked before you retry. |
| A row is disabled | It is already linked to a budget product. Click **Show All** to see which one. |
| The button is visible but nothing loads (company user) | Integration products are for MSP staff only. Ask your MSP. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does selecting a company filter the picker?">
    No. The picker reads the MSP's whole integration catalog. Check each product's company before you import.
  </Accordion>
  <Accordion title="What is the difference between Create New and linking?">
    **Create New** makes a new catalog product from the source. Linking attaches the source to a product you already have and leaves its fields alone.
  </Accordion>
  <Accordion title="Does linking update the product's price?">
    No. Edit the product separately.
  </Accordion>
  <Accordion title="Can I select across several pages?">
    No. Import one page at a time.
  </Accordion>
  <Accordion title="Does importing change my provider?">
    No. It only creates or links MSPortal catalog records.
  </Accordion>
</AccordionGroup>
