title: "Create budget products from Planner"

Use **Import from Planner** on the Products page to turn Planner cost estimates into reusable catalog products. This is different from adding a Planner item's costs straight to a budget, and from syncing a forecast. It is for MSP staff and for company users whose MSP has given them budget write access.

## Before you start

- You need the **write_budgets** or **manage_budgets** permission.
- Pick the company in the top bar first, so similar plans from different clients are easy to tell apart.
- The Planner item needs a cost estimate above zero.

## Import Planner items as products

<Steps>
  <Step title="Open Products">
    Click **Budgets**, then **Budgets Menu**, then **Products**.
  </Step>
  <Step title="Click Import from Planner">
    Click **Import from Planner** at the top right. The **Import Products from Planner** dialog opens.
  </Step>
  <Step title="Find the item">
    Type in **Search planner items...** to match a title or category. The table shows **Title**, **Category**, **Cost**, **Recurrence** and **Due**.
  </Step>
  <Step title="Tick the items">
    Tick each item you want, or tick the header box to select every item in the current list. Check the count on the button. Searching can hide ticked items without unticking them, so clear any you do not want before you import.
  </Step>
  <Step title="Import">
    Click **Import Selected (N)**. A message such as **Imported 2 products from planner.** appears. The products are saved at once. There is no page-level **Save**.
  </Step>
  <Step title="Check the catalog">
    The new products appear on the Products page. Check the names, categories, prices and recurrence.
  </Step>
</Steps>

## Which Planner items appear

The list shows Planner items you can access that have a cost estimate above zero. It leaves out archived items, Cancelled items and items that already have a linked product. Completed items can appear. It does not depend on a fiscal year, and an item does not need a due date.

If an item is missing, check the company, its cost estimate, its archived or Cancelled status, and whether it was imported before. If the dialog says **No planner items available to import.** after an error, do not assume there are none. Close it and try again.

## What the product contains

| Planner item | Product |
| --- | --- |
| Title | Name |
| Category | Category |
| Description | Description |
| Cost estimate | Unit Price |
| Cost type (one-time, monthly or annual) | Recurrence |
| Company | Company. An item with no company makes a shared product. |

The import does not split a Planner item's separate cost lines into several products, and it does not copy the due date into a billing schedule. The product is linked to the Planner item so the same item cannot be imported twice. It is not kept in sync. If the estimate changes, edit the product yourself.

## Add the cost to a budget

Importing here makes reusable products. It does not add budget lines. To put a cost in a budget, use the **Products & Services** panel in the budget editor. See [Add Planner, goal and product costs to a budget](/user-guides/budgets/import-planning-and-products). For yearly projections, see [Sync a forecast](/user-guides/budgets/sync-budget-forecast).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A Planner item is missing | Check the company, a cost estimate above zero, archived or Cancelled status, and whether it was already imported. |
| **Failed to import from planner.** | Try again. Ask your MSP admin if it keeps failing. |
| The count looks wrong after a search | Ticked items stay ticked when hidden. Clear the ones you do not want. |
| A product has the wrong price | Edit it. See [Create and edit budget products](/user-guides/budgets/manage-products). |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can Completed Planner items become products?">
    Yes, if the estimate is above zero. Archived and Cancelled items cannot.
  </Accordion>
  <Accordion title="Does this split a Planner item's separate costs?">
    No. It uses the overall estimate and cost type. Use the budget editor's Planner panel for separate cost lines.
  </Accordion>
  <Accordion title="Do I need to save the Products page?">
    No. **Import Selected** saves at once.
  </Accordion>
  <Accordion title="Does a changed Planner estimate update the product?">
    No. Edit the product when the price changes.
  </Accordion>
</AccordionGroup>
