Use the checkboxes on the Products page to change or delete several budget products at once. Changes save right away and can affect shared products. This guide is for MSP staff, and for company users whose MSP has given them budget write access.

## Before you start

- You need the **write_budgets** or **manage_budgets** permission.
- Open **Budgets > Budgets Menu > Products** and check the company in the top bar. See [Find and understand budget products](/user-guides/budgets/read-product-catalog).
- Selection works on one page at a time. Changing page clears it.

## Update several products

<Steps>
  <Step title="Tick the products">
    Tick the checkbox on each product you want to change. Check the names before you go on.
  </Step>
  <Step title="Open Bulk Edit">
    Click the **Actions (N Selected)** button above the table, then click **Bulk Edit**. The **Bulk Edit Products** dialog opens.
  </Step>
  <Step title="Choose the fields to change">
    Tick the checkbox next to each field you want to change, then fill it in. Fields you leave unticked stay as they are.
  </Step>
  <Step title="Click Update Products">
    Click **Update Products**. It stays unavailable until you tick at least one field. A message such as **Updated 3 products** appears.
  </Step>
  <Step title="Check the results">
    If a message says **Updated 2 of 3 products. 1 product could not be updated.**, some rows changed and some did not. Check each product.
  </Step>
</Steps>

| Field | What you can do |
| --- | --- |
| **Category** | Pick a category from the list. A blank pick changes nothing. |
| **Vendor** | Pick from the vendors already on the selected products. To use a new vendor, use **Edit** on one product. |
| **Product Group** | Pick from the groups already on the selected products. The dialog cannot create a group. |
| **Unit Price** | Type a price of zero or more. Blank changes nothing. |
| **Description** | Type the new text. Tick the box and leave it blank to clear the descriptions. |

Bulk Edit cannot change names, SKUs, recurrence or company. Use [Create and edit budget products](/user-guides/budgets/manage-products) for those.

## Delete one product

<Steps>
  <Step title="Open the row menu">
    Click **...** at the end of the product's row, then click **Delete**.
  </Step>
  <Step title="Read the confirmation">
    It reads **Delete Product Name?** and says budgets that use the product keep their existing numbers.
  </Step>
  <Step title="Confirm">
    Click **Delete**. The row shows **Deleted** with a short **Undo** countdown. After it ends, the product is gone from the catalog.
  </Step>
</Steps>

Deleting removes only the catalog entry. It does not remove costs already copied into budgets, and it does not delete the product in your provider.

## Delete several products

<Steps>
  <Step title="Tick the products">
    Tick the checkbox on each product to delete.
  </Step>
  <Step title="Choose Delete Selected">
    Click **Actions (N Selected)**, then **Delete Selected**.
  </Step>
  <Step title="Check the list">
    The dialog asks **Delete N products?**, names up to five of them, and adds **and N more** for the rest. It says the delete is permanent.
  </Step>
  <Step title="Confirm">
    Click **Delete N products**. A message such as **Deleted 3 products** appears. If only some were deleted, it says how many could not be.
  </Step>
</Steps>

Look at the list afterward. A bulk delete can finish for some products and fail for others.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Update Products** is unavailable | Tick at least one field to change. |
| **Updated 2 of 3 products** | Check which product kept its old values and try again for it. |
| **No products were deleted. Try again.** | Nothing was removed. Try again, and ask your MSP admin if it keeps failing. |
| The selection disappeared | Changing page or company clears it. Tick the rows again. |
| A vendor or group you need is not in the list | The list only holds values already on the selected products. Use **Edit** on one product for a new vendor. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where can I change several prices at once?">
    Tick the products on one page, click **Actions (N Selected) > Bulk Edit**, tick **Unit Price**, enter the amount, and click **Update Products**.
  </Accordion>
  <Accordion title="Will Bulk Edit change fields I leave unticked?">
    No. Only ticked fields are sent.
  </Accordion>
  <Accordion title="Can I clear a category, vendor or group with a blank value?">
    No. Blank values for those fields are ignored. Only **Description** can be cleared.
  </Accordion>
  <Accordion title="Can I change recurrence for many products?">
    No. Edit each product to change its recurrence.
  </Accordion>
  <Accordion title="Does deleting a product change my budgets?">
    No. Budget lines keep their copied numbers.
  </Accordion>
</AccordionGroup>
