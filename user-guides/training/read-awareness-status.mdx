This guide is for company users and MSP staff who need to see who has finished security awareness training and how people did on phishing tests. The table shows imported results from Breach Secure Now, Phin, Huntress, CyberHoot, and Phished.io.

## Before you start

- You need Security Awareness read access for the companies you select.
- Your MSP must connect each provider and map its customers to companies. See [Security awareness training](/user-guides/training/security-awareness).
- This table is read-only. It does not enroll learners, send reminders, play courses, or export CSV.

## Open the learner table

You can open the table from two places.

<Steps>
  <Step title="Option A: Security Training (all providers)">
    Open **Training > Training Menu > Security Training**. This table includes every connected provider, including CyberHoot. When Huntress assignments are available, this page has two tabs and **Training Status** is the one that shows learners.
  </Step>
  <Step title="Option B: Security Awareness (one provider at a time)">
    Open **Security > Security Awareness**. When more than one provider is connected, provider tabs appear at the top. Click the tab for **BSN**, **Phin**, or **Huntress** to see that provider's learners. For Phished.io, click **Phished.io**, then **Learners**. The **CyberHoot** tab shows CyberHoot company and challenge sections instead of this table.
  </Step>
</Steps>

## Find a learner

<Steps>
  <Step title="Check the company selection">
    The table follows the company selector. The **Company** column is hidden when you select exactly one company.
  </Step>
  <Step title="Search by user">
    Use the filter on the **User** column. It matches the learner's name and email.
  </Step>
  <Step title="Filter or sort">
    Use the column filters and sort controls. Filtering and sorting apply to the whole result set, not only the page on screen. Browse the results 25 rows at a time.
  </Step>
  <Step title="Open a Breach Secure Now learner">
    Click a Breach Secure Now row to see [risk details](/user-guides/training/read-bsn-risk). Rows from other providers do not open a panel.
  </Step>
</Steps>

Changing the company selector resets the filters, sorting, and page. Close any open Breach Secure Now panel and select the learner again after you change companies.

## Filter the table

| Column or control | How to use it |
| --- | --- |
| **Provider** | Pick one or more providers. |
| **Company** | Pick companies within your selected scope. |
| **Assigned**, **Completed**, **Completion** | Enter a number range. |
| **Training Status** | Choose **Up to date**, **Behind**, or **Not assigned**. |
| **Phishing Sent**, **Clicked**, **Click Rate**, **Active Campaigns** | Enter a number range. |
| Column toggle | Show more columns: **ESS**, **Security score**, **Micro training**, **Breaches**, **Credentials captured**, **Last training**, **Last login**, **Account**, and **Last Sync**. |
| **Last training**, **Last login**, **Last Sync** | Pick a date range. These are filled in only when the provider supplies them. |

CyberHoot adds **Overdue**, **HootScore**, and columns you can turn on for **HootRank**, individual scores, **Outstanding**, **Attempts**, **Late submissions**, and **AttackPhish failures**. Only CyberHoot fills these in.

## Read the figures

- **Not assigned** means the learner has zero assigned trainings.
- **Up to date** and **Behind** come from each provider's own compliance value. For Breach Secure Now, **Up to date** means completion is 100%.
- **Not provided** means the provider did not send that value. It does not mean zero risk or finished training.

| Provider | How to read the row |
| --- | --- |
| Breach Secure Now | **Assigned** and **Completed** add up security courses, micro training, and additional courses. The risk panel breaks them apart. **Active Campaigns** shows 1 or 0 for the learner's enrollment in a campaign. |
| Phin | **Completion** is completed divided by assigned. **Active Campaigns** is a company count, repeated on every learner row. |
| Huntress | **Assigned** counts the learner's synced assignments. **Completed** counts assignments with a completion date or progress of 100% or more. **Active Campaigns** is a company count. |
| CyberHoot | Uses CyberHoot's own assignment, completion, compliance, and Hoot figures. Use the CyberHoot tab for phishing results. |
| Phished.io | **Assigned** and **Completed** come from Phished's recipient summary. Phishing sent, clicked, and click-rate columns stay empty for Phished. Use its **Insights** view for simulation events from the last 30 days. |

Do not add up **Active Campaigns** across learners, because Phin and Huntress repeat the same company count on each row.

## Phished.io

The [Phished.io integration](/user-guides/integrations/enable-phished-integration) adds learner rows based on the current training snapshot. In **Security > Security Awareness**, select **Phished.io > Learners**; the combined Security Training view can also include Phished. Assigned and completed counts use Phished's recipient summary. Missing statistics remain **Not provided**; they are not treated as completed training.

The generic phishing sent, clicked and click-rate columns are unavailable for Phished. Use its **Insights** view for simulation event counts from the last 30 days. These event counts are distinct from a calculated click rate or a unique learner count.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A learner is missing | Clear filters, check the company selector, and check the provider filter. Reload if needed, then ask your MSP to check the provider mapping and last successful sync. |
| Clicking a row does nothing | Only Breach Secure Now rows open a panel. |
| A column is blank or says **Not provided** | The provider does not supply that value. |
| The table is empty | Check the company selector and filters. An empty table does not mean everyone finished. |
| You need to change an assignment or account | Start with the [Home AI Assistant](/user-guides/ticketing/open-a-ticket), then review and confirm the request. MSP staff make the change in the provider. |

Earlier results can remain visible while a new request loads. An empty or missing table does not prove a successful refresh.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why does clicking a Phin, Huntress, or CyberHoot learner do nothing?">
    Only Breach Secure Now rows open the risk panel in this table.
  </Accordion>
  <Accordion title="Does Not assigned mean the learner passed?">
    No. It means no trainings are assigned. Check the provider's assignments with your MSP.
  </Accordion>
  <Accordion title="Why do I see different providers on Security Training and Security Awareness?">
    **Security Training** lists all providers in one table. **Security Awareness** shows one provider per tab.
  </Accordion>
  <Accordion title="Does the Account column prove someone can sign in?">
    No. It shows **Active** unless the provider reports the account as inactive or locked.
  </Accordion>
</AccordionGroup>
