**Audience:** MSP staff with Training access. Creating or editing paths requires **Write Training** or **Manage Training**; deletion requires manage permission. Company learners use their assigned training instead of administering the catalog.

Open **Training > Learning Paths**. The management area offers **Learning Paths**, **User Groups** and **Templates**. Check the company scope before interpreting the list or assigning people.

## Create a learning path

1. Choose **Create Learning Path**. The full editor opens, the same one used to edit a path.
2. Enter a title and optional description.
3. Choose the company, or the tenant-wide option when available. Review the mandatory and target role/department fields.
4. In **Courses**, tick the courses to include. In **Assignments**, add users or groups if you want learners assigned from the start. Both are optional at creation.
5. Click **Create Learning Path**. The path, its courses and its assignments save together, and nothing is created until this succeeds.

## Edit details, courses and assignments

The full editor has **Details**, **Courses** and **Assignments**. Changes remain staged until **Save & Close** succeeds.

- In **Details**, review scope and mandatory/targeting settings. A scope change can affect which users remain eligible; inspect assignments before saving.
- In **Courses**, search the course list, use the assignment control to include a course, and set whether it is required. Use the move controls to set order. The current editor uses course assignment controls rather than the old pair of Available/Assigned course lists.
- In **Assignments**, use **Users** or **User Groups**, select the intended targets and add them to the assigned side. Remove unwanted targets there. Review the deadline options and mandatory setting where offered.

Click **Save & Close**, then reopen the path to confirm the saved details and selections. Do not treat switching tabs or clicking Add Selected as persistence. If another editor changed the path and Save fails, reload the current path before reconstructing your intended changes.

Target roles and departments are not a substitute for inspecting the actual assignment list. Verify which learners received the path rather than assuming a target field alone proves enrollment or notifications.

## Use focused row actions

The path row menu also offers **Manage Courses** and **Assign to Users/Groups**. Use **Save Changes** in Manage Courses and **Save Assignments** in the assignment dialog. Review the resulting selection and save in that dialog; they do not wait for another page Save.

Assigning a group affects its eligible members. Check both company scope and group membership before saving. Removing a path assignment is not a general course-enrollment deletion workflow; inspect learner records separately if you need to remove enrollment or access.

## Reuse templates and groups

Use **Templates** to create and edit a reusable curriculum, manage its courses, or create a path from it. Creating a path from a template creates a separate path to configure and verify; do not assume later template edits update every previously created path.

**Convert to Template** is a row action on a path and immediately requests the conversion operation. Use it when you intend to create reusable content, not to preview the template dialog.

Use **User Groups** to manage named assignment groups and their members. A group selected for training is not an authorization role. Review actual membership before assigning a curriculum.

Tenant-wide groups are hidden from company group management; this does not remove training already assigned to their members. Parent-company access to descendant groups still depends on the role’s child-company management permission.

Click **Create Group** to save, or **Cancel** to discard the draft. The screenshots show unsaved drafts.

## Bulk actions and deletion

Select the intended paths before using a bulk assignment or deletion action. Review the confirmation and target count. Delete is a separate confirmed operation, not a change staged behind Save & Close. Do not use it as a substitute for disabling one course or removing one learner.

## Troubleshooting

If a learner is missing, check path scope and group membership. If courses do not appear for a learner, inspect the saved path courses, assignments, course enablement, Premium access and training permissions. If Save fails, keep the error and inspect the current record before retrying a create, conversion or assignment.

## FAQs

<AccordionGroup>
  <Accordion title="Does creating a path also add its courses and learners?">
    Yes, when you choose them before clicking Create Learning Path. Courses and assignments you stage in the editor save together with the new path. Reopen the path to confirm them.
  </Accordion>
  <Accordion title="Do edits save when I switch tabs?">
    No. The full editor uses Save & Close. Manage Courses uses Save Changes; the assignment dialog uses Save Assignments.
  </Accordion>
  <Accordion title="Does Add Selected immediately assign learners?">
    It stages the selection in the dialog. Save the dialog and verify the result.
  </Accordion>
  <Accordion title="Do template edits automatically update existing paths?">
    Do not assume this. Review each path created from the template as a separate saved curriculum.
  </Accordion>
  <Accordion title="Does a group grant training administration permissions?">
    No. An assignment group and an authorization role serve different purposes.
  </Accordion>
  <Accordion title="Can I assume target roles sent notifications to everyone matching them?">
    No. Inspect actual assignments and learner access; a targeting field is not proof of enrollment or notification delivery.
  </Accordion>
  <Accordion title="Does removing a path assignment erase all course enrollment?">
    Do not use path unassignment as a general enrollment deletion workflow. Inspect learner records separately.
  </Accordion>
</AccordionGroup>
