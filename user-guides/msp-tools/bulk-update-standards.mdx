This guide shows MSP staff how to change many Standards statuses at once, from a company row or a standard column.

## Before you start

- You need Standards read access, Planner Write permission and active billing.
- Read [Read the Standards matrix](/user-guides/msp-tools/read-standards-matrix) and decide which companies and standards the change should cover.
- Bulk changes save as soon as you choose a status. There is no confirmation and no Undo.

## Choose the scope first

| Where you open the menu | What it changes |
| --- | --- |
| A single status cell | That company and that standard. See [Update a company's Standards deployments](/user-guides/msp-tools/update-standard-deployments). |
| A company name | Every standard in that company's row. |
| A standard's column header | That standard for every non-excluded company in the loaded scope. |

<Warning>
**Search companies...** does not limit a column action. Companies hidden by the search are still changed. The company selector at the top of the app sets the loaded scope. Excluded companies are skipped by column actions.
</Warning>

## Set all standards for one company

<Steps>
  <Step title="Open Standards">
    In the sidebar, open **MSP Tools > Standards**.
  </Step>
  <Step title="Find the company">
    Type the name in **Search companies...**.
  </Step>
  <Step title="Open the company menu">
    Right-click the company name, or click the three-dot button beside it. The menu header shows the company name and **Mark all standards as**.
  </Step>
  <Step title="Choose a status">
    Pick **Mark Deployed**, **Mark In Progress**, **Mark Not Started**, **Mark N/A** or **Mark Declined**. A toast reads **Updated** followed by the number of entries.
  </Step>
  <Step title="Review the row">
    Check the whole row, then open a few linked Planner items.
  </Step>
</Steps>

This covers optional standards and members of **1 of N** categories too. It skips standards that do not apply to the company because of a device platform or company field rule. The row menu cannot choose a deployment option per standard. Set options one cell at a time afterward.

An excluded company can still be changed from its row menu while it is shown.

## Set one standard for all companies in scope

<Steps>
  <Step title="Check the company selector">
    In Global View, the change covers every loaded company. Confirm that is what you want.
  </Step>
  <Step title="Open the column menu">
    Right-click the standard's column header. Or focus the header with the keyboard and press **Enter** or **Space**.
  </Step>
  <Step title="Check the heading">
    The menu shows the standard name and **Mark all companies as**.

    <Frame caption="The column menu says Mark all companies as. Company search does not narrow it.">
      <img src="/images/product/standards-column-menu.png" alt="Standard column menu headed Mark all companies as, with Mark Deployed, Mark In Progress, Mark Not Started, Mark N/A and Mark Declined." width="440" height="468" />
    </Frame>
  </Step>
  <Step title="Choose a status or option">
    Pick a status. If the standard has configured options, you can pick one option instead. That marks every affected company **Deployed** with that option.
  </Step>
  <Step title="Review the results">
    Clear **Search companies...**, then check the affected rows and a few linked Planner items.
  </Step>
</Steps>

<Frame caption="When a standard has deployment options, they appear under their tier above the status choices.">
  <img src="/images/product/standards-deployment-options-menu.png" alt="Column menu with a deployment option listed under its tier, followed by Deployed, option not specified, Mark In Progress, Mark Not Started, Mark N/A and Mark Declined." width="440" />
</Frame>

**Deployed — option not specified** clears the selected option for the affected companies. Other statuses can keep an earlier option, so check it when you mark records Deployed again.

## What a bulk change updates

- Each affected record gets the new status, and its linked Planner item gets the matching status. Deployed becomes Completed. N/A and Declined become Cancelled. In Progress and Not Started keep their names.
- A bulk change can replace On Hold or Pending Approval on linked Planner items.
- Bulk changes keep the notes stored on Standards records.
- If the Standards save works but the Planner update fails, the matrix still shows the new status. The Standards sync fixes the Planner item on its next run.

If a bulk change fails, a toast reads **Failed to update standards** and the cells revert. Reload before you try again, and do not widen the scope to fix one record.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A company I searched out was changed | Column actions ignore the search. Set the correct status on that company, one cell at a time. |
| An excluded company did not change | Column actions skip excluded companies. Use its row menu. |
| A cell did not change | The standard does not apply to that company. Hover the cell to read the rule. |
| Planner items still show the old status | Reload, then ask an administrator to run [Sync Standards to companies](/user-guides/settings/sync-standards). |
| **Failed to update standards** appears | Check Planner Write permission and active billing, reload, then retry. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="How do I change every standard for one company?">
    Right-click the company name, or click its three-dot button, and use **Mark all standards as**.
  </Accordion>
  <Accordion title="How do I change one standard for several companies?">
    Right-click the standard's column header and use **Mark all companies as**.
  </Accordion>
  <Accordion title="Does the company search limit a column action?">
    No. A column action includes loaded, non-excluded companies the search hides.
  </Accordion>
  <Accordion title="Does the row action change only required standards?">
    No. It changes every applicable standard in the row, including optional ones and one-of group members.
  </Accordion>
  <Accordion title="Can one column action set the same option for every company?">
    Yes. Choose an option in the column menu. It marks the affected records Deployed with that option.
  </Accordion>
  <Accordion title="Is there a confirmation?">
    No. Choosing a status saves it. Press **Escape** or click outside the menu to cancel before you choose.
  </Accordion>
  <Accordion title="Do bulk changes erase Standards notes?">
    No. Bulk changes keep stored notes. A single-cell change clears the note on the Standards record.
  </Accordion>
</AccordionGroup>
