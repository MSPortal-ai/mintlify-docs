**Audience:** MSP staff with Training settings access. Course availability changes require Training settings write access. **Create Course** requires **Manage Training** and active billing. These are separate permissions.

Open **Settings > Training**. Review the company selector before changing availability: a selected company or set of companies scopes course enablement; the organization-wide view changes the broader catalog setting. The Launch setup view uses organization-wide scope.

## Find and enable courses

Filter the table by its available title, type, category, tags, duration or enabled controls. Review the matching course before changing its **Enabled** switch. The switch saves immediately; there is no confirmation followed by a page Save. The row menu also offers enable/disable and **Preview Course**.

For a batch, select the exact courses and use the bulk enable/disable action. In the Launch training setup view, **Enable All Included Training** enables included content organization-wide, not merely the currently visible rows. Preview and verify the resulting learner access before a wider rollout.

Availability, enrollment and Premium entitlement are separate. Enabling a course does not by itself assign every user to it. Disabling is not an enrollment cleanup tool; check the learner's actual course access before assuming an existing enrollment remains usable.

## Choose certificate branding

<Note>
Branch preview for the 2026-09-25 release. Certificate branding is not yet generally available, and this section has no screenshot yet.
</Note>

The **Certificate branding** card at the top of **Settings > Training** sets the name and logo printed on training certificates for all clients. It is not scoped by the company selector.

1. Choose **MSP branding** to show your organization's name and logo, or **Client branding** to show the learner's company name and logo.
2. Click **Save**. The button stays disabled until you change the selection. Wait for **Certificate branding saved**.

With **Client branding**, a company without a logo shows its name instead. Learners who do not belong to a company keep MSP branding. The choice applies to certificates already issued, so the next time a certificate is viewed, downloaded or shared, it uses the current setting.

Changing the setting requires Training settings write access and active billing. Users with read-only access see the current choice without a **Save** button.

## Create a custom course

1. Click **Create Course**.
2. Enter **Course Title**, description and a required **Category**.
3. Choose **SCORM Package**, **Video Course** or **Document**.
4. Review duration, passing score, maximum attempts, expiry and the mandatory setting. A placeholder is not a saved value.
5. Provide content using the relevant input described below.
6. Click **Create Course** to create the record and process its content. **Cancel** closes the unsaved form.
7. Find the resulting course, check availability and open **Preview Course** to verify its actual content before assigning learners.

| Content type | Input |
| --- | --- |
| SCORM Package | A ZIP package; package processing follows course creation. |
| Video Course | Uploaded MP4, WebM or MOV files, or YouTube links. Review the selected source and complete link list. |
| Document | The picker accepts PDF, DOC, DOCX, PPT and PPTX. Preview the resulting learner experience; accepting a file does not prove every format renders inline. |

Creating the course and uploading its content are separate stages. If an upload fails, the course record may already exist. Look for it before repeating Create Course, and inspect the content error rather than treating a closed form as proof of success.

The creation form does not offer a company selector. Do not assume the page's company filter makes a new custom course private to that company; review its availability separately.

## Preview and manage video questions

Use a course's row menu to open **Preview Course** in a new tab. Video courses also offer a questions-management entry. Author questions in that screen and verify the quiz in the preview. A staff preview is not proof that an ordinary Company user has access.

Use [Learning Paths](/user-guides/training/learning-paths) to group courses and assign users or groups. Use [Enable Training](/user-guides/training/enabling-training) to review company and user Premium access. The current library, entitlement and [Billing settings](/user-guides/settings/billing) determine what is available; do not rely on a fixed public course count.

## Troubleshooting

If a switch or Create button is disabled, check the permission for that action. If a course is absent, check company scope and filters. If a learner cannot launch it, review course availability, Premium entitlement, training permissions and assignment. If creation reports a content error, inspect the existing record and preview before creating a duplicate.

## FAQs

<AccordionGroup>
  <Accordion title="Can I use client branding for only some companies?">
    No. Certificate branding is one organization-wide choice. With Client branding, each certificate uses its learner's company.
  </Accordion>
  <Accordion title="Does enabling a course enroll everyone?">
    No. Course availability and learner enrollment are separate; use assignment or learning-path workflows.
  </Accordion>
  <Accordion title="Do enable switches wait for Save?">
    No. Course enable/disable actions persist immediately for the selected company scope.
  </Accordion>
  <Accordion title="Does Enable All Included Training only change this page?">
    No. That action appears in Launch training setup and enables included content organization-wide, not just visible rows.
  </Accordion>
  <Accordion title="Can settings access alone create courses?">
    No. Create Course requires Manage Training and active billing; availability controls use Training settings write access.
  </Accordion>
  <Accordion title="Can a course exist after its upload fails?">
    Yes. Creation precedes content upload. Inspect the course before repeating creation.
  </Accordion>
  <Accordion title="Does the company filter make a new course company-private?">
    Do not assume that. The creation form has no company selector; review availability after creation.
  </Accordion>
  <Accordion title="Does disabling a course erase enrollments?">
    Do not use disabling as enrollment cleanup or assume an enrolled learner can still launch the course. Verify actual access separately.
  </Accordion>
</AccordionGroup>
