Note templates are reusable starting text. Staff pick one from a **+ Add Template** menu while they write a compliance note, a Planner item, or meeting notes and agendas. This page is for MSP staff who manage those templates.

## Before you start

- You need Note Templates access. **View** needs read access. **Add New Template** and **Edit** need write access. **Set Default**, **Remove Default** and **Delete** need manage access.
- Notification email templates are not managed here. Use [Email settings](/user-guides/settings/email) for those.

## Open Note Templates

<Steps>
  <Step title="Open Settings > Customization > Note Templates">
    The page lists your templates in a table with the columns **Name**, **Template Type**, **Description** and **Default**.
  </Step>
  <Step title="Pick a tab to filter the list">
    The tabs are **All Templates**, **Compliance Notes**, **Planner Items**, **Meeting Agendas**, **Meeting Notes** and **Report Sections**. The **Template Type** column only shows on **All Templates**.
  </Step>
</Steps>

## Create a template

<Steps>
  <Step title="Click Add New Template">
    The button is at the top right of the page. It is disabled if you do not have write access. A **Create New Template** dialog opens. Nothing is saved yet.
  </Step>
  <Step title="Enter a Template Name">
    This field is required. The name is what staff see in the template picker.
  </Step>
  <Step title="Add a Description">
    Optional. A short description helps other staff choose the right template.
  </Step>
  <Step title="Choose a Template Type">
    Pick **Compliance Check Note**, **Planner Item**, **Meeting Agenda**, **Meeting Notes** or **Report Section**. The type decides where the template shows up in a picker.
  </Step>
  <Step title="Write the Content">
    Type in the editor and format it with the toolbar. Markdown shortcuts work. Content is required.

    To start from a draft, fill in both **Template Name** and **Description**, then click **Draft with AI**. The button stays disabled until both are filled in. The draft replaces whatever is in the editor, so edit it before you save.

    <Frame caption="The Create New Template dialog. Create Template stays disabled until the name and content are filled in.">
      <img src="/images/product/note-template-editor.png" alt="Create New Template dialog with Template Name, Description, Template Type and Content fields." width="1820" height="1536" />
    </Frame>
  </Step>
  <Step title="Click Create Template">
    The template appears in the list.
  </Step>
</Steps>

If you close the dialog with unsaved changes, MSPortal asks you to confirm before it discards them.

## Edit or view a template

<Steps>
  <Step title="Open the template">
    Click its name in the **Name** column, or open the row's **Open menu** (the three dots) and choose **Edit**. If you only have read access, the menu shows **View** instead, and the dialog is read-only with a **Close** button.
  </Step>
  <Step title="Change the fields and click Save Changes">
    Existing notes and meetings that already used the template do not change.
  </Step>
</Steps>

## Set or remove a default

<Steps>
  <Step title="Open the row's menu">
    Click **Open menu** on the template's row.
  </Step>
  <Step title="Choose Set Default or Remove Default">
    A template marked as the default shows a **Default** badge in the **Default** column. Each template type can have one default.
  </Step>
  <Step title="Confirm a replacement">
    If another template of the same type is already the default, a **Change Default Template** prompt names both templates. Click **Confirm** to replace the old default, or **Cancel** to keep it.
  </Step>
</Steps>

## Delete a template

<Steps>
  <Step title="Open the row's menu and choose Delete">
    A **Delete Template** dialog names the template.
  </Step>
  <Step title="Confirm the deletion">
    Deleting is permanent and cannot be undone. It does not change notes that already used the template.
  </Step>
</Steps>

## Use a template

Open a compliance check note, a Planner item, or a meeting, and click **+ Add Template** next to the notes field. Search by name and click a template. Its content is added to the notes. The menu lists only templates of the matching type:

| Where | Types offered |
| --- | --- |
| Compliance check notes | Compliance Check Note |
| Planner item notes | Planner Item |
| Meeting notes and agendas | Meeting Notes and Meeting Agenda, grouped by type |

If the menu says **No templates found**, click the **settings** link in it to open this page.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Add New Template** is disabled. | Your role has read-only access. Ask an administrator for write access to Note Templates. |
| **Create Template** is disabled. | Fill in **Template Name** and **Content**. |
| **Draft with AI** is disabled. | Fill in both **Template Name** and **Description**. |
| **Set Default**, **Remove Default** or **Delete** is unavailable. | These need manage access to Note Templates. |
| A template is missing from a picker. | Check its **Template Type**. Each picker shows only its own types. |
| The Draft with AI result is a generic outline. | The AI request failed and MSPortal inserted a placeholder outline. Edit it, or click **Draft with AI** again. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Are email templates managed here?">
    No. Note Templates covers compliance notes, Planner items, meeting agendas, meeting notes and report sections. Use Email settings for notification emails.
  </Accordion>
  <Accordion title="Does opening Add New Template create a record?">
    No. The template is created when you click **Create Template**.
  </Accordion>
  <Accordion title="Can there be more than one default?">
    One default per template type. Setting a new one asks you to confirm and removes the old one.
  </Accordion>
  <Accordion title="Does editing a template change notes that already used it?">
    No. A template only supplies starting text when someone adds it.
  </Accordion>
  <Accordion title="Can I use placeholders such as company name or date?">
    The editor does not fill in placeholders. Whatever you type is inserted as written.
  </Accordion>
</AccordionGroup>
