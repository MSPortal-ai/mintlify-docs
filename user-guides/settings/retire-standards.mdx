This page is for MSP staff who manage the shared Standards catalog. It shows how to delete a standard, a category, a deployment option, or a tier, and what each deletion removes. Deleting a definition affects every company, not only the one you have selected.

## Before you start

- You need the permission to manage Standards settings, and your billing must be active.
- Company users cannot delete Standards definitions.
- Review the linked work in the [Standards matrix](/user-guides/msp-tools/read-standards-matrix) first.
- If you only want to change scoring or record a company's situation, use **Required**, **Optional**, **Require one of group**, or a company deployment status instead. These do not retire a definition.
- The catalog has no Archive action. Deletion is permanent.

## Delete a standard

<Steps>
  <Step title="Open the catalog">
    Go to **Settings > MSP Tools > Standards** and expand the category that holds the standard.
  </Step>
  <Step title="Start the delete">
    Select the trash icon on the item, labeled **Delete item**.
  </Step>
  <Step title="Read the confirmation">
    The app counts the Planner items linked to the standard. If the count is zero, a **Delete Item** confirmation opens. If the count is above zero, or the app could not check it, a **Delete Standards Item** dialog opens with the number of linked Planner items.
  </Step>
  <Step title="Confirm">
    For **Delete Standards Item**, type the exact item name, including spacing and case, then select **Delete Item & Planner Items**. For **Delete Item**, select **Delete**. Select **Cancel** to keep the standard.
  </Step>
  <Step title="Check the result">
    Confirm that the standard is gone from the catalog and that the Planner items are gone from Planner.
  </Step>
</Steps>

<Warning>
Deleting a standard permanently deletes its linked Planner items across all companies. It also removes the standard's company tracking, deployment options, tier settings, SKU mappings, and evidence. Onboarding tasks and onboarding template tasks that pointed to the standard stay, with their Standards link cleared.
</Warning>

The deletion runs as one step. If an error appears, nothing was deleted. Try again, or ask for help if it repeats.

## Delete a category

<Steps>
  <Step title="Open the catalog">
    Go to **Settings > MSP Tools > Standards**.
  </Step>
  <Step title="Start the delete">
    Select the trash icon on the category, labeled **Delete category**.
  </Step>
  <Step title="Confirm">
    The **Delete Category** dialog warns that all items in the category are deleted too. Select **Delete**. This dialog does not ask you to type a name and does not show a linked Planner count.
  </Step>
  <Step title="Review the Planner items">
    Open Planner and review the items that were linked to the category's standards.
  </Step>
</Steps>

Deleting a category deletes its standards and their company tracking. It does not delete their Planner items. Those items stay in Planner with their Standards link cleared, so review them yourself. This is different from deleting each standard one by one, which deletes the Planner items.

## Remove a deployment option or tier

Go to [Configure Standards tiers and deployment options](/user-guides/settings/standards-tiers) for the steps.

- Deleting a deployment option takes effect at once. Company records that used it become unspecified.
- Deleting a tier asks you to confirm. The app refuses if any deployment option still uses the tier. Move or delete those options first.
- A deleted tier clears the tier assigned to company types.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The trash icon is missing | Check that you have the permission to manage Standards settings and that your billing is active. |
| The dialog asks for the standard's name | The standard has linked Planner items, or the app could not count them. Type the name exactly, including spacing and case. |
| **Delete Item & Planner Items** is greyed out | The text you typed does not match the item name exactly. |
| Tier delete is refused | A deployment option still uses the tier. Move or delete those options, then try again. |
| Planner items remain after deleting a category | This is expected. Category deletion clears their Standards link and leaves them in Planner. |
| An error appears on delete | Nothing was deleted. Try again. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I delete a standard?">
    Open **Settings > MSP Tools > Standards**, expand the category, and select the trash icon on the item.
  </Accordion>
  <Accordion title="Does deleting a standard affect only my selected company?">
    No. The standard is shared, so deleting it removes it and its linked work for every company.
  </Accordion>
  <Accordion title="When do I have to type the standard name?">
    When the standard has linked Planner items, or when the app could not count them. A failed count never means zero, so the app asks for the name.
  </Accordion>
  <Accordion title="Does deleting a standard archive its Planner work?">
    No. It deletes the linked Planner items. There is no archive.
  </Accordion>
  <Accordion title="Does deleting a category delete its Planner items?">
    No. The Planner items stay and lose their Standards link.
  </Accordion>
  <Accordion title="Can I undo a delete?">
    No. **Cancel** keeps the definition only before you confirm.
  </Accordion>
  <Accordion title="Does Optional stop company tracking from being created?">
    No. **Optional** changes scoring only. Sync can still create company tracking and Planner work.
  </Accordion>
</AccordionGroup>
