Use this page to build the shared Standards catalog: the categories and standards your MSP expects clients to have. It is for MSP staff. Company users should read [Understand Standards items in Planner](/user-guides/planner/understand-standards-items).

## Before you start

- You need Standards settings **Read** permission to view the catalog. Creating, editing, deleting and syncing need **Manage** permission and an account in good billing standing. Company administrator access does not grant these MSP settings.
- The page is at **Settings > MSP Tools > Standards**. The older `/settings/tool-stack` address redirects here.
- Settings defines the shared catalog. The company deployment matrix is a separate page at **MSP Tools > Standards**.
- The page has three tabs. **Standards** is the catalog on this page. **Standards tiers** is covered in [Standards tiers and deployment options](/user-guides/settings/standards-tiers). **Company Standards applicability** is covered in [Choose which Standards apply](/user-guides/settings/standards-applicability).

## Create a category

<Steps>
  <Step title="Open the catalog">
    Go to **Settings > MSP Tools > Standards** and stay on the **Standards** tab.
  </Step>
  <Step title="Add the category">
    Click **Add Category**. A category named **New Category** is saved right away. If that name is taken, the new one is named **New Category 2**, and so on.
  </Step>
  <Step title="Rename it">
    Click the category name, type a name, then press Enter or click outside the field. Press Escape to cancel. Category names must be different from each other.
  </Step>
  <Step title="Add a description and icon">
    Click the pencil (**Edit category details**). Enter a **Description**, then pick an **Icon**. The description saves when you click out of the box.
  </Step>
  <Step title="Choose a Planner type">
    In the category header, open the dropdown that reads **No planner type** and pick a type. On a phone, this dropdown is inside the pencil popover under **Planner Type**.
  </Step>
</Steps>

The Planner type sets the type of the Planner items that [Sync All Companies](/user-guides/settings/sync-standards) creates for the category. Choosing it does not create any work by itself. A category with **No planner type** can still get Planner items on sync.

## Add and edit a standard

<Steps>
  <Step title="Add the standard">
    Click the **plus** (**Add item**) in the category header. In an empty category you can also click **Add one**. An item named **New Item** is created and opens for editing.
  </Step>
  <Step title="Name it">
    Type a name in **Name**. Names must be different within a category. Rename **New Item** before you add another item to the same category, or the second add fails with a duplicate-name message.
  </Step>
  <Step title="Fill in the details">
    Complete the fields in the table below. Every field saves on its own shortly after you stop typing. There is no Save button.
  </Step>
  <Step title="Reopen it later">
    Click the item row to open its editor again. Only one item is open at a time.
  </Step>
</Steps>

The editor is one form. Each row has its label and a short hint on the left and its controls on the right.

<Frame caption="The item editor: Details, Deployment options, Standards applicability and Answered by billing rows.">
  <img src="/images/product/standards-item-editor.png" alt="Standards item editor showing the Details fields, an empty Deployment options row, a Standards applicability row with Add condition, and an Answered by billing row with Link a product." width="1852" height="1124" />
</Frame>

| Field | What it does |
| --- | --- |
| **Name** | The standard's name. It is also the title of the linked Planner items. |
| **Vendor** | An optional supplier label such as SentinelOne. It does not connect an integration or install anything. |
| **Service plans** | The plans that expect this standard. Leave it at **All plans** to expect it of every client. The field shows only after you create at least one tier. |
| **Default Price** | The Planner cost estimate for linked items, in your currency. Sync supplies it. It is not a quote or an invoice amount. |
| **Required** | Whether the standard counts as a required check. The switch is disabled in a **Require one of group** category. |
| **Description** | Copied to the linked Planner item's description on sync. |
| **Deployment options** | Named implementations of the standard, each ranked by a tier. See [tiers and options](/user-guides/settings/standards-tiers). |
| **Standards applicability** | Conditions that decide which companies the standard applies to. See [Choose which Standards apply](/user-guides/settings/standards-applicability). |
| **Answered by billing** | PSA products that mark the standard Deployed automatically. See [Use PSA billing to answer Standards](/user-guides/settings/standards-sku-automation). |
| **Planner template** | An optional template applied to the standard's open Planner items on sync. See [Apply a Planner template](#apply-a-planner-template). |

New items are **Required** in an ordinary category and optional in a **Require one of group** category. An optional standard still gets company tracking records and Planner items on sync.

## Apply a Planner template

Pick a template on a standard to set up its Planner items from the start, instead of applying a template to each item after sync creates it.

<Steps>
  <Step title="Create the template">
    If you have none yet, create one in [Planner templates](/user-guides/planner/manage-templates).
  </Step>
  <Step title="Choose it on the standard">
    Open the standard's row and pick the template under **Planner template**. The choice saves automatically. **None** is the default. If the list is empty, click the **Create one in Planner templates** link in the row.
    <Frame caption="The Planner template row in the standard's editor. Choose None to stop applying a template.">
      <img src="/images/product/standards-planner-template.png" alt="Standards item editor row labeled Planner template with a None selection." width="2174" height="262" />
    </Frame>
  </Step>
  <Step title="Sync">
    Click **Sync All Companies**. Choosing a template changes no Planner item until you sync.
  </Step>
</Steps>

On sync, each **open** Planner item for the standard gets the template:

| From the template | What happens |
| --- | --- |
| Business value, hours, probability, public and private notes | Written to the item. |
| Description and Planner type | Used instead of the standard's description and the category's Planner type. Empty template values fall back to those. |
| Cost rows | Added to the item, or the template's single cost estimate as one row. A template with no cost keeps the standard's **Default Price**. |
| Compliance checks | Linked for each company that has the check assigned. |
| Hide from company users | A template can make items internal. It never shows an internal item to company users. |

The standard's name stays the item title, and the Standards matrix still sets the status. Completed, Cancelled and archived items are not changed. If one is reopened, a later sync applies the template.

### Change or remove a template

- **Switch templates.** On the next sync, open items drop the old template's cost rows and get the new template. Cost rows added by hand stay. The new template's compliance links are added; the old links stay.
- **Choose None.** On the next sync, the old template's cost rows are removed. When no rows remain, the standard's **Default Price** comes back. The description and type return to the standard's; the other fields stay.
- **Delete the template.** The standard's choice returns to **None**, but its items keep what the template gave them.
- **Edit the template.** Changes to a template's contents are not re-applied to items that already have it. Only choosing a different template updates them.

Editing a template cost row on a Planner item turns it into a row the sync no longer replaces. Returning the row to its original values keeps it a template row.

## Require one of a group

Use this for a category of alternatives, such as a company needing one suitable backup product from a group.

<Steps>
  <Step title="Open the category details">
    Click the pencil (**Edit category details**) in the category header.
  </Step>
  <Step title="Turn on the rule">
    Turn on **Require one of group**.
  </Step>
  <Step title="Check the result">
    The category header shows **1 of N required**. Items show **Group** instead of Required or Optional, and their **Required** switches are disabled.
  </Step>
</Steps>

The category counts as one required check, and any deployed item in it satisfies the check. Turning the rule on changes every existing item in the category to optional.

Turning the rule off does not bring back the earlier Required choices. Open the items and turn **Required** back on where you need it. For scoring and exclusions, see [Read the Standards matrix](/user-guides/msp-tools/read-standards-matrix).

## Organize the list

<Steps>
  <Step title="Collapse or expand categories">
    Click a category's chevron, or use the **Collapse all** / **Expand all** button at the top. This hides rows only. It does not delete or disable anything.
  </Step>
  <Step title="Reorder">
    Drag the grip handle on a category to reorder categories. Drag the grip handle on an item to reorder items inside its category. Reordering saves right away, and a failed save puts the old order back. You cannot drag an item into a different category.
  </Step>
</Steps>

## Delete a category or standard

Click the trash icon on the category (**Delete category**) or the item (**Delete item**) and confirm. Deleting a category deletes its items. Deleting an item removes it from every company. If the item has linked Planner items, you must type its name to confirm, and those Planner items are deleted too. See [Retire Standards definitions](/user-guides/settings/retire-standards) before you delete anything that companies already track.

## Understand automatic saving

There is no overall Save or Cancel button. Adding a category or item saves it immediately. Item fields save about half a second after you stop typing. Category names save when you press Enter or click out of the field, and category descriptions save when you click out of the box. An empty item name is never saved.

Wait a moment before you leave the page. If a red error message appears, the change did not save, so reload the page and check the value. Closing the pencil popover or an item editor does not undo anything already saved.

Saving the catalog does not change company Planner items. Review [Sync Standards to companies](/user-guides/settings/sync-standards) before you click **Sync All Companies**.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The page is missing from Settings | You need Standards settings Read or Manage permission. Ask an administrator to update your role. |
| Changes will not save and a billing message appears | The account is read-only because of a billing issue. Update the payment information, then try again. |
| "An item with this name already exists in this category" | Give the item a name no other item in the category uses. This also happens if you add a second item before renaming **New Item**. |
| "A category with this name already exists" | Pick a name no other category uses. |
| **Service plans** is missing from the editor | Create at least one tier on the **Standards tiers** tab first. |
| The **Required** switch is disabled | The category has **Require one of group** on. Turn that off to set Required per item. |
| A value reverted after you reloaded | The save failed. Retype it, wait for it to save, and check for an error message. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I create or rename a standard?">
    Go to Settings > MSP Tools > Standards, open the category, and click the item row.
  </Accordion>
  <Accordion title="Can Company administrators edit this catalog?">
    No. This is an MSP setting. It needs Standards settings Manage permission.
  </Accordion>
  <Accordion title="Does Add Category open an unsaved form?">
    No. It saves a New Category right away. If New Category already exists, the new one is named New Category 2, and so on. Rename it.
  </Accordion>
  <Accordion title="Can two items have the same name?">
    Not in the same category. The same name can be used in different categories.
  </Accordion>
  <Accordion title="Where is the Save button?">
    There is none. Fields save as you type or when you click out of them.
  </Accordion>
  <Accordion title="Does closing the editor discard my changes?">
    No. Anything already saved stays.
  </Accordion>
  <Accordion title="Does choosing a Planner type create work right away?">
    No. The type applies when you run Sync All Companies. A category with no Planner type can still get Planner items on sync.
  </Accordion>
  <Accordion title="Are optional standards left out of sync?">
    No. Optional standards still get company tracking records and Planner items. Optional only affects scoring.
  </Accordion>
  <Accordion title="Is Default Price a monthly subscription price?">
    No. It sets the Planner item's cost estimate. Check the amount and recurrence on the Planner item.
  </Accordion>
  <Accordion title="What does Require one of group do?">
    The category counts as one required check, and any deployed item satisfies it. It changes the items to optional and disables their Required switches.
  </Accordion>
  <Accordion title="Does turning the group rule off restore Required?">
    No. Turn Required back on for each item that should count.
  </Accordion>
  <Accordion title="Can I drag an item to a different category?">
    No. You can reorder items only inside their own category.
  </Accordion>
  <Accordion title="Where is Planner type on a phone?">
    Click the pencil (Edit category details) and look under Planner Type.
  </Accordion>
  <Accordion title="Does choosing a Planner template change items right away?">
    No. The template is applied to open Planner items on the next Sync All Companies.
  </Accordion>
  <Accordion title="Are completed items updated when I change the template?">
    No. Completed, Cancelled and archived items keep what they have. Only open items are updated.
  </Accordion>
  <Accordion title="Why is the Planner template list empty?">
    Your MSP has no Planner templates yet. Use the link in the row to create one.
  </Accordion>
  <Accordion title="Do I need Planner access to choose a template?">
    No. Standards settings Manage permission is enough.
  </Accordion>
  <Accordion title="Does entering a vendor install or connect the product?">
    No. Vendor is only a label.
  </Accordion>
</AccordionGroup>
