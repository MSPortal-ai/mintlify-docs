**Audience:** MSP staff with Standards settings access. Company users should follow [Understand Standards items in Planner](/user-guides/planner/understand-standards-items).

Open **Settings > MSP Tools > Standards**. The older `/settings/tool-stack` address redirects here. Settings defines the shared catalog; **MSP Tools > Standards** is the company deployment matrix.

Viewing needs Standards settings Read permission. Creating, editing, deleting and syncing need Manage permission and active billing. Company administrator access does not automatically grant these MSP settings.

## Create a category

1. Select **Add Category**. This immediately creates **New Category**.
2. Select the category name, enter a distinct name, then press Enter or move focus out of the field. Escape cancels the name edit before it is submitted.
3. Use the category's **pencil**, labeled **Edit category details**, to add its description and icon.
4. Choose **Planner Type** in the category header. On a narrow screen, this choice is inside the category details popover.
5. Wait for automatic saving, then reopen the page to confirm the result before distributing it.

Rename **New Category** before adding another category. If that placeholder already exists, Add Category reports a duplicate-name error; it does not open a second draft. The catalog's names must be distinct within the MSP.

Planner Type classifies the linked work when you [sync Standards](/user-guides/settings/sync-standards). Selecting a type does not itself create tasks, and **No planner type** does not prevent sync from creating them.

## Add and edit a standard

1. Expand the category using its chevron.
2. Select its **plus**, labeled **Add item**. In an empty category you can also use **Add one**.
3. The new **New Item** opens for editing. Give it a distinct name within that category before adding another item there.
4. Complete the fields below. Select an existing item row whenever you need to reopen its editor.

The editor is one form. Each row shows its label and a short hint on the left and its controls on the right, and every row saves on its own.

| Field | Purpose |
| --- | --- |
| Name | Shared standard name and the title supplied to linked Planner work on sync. |
| Vendor | Optional supplier label. It does not connect a provider or install its product. |
| Default Price | Default Planner estimate supplied on sync. It is not a quote, invoice or automatically monthly per-user price. |
| Service plans | Plans that expect this standard. Leave it at **All plans** to expect the standard of every client. The field appears only once you have created Standards tiers. |
| Required | Whether the individual item counts as a required compliance check, unless its category uses the group rule below. |
| Description | Shared explanation supplied to the linked Planner description on sync. |
| Deployment options | Named implementations classified by your Standards tiers. See [tiers and options](/user-guides/settings/standards-tiers). |
| Standards applicability | Conditions that decide which companies the standard applies to. See [Choose which Standards apply](/user-guides/settings/standards-applicability). |
| Answered by billing | PSA products that answer the standard automatically. See [Use PSA billing to answer Standards](/user-guides/settings/standards-sku-automation). |

New items are Required by default in an ordinary category and Optional in a one-of group. An optional standard can still receive company tracking and Planner work during sync.

## Require one of a group

Use **Edit category details > Require one of group** when the category lists alternatives. For example, a company needs one suitable backup product from the group.

Turning this on changes existing items in the category to Optional and disables their individual Required switches. The group contributes one applicable required check; any deployed member satisfies it. Items display **Group**, and the category displays **1 of N required**.

Turning the group rule off does not restore the earlier Required choices. Open the items and turn Required back on where needed. For scoring exclusions, optional items and tiers, see [Read the Standards matrix](/user-guides/msp-tools/read-standards-matrix).

## Organize the list

Use category chevrons or **Collapse all / Expand all** to change what is open. These controls do not delete or disable standards. Use the grip handles to reorder categories or items within their category. Reordering saves immediately; a reported failure can restore the previous order. Dragging an item between categories is not supported by this screen.

## Understand automatic saving

There is no overall Save or Cancel button. Creating a category or item saves the placeholder immediately. Item fields save shortly after typing stops; category names save after Enter or blur, and category descriptions save after leaving their field.

Finish typing and wait before navigating away. A value changing on screen is not proof it saved: if an error appears, reopen the page and check the stored value. Closing a popover does not undo fields already saved. An empty item name is not a valid saved name.

Catalog saving and distributing Planner changes are separate. Review [Sync Standards to companies](/user-guides/settings/sync-standards) before using Sync All Companies. To remove definitions, follow [Retire Standards definitions](/user-guides/settings/retire-standards).

## FAQs

<AccordionGroup>
  <Accordion title="Where do I create or rename a standard?">
    Open Settings > MSP Tools > Standards, expand its category and open the item row.
  </Accordion>
  <Accordion title="Can Company administrators edit this catalog?">
    This is an MSP settings workflow. Company administrator access alone does not grant Standards settings management.
  </Accordion>
  <Accordion title="Does Add Category open an unsaved form?">
    No. It immediately saves a New Category placeholder. Rename it before adding another.
  </Accordion>
  <Accordion title="Why does Add Category say the name already exists?">
    Another category still has the New Category placeholder name. Review and rename that existing definition before adding the next one.
  </Accordion>
  <Accordion title="Can two items have the same name?">
    Use distinct item names within each category. An existing exact name in that category is rejected.
  </Accordion>
  <Accordion title="Where is the Save button?">
    There is no overall Save button. Inline fields save automatically; check for errors and reopen the page to confirm persistence.
  </Accordion>
  <Accordion title="Does closing the editor discard my changes?">
    No. Fields already saved remain changed. Finish editing and wait before navigating away.
  </Accordion>
  <Accordion title="Does choosing a Planner Type immediately create work?">
    No. It classifies work during Sync All Companies. A category without a type can still create Planner work on sync.
  </Accordion>
  <Accordion title="Are optional standards excluded from sync?">
    No. Optional affects scoring; sync can still create tracking records and Planner items for them.
  </Accordion>
  <Accordion title="Is Default Price a monthly subscription price?">
    Not automatically. It supplies a Planner estimate; review the resulting amount, currency and recurrence separately.
  </Accordion>
  <Accordion title="What does Require one of group do?">
    It makes the category one applicable check satisfied by any deployed member, changes its items to Optional and disables individual Required switches.
  </Accordion>
  <Accordion title="Does turning the group rule off restore Required?">
    No. Set Required individually again for the items that should count.
  </Accordion>
  <Accordion title="Can I drag an item to a different category?">
    This screen supports item reordering within its category, not moving it between categories.
  </Accordion>
  <Accordion title="Where is Planner Type on mobile?">
    Open the category pencil, Edit category details, to find the Planner Type choice on narrow screens.
  </Accordion>
  <Accordion title="Does entering a vendor install or connect the product?">
    No. Vendor is a descriptive catalog field; it does not install software or configure an integration.
  </Accordion>
</AccordionGroup>
