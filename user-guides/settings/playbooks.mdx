Use this page to browse the standard playbook library and import a playbook's checks into your tenant. It is for MSP staff.

## Before you start

- You need the `read_settings_playbooks` permission to browse the library.
- You need the `manage_settings_playbooks` permission and an active billing account to import. Without it, the **Add** buttons and checkboxes are disabled or hidden.
- Company users do not see this library.
- Your tenant needs at least one status list. The import dialog asks for one for every playbook. Device playbooks can also use your device types.

## Find a playbook

<Steps>
  <Step title="Open Settings > Compliance > Playbooks">
    The page shows two cards, **Best Practices** and **Security Frameworks**.

    <Frame caption="The Playbooks home page with the Best Practices and Security Frameworks cards.">
      <img src="/images/product/playbooks-library-paths.png" alt="The Playbooks home page with the Best Practices and Security Frameworks cards" width="1856" height="506" />
    </Frame>
  </Step>
  <Step title="Choose a path">
    Click **Best Practices** for broad operational and technology reviews. Click **Security Frameworks** for **CIS Benchmarks**, **CAN/DGSI 104** and **NIS2**.
  </Step>
  <Step title="Or search everything">
    Type in **Search all playbooks...** on the home page. The results list every matching playbook as a card. Click the clear button in the search box to go back to the two cards.
  </Step>
  <Step title="Go back">
    Use the back arrow in the page header to return to the previous level.
  </Step>
</Steps>

## Review a playbook before importing

<Steps>
  <Step title="Open the details">
    Click the playbook's name on its card. On a CIS Benchmarks card, click the eye button next to the **L1**, **L2** or **Full** row instead.
  </Step>
  <Step title="Read the checks">
    The details window is read-only. It shows the playbook's name, description, category, version and check list.
  </Step>
  <Step title="Close it">
    Click **Cancel**.
  </Step>
</Steps>

<Note>
The **Copy** button in the details window closes the details and opens **Add Playbooks to Tenant** for that playbook. It works like **Add** on the card, so you choose the folder, status list and device types before anything is imported. **Copy** is disabled without manage access to Playbooks.
</Note>

## Import one or several playbooks

<Steps>
  <Step title="Pick the playbooks">
    Click **Add** on one card. To import several at once, tick the checkbox on each card, then click **Add to Tenant** in the page header. The header button shows the count, such as **Add to Tenant (3)**.
  </Step>
  <Step title="Check the folder">
    In **Add Playbooks to Tenant**, find **Folder:** under each playbook. This is where the checks land in Compliance.
  </Step>
  <Step title="Choose a status list">
    Pick a **Status list** for each playbook. Your default status list is preselected when you have one. Check that its answer choices fit the playbook's checks.
  </Step>
  <Step title="Set device types (Device playbooks only)">
    In **Device types**, review the preselected types tagged **Suggested**. Remove a type with the x on its tag, or click **Clear** to remove all of them. Selected device types receive the imported check group automatically.
  </Step>
  <Step title="Watch for the duplicate warning">
    A playbook you already imported shows the warning **Already in your tenant. Importing again creates a second copy of this check group.** Click **Cancel** and clear that playbook's checkbox if you do not want a second copy.
  </Step>
  <Step title="Import">
    Click **Add to Tenant**. A message names the folder that holds the new checks. Click **Cancel** instead to close the dialog without importing.
  </Step>
  <Step title="Check the result">
    Open **Settings > Compliance > Checks** and look in the folder the message named. Open **Settings > Compliance > Groups** to see the new group.
  </Step>
</Steps>

## What an import does

- It creates one check group named after the playbook.
- It copies the playbook's checks into the folder shown in the dialog, using the status list you chose.
- It links the group to the device types you selected.
- It does not change settings on any endpoint, start an assessment or assign checks to a company.

The **Imported** badge on a card shows you already imported that playbook once. Importing again makes another group and another set of checks. Nothing updates in place.

## Edit imported checks

<Steps>
  <Step title="Open Settings > Compliance > Checks">
    Find the imported checks in the folder named in the import message.
  </Step>
  <Step title="Edit the checks">
    Change guidance, status list or other details. See [Compliance settings](/user-guides/settings/compliance).
  </Step>
  <Step title="Review the group">
    Open **Groups** to check the group and its checks before adding it to a run.
  </Step>
</Steps>

Importing a newer catalog version does not update your earlier copies.

For CIS profiles, see [Adding CIS Benchmarks](/user-guides/compliance/adding-cis-benchmarks). For NIS2, see [Adding NIS2 playbooks](/user-guides/compliance/adding-nis2-playbooks). To assess the checks, see the [Compliance guide](/user-guides/compliance/index).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Add** is greyed out and no checkboxes appear | Ask an admin for the `manage_settings_playbooks` permission. |
| **Add to Tenant** in the dialog is disabled | Pick a **Status list** for every playbook. Wait for the lists to load. |
| The import fails with a billing error | Your tenant needs an active billing account to import. |
| You cannot find the imported checks | Look in the folder named in the success message under **Settings > Compliance > Checks**. Check **Groups** before importing again. |
| A bulk import failed partway through | Earlier playbooks in the list may already be imported. Check **Checks** and **Groups** before you retry. |
| The Playbooks tab is missing | Ask an admin for the `read_settings_playbooks` permission. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Add import the playbook right away?">
    No. **Add** on a card opens **Add Playbooks to Tenant**. The import happens when you click **Add to Tenant** in that dialog.
  </Accordion>
  <Accordion title="What does Copy in the details window do?">
    It imports the playbook immediately, with no status list and no device types. Use **Add** on the card to choose them.
  </Accordion>
  <Accordion title="Does importing apply a playbook to one company?">
    No. It adds checks and a group to your tenant library. Company assessments and run assignments are separate.
  </Accordion>
  <Accordion title="Does the Imported badge stop me from importing again?">
    No. Importing again creates a second group and a second set of checks.
  </Accordion>
  <Accordion title="Do the device type choices only filter the list?">
    No. Each selected device type receives the imported group.
  </Accordion>
  <Accordion title="Can I import several playbooks at once?">
    Yes. Tick each card's checkbox and click **Add to Tenant** in the page header. Each playbook gets its own status list and folder.
  </Accordion>
</AccordionGroup>
