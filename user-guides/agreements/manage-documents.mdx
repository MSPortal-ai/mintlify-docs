This guide is for MSP staff. It shows how to add, replace, and delete the PDFs attached to an agreement. The upload stores a file in MSPortal only. It does not change the PSA agreement, billing terms, balance, or signature status.

## Before you start

- You need the **write agreements** permission and an MSP staff account. Company users do not see these controls.
- The agreement must belong to a mapped company. Without one, the upload controls do not appear.
- Use a PDF no larger than 25 MB. The portal uses the file name, without `.pdf`, as the document title, so give it a clear name.
- Anyone who can read that agreement's documents can open the file. There is no separate publish step.

## Upload a PDF

<Steps>
  <Step title="Open the Documents tab">
    Click **Agreements** or **Contracts** in the sidebar, click the agreement's row, then the **Documents** tab. Find **Upload yearly PDF**.
  </Step>
  <Step title="Set Agreement year">
    Choose the year the document belongs to. This only files the PDF. It does not change the agreement's dates.
  </Step>
  <Step title="Choose Version handling">
    Pick **Keep versions** to add the PDF as the next version for that year. Pick **Replace year** to remove that year's active files and start the new PDF as version 1. A notice shows how many active documents will be replaced.

    <img src="/images/product/agreement-document-upload-options.png" alt="MSP agreement PDF upload controls showing Agreement year, Keep versions, Replace year, and Upload PDF" width="1262" height="556" />
  </Step>
  <Step title="Click Upload PDF and pick the file">
    The upload starts as soon as you choose the file, using the year and version handling you set. There is no second Save button.
  </Step>
  <Step title="Check the result">
    Wait for **Document uploaded**. Then check the year, title, version badge, and the document count. Use **Download** to open the file. If an error appears, check the list before you try again.
  </Step>
</Steps>

<Warning>
**Replace year** removes all active versions for that year on this agreement, not just one file. Set the year and mode before you choose a file. Keep copies you need. Use **Keep versions** to retain the existing files.
</Warning>

## Delete one document

<Steps>
  <Step title="Find the file">
    Look in the **Documents** tab for the right year and version.
  </Step>
  <Step title="Click its Delete icon">
    The **Delete document?** dialog opens and names the file.
  </Step>
  <Step title="Click Delete">
    Wait for **Document deleted** and check that the file is gone. Click **Cancel** to keep it.
  </Step>
</Steps>

The file is permanently removed. There is no restore. Deleting a PDF does not delete the agreement, change its status, or touch other years' files.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Upload yearly PDF** is missing | Check you are MSP staff with **write agreements** permission, the feature is on, and the agreement has a mapped company. |
| **Failed to upload document** | Check the file is a PDF under 25 MB, then try again. |
| The wrong year was used | Delete the file and upload it again with the right year. |
| A version disappeared | **Replace year** removes a year's active files. Upload the copy again. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="When does the upload save?">
    As soon as you choose a file after clicking **Upload PDF**. Set the year and version handling first.
  </Accordion>
  <Accordion title="Does changing the year or mode change any files?">
    No. They only set up the next upload.
  </Accordion>
  <Accordion title="What is the difference between Keep versions and Replace year?">
    **Keep versions** adds the next version. **Replace year** removes that year's active files and starts again at version 1.
  </Accordion>
  <Accordion title="Can I upload a Word file or an image?">
    No. Only PDF files, up to 25 MB. Convert the file first.
  </Accordion>
  <Accordion title="Can I recover a replaced or deleted file?">
    No. Keep your own copy.
  </Accordion>
  <Accordion title="Does the upload update my PSA?">
    No. It only stores the PDF in MSPortal.
  </Accordion>
</AccordionGroup>
