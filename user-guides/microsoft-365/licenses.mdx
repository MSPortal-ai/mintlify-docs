Microsoft 365 license inventory lives in **Cloud > Licenses**. Existing `/m365/licenses` links open Cloud Licenses with Microsoft selected. This page is for company users with Microsoft 365 read access and for MSP staff.

## Before you start

- Your role has Microsoft 365 read access.
- The company has a connected Microsoft 365 tenant. MSP staff connect it under [Connecting companies to Microsoft 365](/user-guides/microsoft-365/connecting-companies).

## Review licenses

<Steps>
  <Step title="Open Cloud Licenses">
    Go to **Cloud > Licenses** and select the company you want.
  </Step>
  <Step title="Choose Microsoft 365">
    Set **Provider** to **Microsoft 365** when the column is shown. It is hidden when only one provider is available.
  </Step>
  <Step title="Read the counts">
    Review **Assigned**, **Purchased**, **Available** and **Renews / Expires**. Open **Columns** to add **Status** and **Last synced**.
  </Step>
  <Step title="See who holds a license">
    Select a license row to see its synchronized **Assigned users**. Select one company first so the user list stays specific to it.
  </Step>
</Steps>

The Cloud panel shows counts and assigned users. The older Microsoft-only panel's included-service list and **Load more** control no longer exist.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No licenses appear | Check the company selector and **Provider**. Ask your MSP to check the Microsoft 365 connection and sync. |
| The assigned user list mixes companies | Select one company first. |
| A license shows no seat count | Some licenses report none. They are left out of **Purchased** and **Available**. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I buy or remove seats here?">
    No. Viewing and filtering licenses changes nothing. Ask your MSP through [a support ticket](/user-guides/ticketing/open-a-ticket) to change an assignment or subscription.
  </Accordion>
  <Accordion title="Where did the old Microsoft 365 licenses page go?">
    It moved to **Cloud > Licenses**.
  </Accordion>
</AccordionGroup>
