This guide helps company users with Microsoft 365 read access and MSP staff read one Secure Score recommendation. Company users ask their MSP to make changes.

## Before you start

- Your role has Microsoft 365 read access.
- The company has a synced Secure Score. See [Read Microsoft Secure Score](/user-guides/microsoft-365/index).

## Open and read a control

<Steps>
  <Step title="Find the recommendation">
    Go to **Cloud > Posture > Secure Score** and find it. Use **All** if you do not know its status. See [Find and filter controls](/user-guides/microsoft-365/find-secure-score-controls).
  </Step>
  <Step title="Open it">
    Click its linked **Title**. Clicking elsewhere in the row does not open it.
  </Step>
  <Step title="Read the header">
    In the right-hand panel, read the title, service, status, maximum points, category, severity and implementation cost, when available.
  </Step>
  <Step title="Read Summary and Remediation">
    These start expanded when the source supplies them.
  </Step>
  <Step title="Expand more sections">
    Open **User Impact**, **Remediation Impact**, **Threats**, **Recent Scores** or **History** when they are listed.
  </Step>
  <Step title="Close the panel">
    Select **Close details** or press Escape.
  </Step>
</Steps>

</Frame>

A control can lack some sections, and profile and history details load after the panel opens. A missing section does not mean there is no risk, impact or change. If guidance you expect stays missing, ask your MSP to check the synced source.

## Interpret the evidence

**Remediation** is Microsoft's recommendation. Reading it applies nothing. **Threats** are relevant risks, not detected incidents. **Max Points** is the control's top value, not points you will gain.

**Recent Scores** holds up to 30 stored score records, newest first. **History** holds up to 30 state changes, with Microsoft's comments and who made the change when supplied. Gaps are possible, so they are not one record per day. This panel has no control to edit a status, accept a risk or mark a control completed.

## Choose a follow-up

| Available action | Result |
| --- | --- |
| **Open in Planner**, or a linked Planner item | Opens already linked work when your role can read Planner. |
| **Add to Planner** | Opens an editor for proposed work when allowed. Saving creates work; opening the editor does not. |
| **Add to Meeting** | Opens a dialog to select an existing upcoming company meeting and add an agenda item. |
| **Open in Portal** | Opens the supplied external provider link when available. Provider sign-in and permissions still apply. |

Which actions you see depends on your access, linked records and the source data. Company users should [start with the Home AI Assistant](/user-guides/ticketing/open-a-ticket) to ask their MSP about remediation. Include the control title, company, status and dates. MSP staff can use [planning actions](/user-guides/microsoft-365/plan-secure-score-work).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Clicking the row does nothing | Click the linked **Title**. |
| A section is missing | The source did not supply it. Ask your MSP to check the sync. |
| **Open in Planner** is missing | No Planner item is linked, or you lack Planner read access. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Where do I read remediation instructions?">
    Click the linked Title in Secure Score. Read the Remediation section of the right-hand detail panel when source guidance is available.
  </Accordion>
  <Accordion title="Why does clicking the row not open the control?">
    Use the linked Title. The surrounding row is not the detail-opening control.
  </Accordion>
  <Accordion title="Does an absent User Impact section mean there is no impact?">
    No. Optional sections depend on loaded source information. Missing evidence is not a no-impact result.
  </Accordion>
  <Accordion title="Are Recent Scores always the last 30 days?">
    No. The panel shows up to 30 stored records, newest first; gaps and collection timing can change the date range.
  </Accordion>
  <Accordion title="Can I accept risk or mark the control complete here?">
    The reader has no such status-editing action. Ask the MSP to use the appropriate provider workflow.
  </Accordion>
  <Accordion title="Does Open in Portal automatically remediate the recommendation?">
    No. It opens an external provider page. Authentication, permissions and any actual change happen there.
  </Accordion>
  <Accordion title="Why is Open in Planner missing?">
    It requires an available linked item and Planner read access. A missing link does not prove similar work has not been created.
  </Accordion>
  <Accordion title="How should a Company user request help with a control?">
    Start with the Home AI Assistant. Include the company, exact title, status and relevant dates. Review and submit the prepared support request.
  </Accordion>
</AccordionGroup>
