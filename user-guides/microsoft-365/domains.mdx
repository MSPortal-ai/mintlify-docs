Open **Cloud > Domains** to read Microsoft domain records. Existing `/m365/domains` links open Cloud Domains with Microsoft selected. This page is for company users with Microsoft 365 read access and for MSP staff.

## Before you start

- Your role has Microsoft 365 read access.
- The company has a connected Microsoft 365 tenant. MSP staff connect it under [Connecting companies to Microsoft 365](/user-guides/microsoft-365/connecting-companies).

## Find a domain

<Steps>
  <Step title="Open Cloud Domains">
    Go to **Cloud > Domains**.
  </Step>
  <Step title="Confirm the company">
    Check the company selector at the top.
  </Step>
  <Step title="Choose Microsoft 365">
    Select **Microsoft 365** in **Provider** when the column is shown. It is hidden when only one provider is available.
  </Step>
  <Step title="Find the domain">
    Use the **Domain** filter, then read **Verification**, **Services** and **Authentication**.
  </Step>
  <Step title="Show more columns">
    Open **Columns** to show **Primary** and **Last synced**, then select **Save Changes** to keep the choice.
  </Step>
</Steps>

This page only reads domains. **Primary** marks the current default domain, and there is no separate initial-domain badge or domain-editing action. A Microsoft row with no registrar expiry does not mean the registration never expires. Read the DNSimple row when one exists, or ask your MSP to check the registrar.

## Use the current domain guides

- [Read cloud and registrar domains](/user-guides/cloud/domains): fields, provider differences and summary counts.
- [Find and export domains](/user-guides/cloud/filter-domains): filters and the CSV export of every matching domain.
- [Review domain renewal information](/user-guides/cloud/review-domain-renewals): registrar fields and MSP follow-up.

**Export CSV** needs read access and downloads every matching domain. It has no format chooser, and the table has no column sorting.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No domains appear | Check the company selector and **Provider**. Ask your MSP to check the Microsoft 365 connection and sync. |
| Registrar expiry is blank on a Microsoft row | Read the DNSimple row, or ask your MSP to check the registrar. |
| **Primary** or **Last synced** is missing | Open **Columns** and turn them on. |

## Frequently asked questions

  <Accordion title="Can I change a domain here?">

  </Accordion>
  <Accordion title="Where did the old Microsoft 365 domains page go?">
    It moved to **Cloud > Domains**. Old `/m365/domains` links open it with Microsoft selected.
  </Accordion>
</AccordionGroup>
