This guide helps company users with Microsoft 365 read access and MSP staff find a Secure Score recommendation.

## Before you start

- Your role has Microsoft 365 read access.
- The company has a synced Secure Score. See [Read Microsoft Secure Score](/user-guides/microsoft-365/index).

## Find a recommendation

<Steps>
  <Step title="Open Secure Score">
    Go to **Cloud > Posture > Secure Score** and confirm the company in the top bar.
  </Step>
  <Step title="Choose a view">
    Select **Needs attention**, **Addressed** or **All**. Use **All** if you do not know the control's status.
  </Step>
  <Step title="Search by title">
    Type part of the control name into the **Title** column filter.
  </Step>
  <Step title="Add more filters">
    Combine the **Category**, **Service**, **Severity**, **Max Points** and **Status** filters. Views that cover several companies also show a **Company** filter.
  </Step>
  <Step title="Open the control">
    Click the control's **Title**.
  </Step>
  <Step title="Clear the filters">
    Select **Clear Filters** to remove the table filters. This does not change the view, so switch from **Needs attention** to **All** yourself if you need to.
  </Step>
</Steps>

For example, Completed has no results inside **Needs attention**. Switch to **Addressed** or **All** before you filter for it. An unusual Microsoft state can show its original wording and still count as Unknown.

## Sort and move through results

Use the sortable column headings to change the order. The table shows 20 rows per page, with paging controls below it. MSPortal loads at most 5,000 controls for the selected companies. Filters, view counts and the CSV export all work on that loaded set, so a broad view may not hold every matching control. Select one company for a focused review.

The counts beside **Needs attention**, **Addressed** and **All** count loaded controls before column filters, so they can be larger than your filtered list. The **Severity** filter lists Low, but no control currently maps to Low.

## Select controls for an MSP action

Checkboxes pick rows for actions. Filters decide which rows you see. The header checkbox selects the current page only. Before a bulk action, clear old selections, filter to one company and check the rows and the selection count. Changing a column filter can leave earlier rows checked. Switching the view clears all selections.

For MSP actions, see [Plan work from Secure Score](/user-guides/microsoft-365/plan-secure-score-work). Row selection does not limit a CSV export.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A control is missing | Switch to **All**, then clear the column filters. |
| The view count is larger than the list | The count is before column filters. |
| Few controls show for a large portfolio | Select one company. Only the first 5,000 controls load. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why can I not find a completed recommendation?">
    The default Needs attention view excludes Completed. Switch to Addressed or All, then check the Title and other column filters.
  </Accordion>
  <Accordion title="Can I filter for more than one status?">
    Yes. Status allows multiple selections, but results must also belong to the active view.
  </Accordion>
  <Accordion title="Why is the view count larger than the filtered list?">
    View counts describe loaded controls before column filters. The filtered table can contain fewer records.
  </Accordion>
  <Accordion title="Does Clear Filters change the active view?">
    No. Check Needs attention, Addressed or All separately. Clear Filters resets table filters.
  </Accordion>
  <Accordion title="Does the header checkbox select every matching control?">
    No. It selects rows on the current page. Review selections before using bulk actions.
  </Accordion>
  <Accordion title="Can filters search every control across a large portfolio?">
    The page currently loads at most 5,000 controls for its scope. Filters operate on that loaded set. Select a company to narrow the review.
  </Accordion>
  <Accordion title="Why is Low severity empty?">
    Low is an available filter option, but the current tier mapping assigns Critical, High, Medium or Informational.
  </Accordion>
  <Accordion title="Do selected checkboxes limit Export CSV?">
    No. CSV uses the active view and column-filtered loaded rows across table pages, independently of checkboxes.
  </Accordion>
</AccordionGroup>
