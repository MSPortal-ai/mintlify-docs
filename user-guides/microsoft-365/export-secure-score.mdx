This guide is for MSP staff with Microsoft 365 management permission. Read access alone does not show **Export CSV**. Company users can ask their MSP for an export.

## Before you start

- You have Microsoft 365 management permission.
- The company has a synced Secure Score. See [Read Microsoft Secure Score](/user-guides/microsoft-365/index).

## Download a CSV

<Steps>
  <Step title="Open Secure Score">
    Go to **Cloud > Posture > Secure Score** and confirm the company in the top bar.
  </Step>
  <Step title="Choose a view">
    Select **Needs attention**, **Addressed** or **All**.
  </Step>
  <Step title="Filter the rows">
    Apply the column filters for the records you need.
  </Step>
  <Step title="Export">
    Select **Export CSV** and wait for the browser download.
  </Step>
  <Step title="Check the file">
    Open it in a spreadsheet and check the company, statuses and rows before you use it.
  </Step>
</Steps>

The file holds the filtered rows across all table pages. Checked rows and the 20-row page size do not limit it. MSPortal loads at most 5,000 controls for the selected companies and cannot export what it has not loaded, so export one company at a time for a large portfolio.

## CSV fields

The English export has these ten fields, even if some corresponding columns are hidden in the table:

| Field | Meaning |
| --- | --- |
| Company | Associated company name. |
| Title | Recommendation title. |
| Category | Security category. |
| Service | Related Microsoft service. |
| Severity | Tier-derived priority label. |
| Status | Displayed state; an unrecognized Microsoft state can keep its provider wording. |
| Current Score | Stored points currently achieved for the control. |
| Max Points | Maximum points for that control, not remaining improvement. |
| Tier | Underlying recommendation tier when supplied. |
| Implementation Cost | Provider's implementation-cost value when supplied. |

The CSV holds table data only. It leaves out remediation text, detail history and summary cards. Use [Read a Secure Score control](/user-guides/microsoft-365/read-secure-score-control) for supporting evidence.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Export CSV** is missing | You need Microsoft 365 management permission. Ask an MSP administrator. |
| Rows are missing from the file | Check the view and column filters, and select one company to stay under the 5,000-control limit. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why can I read Secure Score but not export it?">
    Export CSV requires Microsoft 365 management permission. Ask the MSP to review access or provide the export.
  </Accordion>
  <Accordion title="Does the CSV contain only the selected rows?">
    No. It includes the active view’s filtered loaded rows, independently of checkboxes.
  </Accordion>
  <Accordion title="Does the export stop at the current table page?">
    No. It includes filtered loaded rows across pagination. It remains bounded by the reader’s 5,000-control load limit.
  </Accordion>
  <Accordion title="Does hiding a column remove it from the CSV?">
    No. The export has a fixed set of ten fields.
  </Accordion>
  <Accordion title="Can I download remediation and history in this CSV?">
    No. Those details are not among the export fields. Open the control panel to read them.
  </Accordion>
  <Accordion title="Is Max Points the improvement I will gain?">
    No. It is the control’s maximum value. Some points may already be achieved, and actual changes depend on Microsoft’s subsequent assessment.
  </Accordion>
</AccordionGroup>
