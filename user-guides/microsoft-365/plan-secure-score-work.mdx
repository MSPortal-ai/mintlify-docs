This guide is for MSP staff. It shows how to turn Secure Score controls into Planner work, meeting agenda items and PSA tickets. Company users [start with the Home AI Assistant](/user-guides/ticketing/open-a-ticket) to ask their MSP for help.

## Before you start

- You have access to Secure Score for the company. See [Read Microsoft Secure Score](/user-guides/microsoft-365/index).
- Planner items need Planner write or management permission.
- Agenda changes need Calendar write access.
- PSA tickets need ticket-creation permission and a configured, mapped PSA connection.

## Choose the company and controls

<Steps>
  <Step title="Open Secure Score">
    Go to **Cloud > Posture > Secure Score**.
  </Step>
  <Step title="Scope the list">
    Select one company in the top bar, choose a view and filter the list.
  </Step>
  <Step title="Select the controls">
    Clear old checkbox selections, then check the controls you want. The header checkbox selects the current page only.
  </Step>
  <Step title="Check the selection">
    Confirm the company and the selection count. These bulk actions need controls from one company.
  </Step>
  <Step title="Open Actions">
    Choose the action for the result you need.
  </Step>
</Steps>

<Frame caption="MSP actions available in this example. Permissions and destination setup affect what you can use.">
  <img src="/images/product/secure-score-actions-menu.png" alt="Add to Meeting, Add to Planner, Create Individual Tasks and Create Tickets actions." width="448" height="276" />
</Frame>

| Action | What happens |
| --- | --- |
| **Add to Planner** | Opens one proposed Planner item for the selected controls. Review and save it. |
| **Create Individual Tasks** | Immediately creates separate Planner items, one per selected control. There is no review editor or second confirmation. |
| **Add to Meeting** | Opens a dialog for adding controls to an existing upcoming company meeting. |
| **Create Tickets** | Opens a reason-and-review dialog for separate PSA tickets, up to 25 controls per submission. |

These actions create coordination work. They do not change Microsoft security settings, automatically mark a control Planned or Completed, or immediately increase the score.

## Create one Planner item

<Steps>
  <Step title="Start the proposal">
    For one control, open its **Title**, then select **Add to Planner**. For several, select the rows and choose **Actions > Add to Planner**.
  </Step>
  <Step title="Review the fields">
    Check the proposed title, company, description, type, status, business value, effort, cost, due date and notes. You can also set the assignee, dates, visibility, links and custom fields. All of them are saved.
  </Step>
  <Step title="Check the points wording">
    The generated text uses each control's maximum points, which can overstate the gain when some points are already achieved. Edit it if needed.
  </Step>
  <Step title="Save">
    Select **Save** when ready. Close the editor to leave without creating the item, and answer any unsaved-changes prompt.
  </Step>
  <Step title="Check the result in Planner">
    Open the new item and check its content, control links, dates and visibility.
  </Step>
</Steps>

The item and its control links are saved together. If you see an error, the editor stays open and nothing is saved, so you can fix the problem and click **Save** again.

## Create separate Planner tasks

Use **Actions > Create Individual Tasks** only after confirming the selected company and rows. It creates one item per selected control immediately, with a security-prefixed title, recommendation content and a Not Started status. Review and finish the details in Planner afterward.

The current individual-task path does not add the same control links as Add to Planner. Find the created work in Planner by its title; do not depend on a link appearing back in the Secure Score table.

## Add controls to an upcoming meeting

<Steps>
  <Step title="Open the dialog">
    Use a control's **Add to Meeting**, or select rows and choose **Actions > Add to Meeting**.
  </Step>
  <Step title="Check the controls">
    Confirm the controls and the company.
  </Step>
  <Step title="Choose a meeting">
    Pick an existing upcoming meeting. The picker lists up to the next 50 meetings for that company and no past ones.
  </Step>
  <Step title="Add it">
    Review the agenda, then select **Add to Agenda**.
  </Step>
  <Step title="Check the agenda">
    Wait for the success message, then open the meeting and look for the new items.
  </Step>
</Steps>

The dialog does not create a meeting. If none is listed, cancel and arrange one in Calendar first. Controls become agenda items and are not remediated. Calendar permission is checked when you submit, so a visible action can still fail to save.

## Create PSA tickets

<Steps>
  <Step title="Select the controls">
    Select up to **25 controls from one company**, then choose **Actions > Create Tickets**.
  </Step>
  <Step title="Check the destination">
    Confirm the controls, company and connected provider. ConnectWise, HaloPSA and Autotask are supported when configured and mapped.
  </Step>
  <Step title="Give a reason">
    Enter why you are creating the tickets. It is required and can be up to 5,000 characters.
  </Step>
  <Step title="Fix any warning">
    Resolve a missing company mapping or PSA default first. You cannot pick a board, queue or category here, so your configured defaults apply.
  </Step>
  <Step title="Submit">
    Select **Create Tickets** and wait for the result.
  </Step>
  <Step title="Verify the tickets">
    Check the PSA before you retry anything. A batch can partly succeed, and an email fallback is not a confirmed PSA ticket.
  </Step>
</Steps>

Each control creates its own ticket. A fallback or failure can stop the rest of the batch. Never resubmit the whole selection after a partial success without checking for existing tickets.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| An action is missing from **Actions** | You lack the permission it needs, or the destination is not set up. |
| **Add to Meeting** lists no meetings | Arrange an upcoming meeting for that company in Calendar first. |
| A ticket batch shows an error | Check the PSA for tickets that were created before you retry. |
| Different companies are selected | These actions need one company. Clear the selection and start again. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What is the difference between Add to Planner and Create Individual Tasks?">
    Add to Planner opens one editable proposal for the selected controls. Create Individual Tasks immediately creates separate items without a review dialog.
  </Accordion>
  <Accordion title="Does opening the Planner editor create an item?">
    No. Saving creates the item. Review the result and control links in Planner after success.
  </Accordion>
  <Accordion title="Does creating work change the Microsoft control status?">
    No. Planner work, meeting agenda items and PSA tickets do not automatically change Microsoft’s state or security configuration.
  </Accordion>
  <Accordion title="Can I combine controls from different companies?">
    These bulk workflows require one company. Narrow the scope, clear previous selections and verify the selected rows.
  </Accordion>
  <Accordion title="Why did individual tasks not appear as Planner links?">
    The current individual-task creation path does not add the control links used by Add to Planner. Find the work by its title in Planner.
  </Accordion>
  <Accordion title="What should I do after a Planner save error?">
    Click **Save** again. The editor stays open after an error and nothing was saved, so a retry does not duplicate work.
  </Accordion>
  <Accordion title="Can Add to Meeting create a new meeting?">
    No. Select an existing upcoming company meeting. If none is available, cancel and arrange it in Calendar first.
  </Accordion>
  <Accordion title="Why is a past meeting absent from the picker?">
    The dialog lists upcoming meetings only, up to the next 50 available for the company.
  </Accordion>
  <Accordion title="Which PSA providers can receive Secure Score tickets?">
    ConnectWise, HaloPSA and Autotask, with a configured integration, company mapping and required defaults.
  </Accordion>
  <Accordion title="How many tickets can I create at once?">
    Select up to 25 controls from one company. Each control creates a separate request, and the reason is required.
  </Accordion>
  <Accordion title="Should I retry the whole batch after some tickets fail?">
    First check the destination for successful tickets. Retry only confirmed failures; partial success or an email fallback is possible.
  </Accordion>
  <Accordion title="Do all the fields in the Planner editor save?">
    Yes. Assignee, dates, visibility, costs, links and custom fields are saved with the item.
  </Accordion>
</AccordionGroup>
