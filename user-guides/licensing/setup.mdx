This is an **MSP staff** setup task. Connect Pax8 to import distributor data, then configure what clients may see or request. Connecting a distributor does not automatically grant purchasing access.

## Connect Pax8

Use the current [Configure Pax8 Integration](/user-guides/integrations/enable-pax8-integration) guide for the full setup sequence and reconnect/removal instructions. You need integration management access and authority to approve Pax8 OAuth.

1. Open **Settings > Integrations**, select the intended Pax8 connection and complete **Connect to Pax8**.
2. On **Sync Settings**, decide whether to enable **Pax8 Invoices**. The switch saves immediately and enabling it requests invoice synchronization.
3. On **Map Companies**, review Quick Match suggestions or select companies manually. **Import Selected** or **Next** saves pending mappings. Creating a new company and unlinking an existing mapping have separate immediate effects.
4. On **Complete**, request **Sync Subscriptions** when needed, then inspect the imported subscriptions in **Storefront**. A started sync is not a completed import.

## Verify the result and configure access

Check the intended provider account, saved company mappings and each company's available subscription data. Map newly discovered companies as needed. Provider data and background completion determine what appears.

Use [Storefront](/user-guides/storefront/index) for the buying and subscription workflow, and [Licensing](/user-guides/licensing/index) for the related approval, catalog and self-service settings. Configure those rules deliberately before offering client purchasing.

For Microsoft 365, Google Workspace or Adobe license counts and assignments, open **Cloud > Licenses**. The former `/licensing` inventory route opens Cloud Licenses; distributor setup is a separate task.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| OAuth does not complete | Pax8 account authority, sign-in/MFA/consent and return to the correct connection. |
| No companies or subscriptions | Discovery outcome, saved company mappings and the specific subscription sync result. |
| Invoices are absent | The optional invoice-sync setting, source invoices and completed background sync. |
| Clients cannot purchase | Company access, catalog visibility and approval/self-service rules; OAuth alone does not enable purchasing. |
| Data remains stale | Connection and sync errors; use the provider setup guide before requesting another sync or reconnect. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Is Pax8 setup still a three-step licensing wizard?">
    The current provider sequence includes Connect, Sync Settings, Map Companies and Complete. Follow Configure Pax8 Integration for the current controls.
  </Accordion>
  <Accordion title="Does Quick Match save company mappings?">
    No. Review pending proposals, then save with Import Selected or Next. Creating a new MSPortal company does not itself save its pending provider link.
  </Accordion>
  <Accordion title="Do I need a final Save for the Pax8 Invoices switch?">
    No. It saves immediately. Enabling it requests invoice sync, whose outcome must be checked separately.
  </Accordion>
  <Accordion title="Does completing setup let every client purchase licenses?">
    No. Configure role/company access, catalog visibility, approvals and self-service rules separately.
  </Accordion>
  <Accordion title="Where do I find Microsoft 365 license assignments?">
    Open Cloud > Licenses and use the cloud license guide. Pax8 setup and Storefront subscription purchasing are separate workflows.
  </Accordion>
  <Accordion title="Does removing Pax8 in MSPortal cancel its subscriptions?">
    No. It removes the MSPortal connection and associated synchronized data. Subscription cancellation is a separate provider operation.
  </Accordion>
</AccordionGroup>
