**Audience:** MSP staff with permission to manage Documentation settings. Company users read the content you make available to them.

Use **Documentation > Documents** to create portal pages and upload files. A Hudu or IT Glue integration is not required for native portal documents.

## Create a page

<Steps>
  <Step title="Open the editor">
    Select **New page** in the Documents header.
  </Step>
  <Step title="Choose the title and scope">
    Enter a **Page title**. Select **Company** for company-specific content or leave **Global page** for a page without a company assignment. Choose a custom **Folder**, or leave **Unfiled**.

    Scope and role visibility are separate. Review the document's audience in Documentation settings; a global page is not a private personal draft.
  </Step>
  <Step title="Write the page">
    Enter the **Body** and use the formatting toolbar for text styles, lists, links, and supported images. Review the content and selected company before creating it.
  </Step>
  <Step title="Create and verify">
    Select **Create page** and wait for confirmation. Open the saved page from Documents to verify its content and access. **Cancel** closes the editor without creating the page.
  </Step>
</Steps>

## Upload a file

Select **Upload** in Documents. Choose a DOCX, XLS, XLSX, PDF, or CSV file, set the company and folder as appropriate, and complete the upload. Wait for confirmation before leaving.

The document list identifies it as a **File**. Open its **Preview** to check the result or download the original. A preview may simplify formatting or limit spreadsheet rows; it does not replace the original file.

## Make files easy to find in the Documentation Hub

After uploading a file, add it to the **Documentation Hub** as a **Document** resource in **Settings > Documentation > Hub**. You can also add a **Folder** resource for a collection of documents, or a **Link** resource for a file stored in an external service.

See [Add files and links to the Documentation Hub](/user-guides/documentation/add-files-and-links-to-hub). Uploading a file to Documents and adding it to the Hub are separate steps.

## Organize folders and documents

Select **New folder**, enter its name, and choose the company and parent folder when needed. Select **Create** to save it.

For an editable portal document, use its row's **Document actions > Move to folder…** control to choose a destination. You can also drag an editable portal document into a custom folder. Moving a document saves the folder change; it is not a staged layout preference.

Provider folders and documents have different ownership. Manage their organization in the connected documentation provider when the portal does not offer an edit action.

When deleting a custom folder, read the confirmation: nested folders are included, and their documents move to **Unfiled**. Deleting a folder does not delete the documents it contained.

## Edit a page and review history

Open an editable native page and select **Edit**. Make the changes and select **Save**. Saved edits create document revisions.

Select **Revisions** to view history. **Restore** restores the selected content by creating another revision; it does not erase the revision history. If the page changed while you were editing, reload the current version and reconcile your changes before saving again.

## FAQs

<AccordionGroup>
  <Accordion title="Why are New page or Upload missing?">
    These controls require MSP documentation-management access. Company users do not create or upload portal documents from this screen.
  </Accordion>
  <Accordion title="Does selecting a company make a page visible to every user in that company?">
    Company scope identifies which company's content it is. Visibility rules and the user's documentation permissions still determine access. Review the audience in Documentation settings.
  </Accordion>
  <Accordion title="Is an unsaved page automatically saved?">
    No. Use **Create page** for a new page or **Save** for an edit. Closing or canceling the editor does not submit the form.
  </Accordion>
  <Accordion title="Can I edit a synced Hudu or IT Glue article with this editor?">
    The native editor is for editable portal content. Provider articles are managed in their source system; do not assume a portal edit action is available for them.
  </Accordion>
  <Accordion title="Does deleting a folder delete its files?">
    Custom-folder deletion moves the contained documents to Unfiled and includes nested folders. Review the confirmation before applying it.
  </Accordion>
  <Accordion title="Can I recover a previous version of a page?">
    Open **Revisions** on an editable native document and select **Restore** on the version you need. The restore creates a new revision.
  </Accordion>
  <Accordion title="Does copying a document URL create a public sharing link?">
    No. A normal portal URL retains access checks. Public provider sharing is a separate action and can change visibility in the provider itself.
  </Accordion>
</AccordionGroup>
