Use this page to create pages, upload files, and keep portal documents organized. It is for MSP staff with permission to manage Documentation settings. Company users read what you make available to them.

## Before you start

- You need permission to manage Documentation settings. **New page**, **Upload**, and **New folder** only appear for MSP staff with that access.
- Portal documents do not need Hudu or IT Glue.

## Create a page

<Steps>
  <Step title="Open the editor">
    Open **Documentation > Documents** and click **New page** in the header.
  </Step>
  <Step title="Choose the title and scope">
    Enter a **Page title**. Choose a **Company** for company-specific content, or leave **Global page** for a page with no company. Choose a custom **Folder**, or leave **Unfiled**.
  </Step>
  <Step title="Write the page">
    Type the **Body**. Use the toolbar for text styles, lists, links, and supported images. Check the content and the selected company.
  </Step>
  <Step title="Create the page">
    Click **Create page**. MSPortal shows **Page created**. **Cancel** closes the editor without creating anything.
  </Step>
  <Step title="Verify">
    Open the page from Documents and check its content and who can see it.
  </Step>
</Steps>

  <img src="/images/product/documentation-new-page.png" alt="New page editor with an example title and body, company and folder selectors, and Cancel and Create page controls." width="1792" height="1424" />

The company setting says whose page it is. Visibility rules decide who can read it, so check the audience in Documentation settings. A global page is not a private draft.

## Upload files

<Steps>
  <Step title="Open the upload dialog">
    Open **Documentation > Documents** and click **Upload**. The **Upload documents** dialog opens. You can add several files at once, and each file becomes its own document.
  </Step>
  <Step title="Add files">
    Click to upload, or drag files onto the drop area. DOCX, XLS, XLSX, PDF, and CSV files up to 50 MB each are accepted. A message names any file of another type or over 50 MB, and it is not added.
  </Step>
  <Step title="Check the names">
    Each file is listed with a document name taken from its file name. Edit a name, or click the **X** beside a file to remove it.

    <Frame caption="Three files queued for upload, before Upload is clicked.">
      <img src="/images/product/documentation-upload-multiple-files-preview.png" alt="Upload documents dialog with a drop area, three queued CSV files with editable document names, shared Company and Folder selectors, and an Upload 3 files button." width="1440" height="960" />
    </Frame>
  </Step>
  <Step title="Choose company and folder">
    **Company** and **Folder** apply to every file in this upload. To file documents in different places, upload them in separate batches.
  </Step>
  <Step title="Upload">
    Click **Upload N files** (or **Upload 1 file**). Each file shows **Uploading**, then **Uploaded**. When all files succeed, the dialog closes and shows a confirmation.
  </Step>
</Steps>

If a file fails, it is marked **Failed** and the dialog stays open. The files that worked are already saved. Click **Upload** again to retry the failed files, or remove them.

**Settings > Documentation > Documents** opens the same dialog from **Upload file**.

The document list marks each upload as a **File**. Open it to check the result. The file shows on the page, and **Download** in the page header gets the original. The page can simplify formatting or limit spreadsheet rows, so download the original when you need the exact layout.

## Replace an uploaded file

<Steps>
  <Step title="Open the document">
    Open the uploaded file's document page.
  </Step>
  <Step title="Click Replace file">
    Click **Replace file** in the page header and choose the new DOCX, XLS, XLSX, PDF, or CSV file.
  </Step>
  <Step title="Confirm">
    MSPortal shows **File replaced**. The document keeps its name, company, folder, and sharing, and the new file shows on the page.
  </Step>
</Steps>

Each replacement is a new revision. Click **Revisions** to see earlier versions and **Restore** one to bring the earlier file back. If someone changed the document while you were working, MSPortal tells you and reloads it. Try again.

## Put a file in the Documentation Hub

After you upload a file, add it to the Hub as a **Document** resource in **Settings > Documentation > Hub**. You can also add a **Folder** resource for a collection, or a **Link** resource for a file stored elsewhere. See [Add files and links to the Documentation Hub](/user-guides/documentation/add-files-and-links-to-hub). Uploading and adding to the Hub are separate steps.

## Organize folders and documents

<Steps>
  <Step title="Create a folder">
    Click **New folder**, enter a **Name**, and choose the company and **Parent folder** if needed. Click **Create**. MSPortal shows **Folder created**.
  </Step>
  <Step title="Move a document">
    Open the **Document actions** menu on an editable portal document's row, choose **Move to folder…**, and pick a destination. You can also drag the document into a folder in the folder list. The move saves right away.
  </Step>
  <Step title="Delete a folder (optional)">
    Open **Folder actions** on a custom folder and choose **Delete folder**. Read the confirmation. Nested folders are deleted too, and their documents move to **Unfiled**. The documents themselves are not deleted.
  </Step>
</Steps>

Provider folders and documents belong to the provider. Manage them in Hudu or IT Glue when the portal offers no edit action.

## Edit a page and review history

<Steps>
  <Step title="Edit the page">
    Open an editable portal page and click **Edit**. Change the **Page title** or **Body**, then click **Save**. Saving creates a new revision.
  </Step>
  <Step title="Review the history">
    Click **Revisions** to see the **Revision history**.
  </Step>
  <Step title="Restore a version">
    Click **Restore** on the version you want. Restoring creates a new current revision. It does not erase history.
  </Step>
</Steps>

If the page changed while you were editing, reload the current version and merge your changes before you save again.

## Archive and restore a page

<Steps>
  <Step title="Archive">
    On a portal page's row menu (**Document actions**) or in its page header, click **Archive** and confirm **Archive page?**. The page is hidden from active documentation. Its content, revisions, and sharing settings are kept.
  </Step>
  <Step title="Find archived pages">
    In **Documentation > Documents**, change the **Document view** selector to **Archived pages**.
  </Step>
  <Step title="Restore">
    Click **Restore** on the page and confirm **Restore page?**. The page returns with its earlier sharing settings.
  </Step>
</Steps>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **New page**, **Upload**, or **New folder** is missing | You need Documentation management access as MSP staff. Ask your MSP admin. |
| A file is not added | It is not a DOCX, XLS, XLSX, PDF, or CSV, or it is over 50 MB. The message names it. |
| **Failed** beside a file | Click **Upload** again to retry. Files that already worked are saved. |
| **Couldn't replace the file** | Try again. If the document changed meanwhile, reload it first. |
| **Failed to move document** | Reload the page and try again. |
| A provider article has no Edit button | Provider articles are managed in Hudu or IT Glue. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does choosing a company make a page visible to everyone in that company?">
    No. The company says whose content it is. Visibility rules and each user's permissions still decide access.
  </Accordion>
  <Accordion title="Is an unsaved page saved automatically?">
    No. Click **Create page** for a new page or **Save** for an edit. Closing the editor discards it.
  </Accordion>
  <Accordion title="Can I edit a synced Hudu or IT Glue article here?">
    No. Edit it in its source system.
  </Accordion>
  <Accordion title="Does deleting a folder delete its files?">
    No. Its documents move to **Unfiled**. Nested folders are deleted with it.
  </Accordion>
  <Accordion title="Can I recover a previous version of a page?">
    Yes. Open **Revisions** and click **Restore** on the version you need.
  </Accordion>
  <Accordion title="Does copying a document URL create a public link?">
    No. A normal portal URL keeps its access checks.
  </Accordion>
</AccordionGroup>
