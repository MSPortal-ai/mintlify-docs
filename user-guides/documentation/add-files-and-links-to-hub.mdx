**Audience:** MSP staff with permission to manage Documentation settings. Company users browse the resources you make available to them.

## Are we able to add files somewhere in MSPortal or link to files?

Yes. The **Documentation Hub** gives clients one place to find files and links. Upload a file in **Documentation > Documents**, then add it to the Hub as a **Document** resource. For a file stored elsewhere, add a **Link** resource with its sharing URL in **Settings > Documentation > Hub**. You can also add folders and portal pages. Hudu or IT Glue is not required for native portal content or external links.

The Hub is also called the **resource hub**. Its displayed title is customizable, so your portal may call it **Important Info** or another name.

## Enable the Hub

Open **Settings > Documentation > Hub**. Turn on **Enable hub**, enter a **Title**, and choose **Navigation placement**. The Hub can appear on the main Documentation page, as a standalone page, or as the Company Overview sidebar item. Select **Save hub** to save these settings.

## Upload a file and add it to the Hub

<Steps>
  <Step title="Upload the file to Documents">
    Open **Documentation > Documents** and select **Upload**. Choose a DOCX, XLS, XLSX, PDF, or CSV file, set its company and folder as appropriate, and complete the upload. See [Create and maintain portal documents](/user-guides/documentation/create-portal-documents) for the full upload workflow.
  </Step>
  <Step title="Add a Document resource">
    Return to **Settings > Documentation > Hub**. In **Page layout**, use the **+** (Add resource) control in Featured or the section where you want the file to appear, then choose **Document**. Search for and select the uploaded file. Existing portal pages and shared provider documents can also be selected.
  </Step>
  <Step title="Choose the audience and save">
    Review **Company** and **Who can see this**, then select **Add resource**. Wait for confirmation. Open the Hub to check its placement and review access for the intended audience.
  </Step>
</Steps>

Uploading a file adds it to Documents; adding a Hub resource makes it easy to find from the Hub. These are separate steps. To feature a collection instead of one file, choose **Folder** when adding a resource and select the folder.

## Link to a file stored elsewhere

<Steps>
  <Step title="Copy the file's sharing URL">
    Get the web link from the service where the file is stored, such as SharePoint, OneDrive, or Google Drive. Make sure the intended recipients have access in that service.
  </Step>
  <Step title="Add a Link resource">
    In **Settings > Documentation > Hub**, use **+** (Add resource) in Featured or a section and choose **Link**. Enter a descriptive **Link title** and paste the sharing link into **URL**. You can also add a description and choose an icon.
  </Step>
  <Step title="Choose the audience and save">
    Set **Company** and **Who can see this**, then select **Add resource**. Wait for confirmation and check the link from the Hub.
  </Step>
</Steps>

A Link resource opens its destination in a new tab. It does not upload, copy, or sync the external file into MSPortal. The destination still controls access and may require a separate sign-in.

## Saving and visibility

- **Save hub** saves Hub settings such as its title, enabled state, and navigation placement.
- **Add resource** saves a new resource; **Save changes** saves edits to an existing resource.
- Layout changes, including resource placement and section edits, save automatically. Wait for saving to finish before leaving.
- Review both company scope and audience. A Link resource with no audience selected is hidden; a Document or Folder resource with no audience selected follows the linked content's visibility.
- If the Hub is missing, check **Enable hub**, its navigation placement, and the user's access. Company users do not manage Hub resources themselves.
