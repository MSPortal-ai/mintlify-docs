Use this page to put files, documents, folders, and links in one place for your clients. It is for MSP staff. Company users browse what you make available to them.

The **Documentation Hub**, also called the resource hub, lets clients find files and links in one place. Its title is yours to choose, so your portal might call it **Important Info**. Hudu or IT Glue is not required for portal pages, uploaded files, or external links.

## Before you start

- You need permission to manage Documentation settings.
- To add an uploaded file, upload it to **Documentation > Documents** first. See [Create and maintain portal documents](/user-guides/documentation/create-portal-documents).
- To link to a file stored elsewhere, have its sharing URL ready, and make sure the people who need it have access in that service.

## Enable the Hub

<Steps>
  <Step title="Open Hub settings">
    Open **Settings > Documentation** and click the **Hub** tab.
  </Step>
  <Step title="Turn it on">
    Turn on **Enable hub**. This shows the hub tab and lets resources appear.
  </Step>
  <Step title="Name it and place it">
    Enter a **Title**. Under **Navigation placement**, choose **Main Documentation page**, **Standalone page**, or **Use as the Company Overview sidebar item**.
  </Step>
  <Step title="Save">
    Click **Save hub**. MSPortal shows **Hub settings saved**.
  </Step>
</Steps>

## Upload a file and add it to the Hub

<Steps>
  <Step title="Upload the file to Documents">
    Open **Documentation > Documents** and click **Upload**. Choose a DOCX, XLS, XLSX, PDF, or CSV file, set its company and folder, and finish the upload.
  </Step>
  <Step title="Open Page layout">
    Return to **Settings > Documentation > Hub** and find **Page layout**.
  </Step>
  <Step title="Add a Document resource">
    Click **+** (Add resource) in **Featured** or in the section where the file should appear, and choose **Document**. Search for the file and select it. You can also pick an existing portal page or a shared provider document.
  </Step>
  <Step title="Choose the audience">
    Review **Company** and **Who can see this**.
  </Step>
  <Step title="Save the resource">
    Click **Add resource** and wait for the confirmation. Open the Hub and check the placement.
  </Step>
</Steps>

Uploading a file adds it to Documents. Adding a Hub resource makes it easy to find from the Hub. These are two separate steps. To feature a whole collection, choose **Folder** instead and select the folder.

## Link to a file stored elsewhere

<Steps>
  <Step title="Copy the sharing URL">
    Get the web link from the service that stores the file, such as SharePoint, OneDrive, or Google Drive.
  </Step>
  <Step title="Add a Link resource">
    In **Settings > Documentation > Hub**, click **+** (Add resource) in **Featured** or a section and choose **Link**.
  </Step>
  <Step title="Fill in the link">
    Enter a **Link title**, paste the sharing link into **URL**, and add a **Description** and an icon if you like. The URL must be valid, such as `https://example.com`.
  </Step>
  <Step title="Choose the audience and save">
    Set **Company** and **Who can see this**, then click **Add resource**. Check the link from the Hub.
  </Step>
</Steps>

A Link resource opens in a new tab. It does not copy or sync the file into MSPortal. The other service still controls access and can ask for its own sign-in.

## Organize the Hub

<Steps>
  <Step title="Add a section">
    In **Page layout**, click **Add section** and enter a **Section title**. Choose a layout, column count, accent, and icon if you like.
  </Step>
  <Step title="Place resources">
    Drag resources into **Featured** or a section. Resources that are not placed show under **Unassigned resources**, and clients see them under **More resources**.
  </Step>
  <Step title="Edit or remove a resource">
    Use **Edit resource** to change a resource and click **Save changes**. Use **Remove resource** to take it off the hub. Removing a section moves its resources to **Unassigned resources**, and nothing is deleted.
  </Step>
</Steps>

## Saving and visibility

- **Save hub** saves the hub's title, enabled state, and placement.
- **Add resource** saves a new resource. **Save changes** saves edits to an existing one.
- Layout changes save on their own. Wait for the save to finish before you leave the page.
- A Link with no audience selected is hidden from everyone. A Document or Folder with no audience selected follows the visibility of its content.
- A resource whose source page or folder was removed shows **Source content removed** and does not appear on the client hub. Edit it to point at other content, or remove it.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The Hub is missing | Check **Enable hub**, its **Navigation placement**, and the user's access. |
| A link is hidden | Edit the resource and choose **Who can see this**. A link with no audience is hidden. |
| **Enter a valid URL, for example https://example.com.** | The URL must start with `https://` or `http://`. |
| **Resource saved, but it couldn't be placed in the layout.** | Find the resource under **Unassigned resources** and drag it into place. |
| The file does not show in the Hub | Make sure you added it as a **Document** resource. Uploading alone does not add it. |
| Company users cannot see a resource | Check the **Company** and **Who can see this** settings on the resource. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can we add files somewhere in MSPortal or link to files?">
    Yes. Upload a file in **Documentation > Documents** and add it to the Hub as a **Document** resource, or add a **Link** resource that points to a file stored elsewhere.
  </Accordion>
  <Accordion title="Does a Link resource copy the file into MSPortal?">
    No. It opens the other service in a new tab. That service controls access.
  </Accordion>
  <Accordion title="Do I need Hudu or IT Glue?">
    No. Portal pages, uploads, and links work without a provider.
  </Accordion>
</AccordionGroup>
