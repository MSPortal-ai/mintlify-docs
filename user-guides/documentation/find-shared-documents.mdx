**Audience:** Company users and MSP staff reading documentation available to their account.

Your MSP decides which documents you can access. The **Documents** tab can include pages and uploaded files created in the portal, plus documents shared from Hudu or IT Glue. Native portal documents do not require either provider integration.

## Find a document

<Steps>
  <Step title="Open Documents">
    Select **Documentation > Documents** (`/documentation?tab=documents`). If you can access multiple companies, check the company selector first.
  </Step>
  <Step title="Choose a folder or search">
    Select a folder in the folder sidebar to narrow the list. **All Documents** clears the folder selection; **Unfiled Documents** shows items without a folder.

    Use the **Name** column filter to search document titles. Check any other table filters if an expected item is missing. Changing company scope resets the current folder and document filters.
  </Step>
  <Step title="Open the document">
    Select its name. The **Source** and **Type** columns help distinguish a provider document from a portal page or uploaded file. A paperclip indicates attachments.

    For an uploaded file, **Preview** opens a quick preview directly from the list.
  </Step>
</Steps>

## Read and navigate

The document page shows its title and available company, folder, and update information. Long articles can include a table of contents on larger screens. Use its headings to jump within the article, then the page's back control to return to Documents.

An uploaded file shows directly on its document page. PDF, Word, CSV, and Excel files are supported, but the page can show only part of a large workbook or dataset. Select **Download** in the page header when you need the complete file or its original formatting.

## Open or download attachments

Look for **Attachments** beside the article on a large screen or below the content on a smaller screen. Select an attachment's name to open it. Use its download control to download the file.

The uploaded-file preview also includes **Download**. If a file cannot be previewed, use the download option if it is available and you have permission to access the file.

IT Glue files open in IT Glue. The portal cannot preview or download them, because IT Glue gives files only to signed-in IT Glue users. A document that is only an IT Glue file shows **Open in IT Glue** in place of its content. Its attachments open IT Glue in a new tab. You need your own IT Glue sign-in to view them.

## Export an article to PDF

If your MSP enables it, an article can show **Export PDF**. Select it to open a print view, then choose your browser's PDF destination or printer. Allow the print window for your portal if the browser blocks it.

This export uses the article's text content. For an article that is primarily an attached PDF or uploaded file, download the original file instead. **No content to export** means the article has no text body suitable for this export.

## FAQs

<AccordionGroup>
  <Accordion title="Why is a document missing?">
    Check the selected company, folder, and table filters. Your MSP may need to share the document with your role or company. A direct link does not grant access to an otherwise restricted document.
  </Accordion>
  <Accordion title="Do we need Hudu or IT Glue to use Documents?">
    No. Your MSP can create portal pages and upload files directly. Provider integrations add documents and other records shared from those systems.
  </Accordion>
  <Accordion title="Can Company users upload or edit portal documents?">
    Portal document creation, uploads, and editing are MSP administration tasks. Ask your MSP to add or correct content.
  </Accordion>
  <Accordion title="Why is my spreadsheet preview incomplete?">
    Preview is a reading aid and may show a selected sheet or a limited number of rows. Download the original workbook for all sheets and complete data.
  </Accordion>
  <Accordion title="Why does an IT Glue attachment open IT Glue instead of a preview?">
    IT Glue does not let connected apps download attachment files. The portal links to the file in IT Glue, where you sign in with your own IT Glue account. If you do not have an IT Glue sign-in, ask your MSP for a copy of the file.
  </Accordion>
  <Accordion title="Where are attachments on mobile?">
    Scroll below the article content to the **Attachments** area. On larger screens it appears in the side panel.
  </Accordion>
  <Accordion title="Why is Export PDF missing or failing?">
    Your MSP controls whether export is available. A blocked pop-up or an article without a text body can prevent the print export. Use the original file's download control for a file-based document.
  </Accordion>
  <Accordion title="Can I send a portal document link to someone else?">
    A normal portal link requires the recipient to have access. Ask your MSP if you need an approved public-sharing link; copying a portal URL does not change its permissions.
  </Accordion>
</AccordionGroup>
