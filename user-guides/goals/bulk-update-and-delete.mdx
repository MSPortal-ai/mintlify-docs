Change the status, priority or category of many goals at once, or delete goals you no longer need. This guide is for MSP staff and Company users whose role has **Manage** access to Goals.

## Before you start

- You need **Manage** access to Goals. With only **Read**, the table has no checkboxes and no **Actions** menu.
- Set the company selector and table filters first.

## Change several goals

<Steps>
  <Step title="Select the goals">
    Tick the checkbox on each goal. The header checkbox selects only the goals on the current page.
  </Step>
  <Step title="Open Actions">
    Click **Actions (n)** in the page header. Check that the count is right.
  </Step>
  <Step title="Choose what to change">
    Pick **Set Status**, **Set Priority** or **Set Category**, then pick the value. For **Set Category**, **None** clears the category.
  </Step>
  <Step title="Check the result">
    Wait for the message, for example **Updated status for 3 goals**. The selection clears and the list refreshes.
  </Step>
</Steps>

The change applies as soon as you pick the value. There is no confirmation. Changing the status does not change progress. Filtering the table drops selected goals that no longer match the filter.

## Delete one goal

<Steps>
  <Step title="Open the row menu">
    Click **...** on the goal's row and choose **Delete Goal**.
  </Step>
  <Step title="Read the confirmation">
    It names the goal and says its custom field values are deleted too.
  </Step>
  <Step title="Confirm">
    Confirm only if it is the right goal. Then check the list.
  </Step>
</Steps>

## Delete several goals

<Steps>
  <Step title="Select the goals">
    Tick the goals and check the count in **Actions (n)**.
  </Step>
  <Step title="Choose Delete Selected">
    Open **Actions > Delete Selected**. A dialog shows the count.
  </Step>
  <Step title="Confirm">
    Click **Delete N Goals**. Then check the list.
  </Step>
</Steps>

<Warning>
Deleted goals cannot be restored. If you only want to stop tracking a goal, change its status instead.
</Warning>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No checkboxes or **Actions** menu | You need **Manage** access to Goals. |
| **Failed to update status** (or priority, category) | Try again. If it repeats, send your MSP the message. A disappearing selection does not mean the change worked. Check the list. |
| **Add to Planner** is missing from **Actions** | It also needs **Write** or **Manage** access to Planner. |
| **Please select items from the same company** | Add to Planner and Add to Meeting need goals from one company. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Select all mean every goal?">
    No. The header checkbox selects the current page only. Check the count.
  </Accordion>
  <Accordion title="Do bulk field changes ask for confirmation?">
    No. They apply at once. Deleting has its own confirmation.
  </Accordion>
  <Accordion title="Can I bulk-update progress?">
    No. **Actions** offers status, priority and category. Edit a goal to change its progress.
  </Accordion>
  <Accordion title="Can I undo a deletion?">
    No. There is no restore.
  </Accordion>
  <Accordion title="Can I export only the ticked goals?">
    No. **Export CSV** uses the filtered list. See [Find and read goals](/user-guides/goals/read-goals).
  </Accordion>
</AccordionGroup>
