Use this page to find a device in the Security Endpoints list. It is for company users and MSP staff. The list combines endpoint records from Cork and Acronis.

## Before you start

- You need Security read access.
- Cork or Acronis must be connected. Without either, the **Endpoints** tab does not appear.
- Your MSP manages integrations and company mapping. See [Enable the Cork integration](/user-guides/integrations/enable-cork-integration) and [Enable the Acronis integration](/user-guides/integrations/enable-acronis-integration).

## Find a device

<Steps>
  <Step title="Open Endpoints">
    Open **Security > Endpoints** and check the company selector.
  </Step>
  <Step title="Search by name">
    Type in the **Device Name** column filter to narrow the list. Wait for the table to finish loading.
  </Step>
  <Step title="Filter the list">
    Use the column filters to narrow further. **Status** offers **Online** and **Offline**. **Company** lets you pick companies. **Source** lets you pick one or more sources, and appears when the list holds records from more than one source. **Last Seen** takes a date range.

    <img src="/images/product/security-endpoint-status-filter.png" alt="Endpoint Status filter options: All, Online, and Offline" width="318" height="204" />
  </Step>
  <Step title="Identify the right record">
    Check **Company**, **OS**, and **Source**. Cork records show **Cork -** followed by the source tool name. Acronis records show **Acronis**. The same device can appear once per source.
  </Step>
  <Step title="Open the details">
    Click a row, away from its checkbox, to open the side panel. See [Read security endpoint details](/user-guides/security/read-endpoint-details).
  </Step>
</Steps>

The table shows 20 rows per page. A link from the Security Dashboard can open the list already filtered to **Online** or **Offline**. Clear that filter to see every endpoint.

## Read status and dates

- **Status** comes from Acronis. It shows **Online** or **Offline** for Acronis devices and is blank for Cork devices. A blank Status does not mean a Cork device is offline.
- **Online** does not mean **Protected**. Protection status is in the side panel for Acronis records.
- **Last Seen** shows the Acronis registration date for Acronis rows. A badge like **45d ago** appears when the date is more than 30 days old. For Acronis rows this reflects registration, not the last check-in.

## Follow up on endpoints

Select rows from one company, then open **Actions (N)** in the page header.

- **Add to Meeting** adds the endpoints to an upcoming meeting agenda. See [Add Cork findings to a meeting agenda](/user-guides/security/add-to-meeting).
- **Add to Planner** creates one Planner item. It appears only if your role has Planner write or manage access. See [Add security findings to Planner](/user-guides/security/add-to-planner).

Both actions treat every selected row as a Cork endpoint. Use them for Cork rows only.

The list is read-only. You cannot edit an endpoint, change protection, run a scan, start a backup, or export a CSV here.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The list is empty | Clear the column filters and any dashboard filter, then check the company selector. An empty list can also mean the integration has not synced. |
| **Security integration unavailable** | Cork or Acronis is not connected, or you lack Security read access. Ask your MSP admin. |
| **Failed to load endpoints** | Reload the page. If it keeps failing, report it through the [Home AI Assistant](/user-guides/ticketing/open-a-ticket). |
| A device shows twice | It exists in both Cork and Acronis. Check the **Source** column. |
| A large environment seems cut off | The list loads up to 1,000 Cork and 500 Acronis records per request. Narrow by company or **Device Name**. |
| The **Source** filter is missing | It only appears when the loaded records come from more than one source. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why is Status blank for a Cork endpoint?">
    Status comes from Acronis online information. Cork does not supply it, so the cell stays blank.
  </Accordion>
  <Accordion title="Does an old Last Seen date mean the Acronis agent is offline?">
    No. For Acronis rows the date is the registration date. Check **Status** for the connection state.
  </Accordion>
  <Accordion title="Is this the same as the Devices inventory?">
    No. Security Endpoints lists records from Cork and Acronis. See [Find devices](/user-guides/devices/find-devices) for the device inventory.
  </Accordion>
  <Accordion title="I am a company user. How do I ask about a device?">
    Describe it to the [Home AI Assistant](/user-guides/ticketing/open-a-ticket), including the device name, company, and source, then confirm the request when prompted.
  </Accordion>
</AccordionGroup>
