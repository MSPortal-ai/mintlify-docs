Use this page to turn Cork findings into Planner work you can assign, date, and track. It is for MSP staff. Company users should ask their MSP when the action is not available.

## Before you start

- You need Security read access and Planner write access. **Add to Planner** only appears for roles with Planner write or manage access, and linking the findings needs Planner write access plus Security read access.
- Cork must be connected and the findings mapped to a company.
- All selected findings must belong to the same company.

## Create a Planner item from findings

<Steps>
  <Step title="Open the findings">
    Open **Security > Compliance** for compliance events, **Security > Vulnerabilities** for software vulnerabilities, or **Security > Endpoints** for devices.
  </Step>
  <Step title="Select the rows">
    Check the box beside each finding you want to track. You can select several rows to create a single Planner item that tracks all of them.
  </Step>
  <Step title="Choose Add to Planner">
    Open **Actions (N)** in the page header and choose **Add to Planner**.
  </Step>
  <Step title="Review the draft">
    The Planner item dialog opens with a title, **Description**, **Business Value**, **Due Date**, and **Private Notes** already filled in. The status starts as Not Started, and the due date starts as today. Change **Type**, **Status**, **Due Date**, **Est. Hours**, **Est. Cost**, or the notes as needed.
  </Step>
  <Step title="Save">
    Click **Save**. MSPortal shows **Cork items added to planner.**
  </Step>
  <Step title="Check the result in Planner">
    Open **Planner**, open the new item, and find **Relationships**. The findings appear under **Cork Compliance Events**, **Cork Vulnerabilities**, or **Cork Endpoints**.
  </Step>
</Steps>

Opening the dialog does not save anything. Several findings become one Planner item, not one item per row. The original findings stay as they are.

<Warning>
This shortcut saves only Company, Type, Status, Business Value, Due Date, Est. Hours, Est. Cost, Description, Notes, and Private Notes. It does not save **Assignee**, **Hide from company users**, start or end dates, probability, other relationships, or custom fields. Do not put confidential details in the title, description, or public notes. Open the saved item in Planner and set those fields there.
</Warning>

## What the draft contains

### Compliance events

| Cork field | Planner field |
| --- | --- |
| Event type | Title (single event) and Private Notes |
| Entity | Private Notes |
| Status (At Risk or OK) | Private Notes. Any At Risk event sets Business Value to **High**. |
| Resolved | Private Notes, when the event is resolved |
| Created | Private Notes |

### Vulnerabilities

| Cork field | Planner field |
| --- | --- |
| CVE | Title (single vulnerability) and Private Notes |
| Software and version | Description and Private Notes |
| Vendor | Private Notes |
| CVSS score | Private Notes |
| Priority | Private Notes. Critical or Accelerated sets Business Value to **High**. |
| Known exploited | Highlighted in Private Notes |

### Endpoints

| Cork field | Planner field |
| --- | --- |
| Device name | Title (single endpoint) |
| Hostname | Private Notes |
| OS and OS version | Private Notes |
| IP addresses | Private Notes |
| Last seen | Private Notes |

### Business Value

| Condition | Business Value |
| --- | --- |
| Any Critical or Accelerated vulnerability | High |
| Any At Risk compliance event | High |
| Everything else, including all endpoints | Medium |

You can change Business Value before you save.

### One finding or several

- One finding: the title is the CVE, event type, or device name, and the description covers that finding.
- Several findings: the title reads like **Cork Vulnerabilities (5 items)**, **Cork Compliance Events (3 items)**, or **Cork Endpoints (2 items)**. Each finding is listed in Private Notes with a divider.

Private Notes are for MSP staff and are hidden from company users. Put anything you want clients to read in **Notes**.

## Tips for grouping

- Group vulnerabilities for the same software product.
- Group compliance events that affect the same device.
- Group findings that one action can fix.
- Start with Known Exploited and Critical vulnerabilities, then At Risk compliance events.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Add to Planner** is missing from the Actions menu | Your role lacks Planner write or manage access. Ask your MSP admin. |
| **Please select items from the same company** | Clear your selection and pick rows from one company. |
| **Please select a company first** | Pick a company in the company selector. |
| **Could not save planner item.** | The item may already exist without its links, because the item is saved first and the findings are linked second. Open Planner and fix that item instead of creating another. Linking needs Planner write access and Security read access, so ask your MSP admin to check your role. |
| You selected Acronis endpoint rows | The shortcut links every endpoint row as a Cork endpoint. Use it for Cork endpoints only. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Do several selected findings create several Planner items?">
    No. They create one Planner item with links to every selected finding.
  </Accordion>
  <Accordion title="Does completing the Planner item fix the finding in Cork?">
    No. Planner tracks your work. Patching and resolving the finding happen in the provider, and the result shows up here after the next sync.
  </Accordion>
  <Accordion title="Can I rely on Hide from company users here?">
    No. This shortcut does not save that setting. Set it in the saved Planner item.
  </Accordion>
  <Accordion title="Where do I see the linked findings later?">
    Open the item in **Planner** and look under **Relationships**.
  </Accordion>
  <Accordion title="I am a company user. How do I ask for help with a finding?">
    Describe it to the [Home AI Assistant](/user-guides/ticketing/open-a-ticket) and confirm the request when prompted.
  </Accordion>
</AccordionGroup>
