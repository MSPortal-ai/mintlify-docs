Use this page to find software vulnerabilities that Cork found and to read what each column means. It is for company users and MSP staff.

## Before you start

- You need Security read access.
- Cork must be connected and its companies mapped. Without Cork, the **Vulnerabilities** tab does not appear. See [Enable the Cork integration](/user-guides/integrations/enable-cork-integration).

## Find a vulnerability

<Steps>
  <Step title="Open Vulnerabilities">
    Open **Security > Vulnerabilities** and check the company selector.
  </Step>
  <Step title="Search by CVE or software">
    Type in the **CVE** or **Software** column filter. Use only one at a time. When both are filled, the CVE search is used.
  </Step>
  <Step title="Narrow the list">
    Use **Company** to pick companies, **Priority** to pick a priority, **Known Exploited** to pick **Yes** or **No**, and **CVSS** to set a score range.
  </Step>
  <Step title="Sort and page">
    Click a column header to sort. The table shows 20 vulnerabilities per page.
  </Step>
</Steps>

A link from the Security Dashboard can open the list already filtered to **Critical** priority or **Known Exploited**. Clear the filter to see every finding.

## Read the columns

| Column | What it shows |
| --- | --- |
| **CVE** | The vulnerability ID. Click it to open its National Vulnerability Database page in a new tab. |
| **Software** | The product, with its vendor underneath. |
| **Company** | The mapped company. |
| **CVSS** | The severity score to one decimal place. A dash means no score. |
| **Priority** | The Cork priority, such as Critical, Accelerated, or Routine. The filter lists the priorities that exist in your data. |
| **Known Exploited** | **Yes** when Cork flags the vulnerability as known to be exploited. |

**Known Exploited** describes the vulnerability, not your company. It does not mean you were attacked. A missing score or a **No** does not mean the software is safe.

The table is read-only. You cannot patch, mark a finding fixed, or export a CSV here.

## Plan follow-up

Select rows from one company, then open **Actions (N)** in the page header.

- **Add to Planner** creates one Planner item that links every selected vulnerability. See [Add security findings to Planner](/user-guides/security/add-to-planner).
- **Add to Meeting** adds one agenda entry per vulnerability. See [Add Cork findings to a meeting agenda](/user-guides/security/add-to-meeting).

Finishing the Planner item does not patch the software or rescan it in Cork.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| My **Software** search is ignored | You also have text in **CVE**. Clear **CVE**. |
| The list is empty | Clear every filter, including any set by a dashboard link, and check the company selector. |
| **No vulnerabilities found** for a company you expect to have data | Ask your MSP to check the Cork sync and company mapping. |
| **Failed to load vulnerabilities** | Reload the page. If it keeps failing, report it through the [Home AI Assistant](/user-guides/ticketing/open-a-ticket). |
| **Security integration unavailable** | Cork is not connected, or you lack Security read access. Ask your MSP admin. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Why is my Software filter ignored when I enter a CVE?">
    The page sends one search value. A filled **CVE** filter takes priority over **Software**.
  </Accordion>
  <Accordion title="Does Known Exploited mean our company was compromised?">
    No. It flags the vulnerability. Your MSP must check your environment.
  </Accordion>
  <Accordion title="Where does the CVE link go?">
    To the National Vulnerability Database page for that CVE, in a new tab. It changes nothing in MSPortal.
  </Accordion>
  <Accordion title="Does adding a vulnerability to Planner patch it?">
    No. It creates follow-up work. Patching and rescanning happen outside MSPortal.
  </Accordion>
  <Accordion title="I am a company user. How do I ask about a vulnerability?">
    Tell the [Home AI Assistant](/user-guides/ticketing/open-a-ticket) the CVE, company, and software, then confirm the request when prompted.
  </Accordion>
</AccordionGroup>
