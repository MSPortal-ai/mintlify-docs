Backup > Alerts lists alerts that your backup providers report. MSP staff and company users with Backup read access can use it.

## Before you start

- You have Backup read access.
- Acronis, Datto Backup or Slide Backup is connected and has reported alerts for your companies. The **Alerts** tab is hidden until it has.

## Review an alert

<Steps>
  <Step title="Open Alerts">
    Go to **Backup > Alerts**, or select **Active alerts** on the dashboard.
  </Step>
  <Step title="Check the company">
    Confirm the company selector at the top. It is the only company filter on this page.
  </Step>
  <Step title="Read the alert">
    Read **Severity**, **Title**, **Resource**, **Company**, **Status** and **Created**. MSP staff also see **Provider** when more than one provider has alerts. Under the title, a line gives the description or the threshold that was breached, for example "Threshold: 48 hours".
  </Step>
  <Step title="Page through results">
    The list shows 25 alerts per page.
  </Step>
  <Step title="Report what needs attention">
    Report an unexpected or unresolved alert to the person who manages the backup provider.
  </Step>
</Steps>

**Created** shows when the provider raised the alert, relative to now. **Status** is **Active** or **Resolved**. A resolved alert does not prove the latest backup succeeded, so check the resource too.

Datto Backup and Slide Backup alerts have no severity, so **Severity** shows a dash, and they are always active. A Severity or **Resolved** filter therefore hides them.

## Filter the list

Filters search the whole result, not only the page you are on.

<Steps>
  <Step title="Open a column filter">
    Use the filter on **Severity**, **Status**, **Title** or **Provider**.
  </Step>
  <Step title="Choose a value">
    **Severity** offers Critical, Error, Warning and Information. **Status** offers Active and Resolved. **Title** searches alert titles and descriptions. **Provider** takes one provider at a time.
  </Step>
  <Step title="Clear the filter">
    Remove the filter to see the full list again.
  </Step>
</Steps>

## Ask your MSP to investigate (company users)

Start with the Home AI Assistant, as described in [Open a ticket](/user-guides/ticketing/open-a-ticket). Include the alert title, company, resource, severity, status and creation time. Review the request and confirm it when prompted. Reading an alert does not create a ticket.

## Follow up with the provider (MSP staff)

Review the affected resource and its details under **Backup > Devices**. Then use the provider's own tools to investigate or change anything. This table has no acknowledge, resolve, delete or CSV export control.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Failed to Load Alerts** | Try again later, or ask your MSP to check the integration. |
| **No Backup Alerts** | No provider alerts exist for the current scope. It does not mean every provider is healthy. |
| No **Alerts** tab | No eligible alerts exist for the selected companies. |
| A Datto Backup or Slide Backup alert vanished after filtering | A Severity filter or a **Resolved** status excludes them. Clear the filter. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Alerts include every backup provider?">
    No. It reads Acronis, Datto Backup and Slide Backup alerts. Check other providers through their reports.
  </Accordion>
  <Accordion title="Can I resolve or acknowledge an alert here?">
    No. Authorized MSP staff do that in the provider's own tools.
  </Accordion>
  <Accordion title="Does Resolved prove my backups are current?">
    No. Check the latest backup result and date separately.
  </Accordion>
</AccordionGroup>
