MSPortal's IT Glue document synchronization refreshes folder information for mapped organizations before collecting their documents. **MSP staff manage the connection and sharing**; Company users browse the folders and documents permitted by their portal access.

<Note>
The old browser-console **Generate Script / Import Folders** workflow is no longer part of the current setup. Use the integration's document sync.
</Note>

## Prepare folder coverage

<Steps>
  <Step title="Check the IT Glue connection">
    Open **Settings > Integrations**, find the active IT Glue connection and open **Configure**. Check its credential and connection status.
  </Step>
  <Step title="Save organization mappings">
    On **Map Organizations**, map the intended IT Glue organizations to MSPortal companies. Save pending links with **Import Selected** or **Next**. Folder discovery follows saved company mappings.
  </Step>
  <Step title="Enable Documents">
    On **Sync & Sharing**, check **Documents** is enabled. Changing this switch saves immediately; enabling it requests document sync. Do not repeatedly toggle it just to refresh the view.
  </Step>
  <Step title="Wait for the background result">
    The document sync refreshes the mapped organizations' folder inventory, then collects documents using those folders. It runs in the background. Check the connection's sync information and actual imported documents afterward.
  </Step>
</Steps>

If a manual refresh is needed, use the saved IT Glue connection's sync action in **Settings > Integrations**. Review its scope: it can synchronize multiple IT Glue datasets, not just folders. A request-success message does not prove folder or document import finished.

## Browse and share documents

Open **Documentation > Documents**. Select the permitted company scope, then use the available folder tree and search to find the content. **All Folders** and **Unfiled**, when present, distinguish the full selection from root-level documents. A folder's presence alone does not establish that every document in it was imported or shared.

MSP staff control visibility in **Settings > Documentation > Documents**. Its **Share Articles** section contains synchronized document and folder sharing controls with a separate **Save**. Review the intended company and role groups before applying changes. Importing folders does not automatically grant Company users access.

## Folder changes in IT Glue

After adding or reorganizing folders in IT Glue, let the next document sync refresh the folder inventory or request an appropriate integration sync. Mapping a new organization also changes the inventory eligible for discovery.

Successful discovery can reconcile folder records that no longer exist at the provider. A missing organization or failed source request may leave earlier folder data in place. Therefore a visible old folder is not proof that the source still contains it, and a successful partial run is not complete coverage of every organization.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| There is no Sync Folders dialog | The current workflow uses automatic discovery during document sync. The old console-script instructions are obsolete. |
| One organization has no folders | Saved mapping, provider API access and actual source folders for that organization. |
| Folder exists but a document is missing | Completed document sync, source availability and portal sharing/permissions. Folder discovery alone is not document import. |
| MSP sees a document but the Company user cannot | Company scope, read access and saved document/folder role visibility. |
| Recently moved folder still looks old | Check the last successful document sync and any organization-specific error. |
| Sync request succeeded but the tree is unchanged | Wait for the background result and inspect the actual records; the request toast is not completion. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Do I still run a script in the IT Glue browser console to import folders?">
    No. The current document sync discovers folders through the IT Glue API. The old Generate Script and Import Folders workflow is obsolete.
  </Accordion>
  <Accordion title="What must be configured before IT Glue folders sync?">
    Use an active working IT Glue connection, saved organization-to-company mappings and **Documents** enabled on **Sync & Sharing**.
  </Accordion>
  <Accordion title="Does changing Documents on Sync & Sharing need a separate Save?">
    That switch saves immediately; enabling it requests document synchronization. Do not repeatedly toggle it to refresh.
  </Accordion>
  <Accordion title="Does an imported IT Glue folder mean all its documents are visible to clients?">
    No. Document import, company scope, permissions and saved visibility rules must also permit the content.
  </Accordion>
  <Accordion title="Where do MSP staff configure IT Glue document sharing?">
    Open **Settings > Documentation > Documents** and use **Share Articles** with its separate **Save** for document/folder visibility.
  </Accordion>
  <Accordion title="Does manual IT Glue sync update only document folders?">
    The integration sync action can cover several IT Glue datasets. Review its scope and inspect the background results.
  </Accordion>
  <Accordion title="Will an old IT Glue folder always disappear immediately?">
    No. It depends on successful discovery for the mapped organization. A failed or missing-source request can preserve earlier folder data.
  </Accordion>
</AccordionGroup>
