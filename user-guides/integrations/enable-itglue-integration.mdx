Connect IT Glue to synchronize documents, configurations, flexible assets and checklists. Password sharing is optional. Setup requires **MSP integration management permission**, and Company sharing requires the appropriate Documentation settings access.

## Prepare the account and API key

Only one documentation platform can be active: **IT Glue or Hudu**. Review any existing connection before replacing it.

IT Glue's custom API requires the applicable **Enterprise plan with API access enabled**. An IT Glue administrator creates the key under **Account > API Keys > Custom API Keys**. Enable the key's **Password Access** only if the integration should reveal password values. Store the key when generated. See [IT Glue API setup](https://help.itglue.kaseya.com/help/Content/1-admin/it-glue-api/getting-started-with-the-it-glue-api.html).

Know which IT Glue API region your account uses. The MSPortal setup selector currently offers **US (api.itglue.com)** and **EU (api.eu.itglue.com)**. This selects your IT Glue endpoint, not your MSPortal tenant region. If your account needs another endpoint, ask support rather than choosing a different region merely to pass setup.

## Connect

<Steps>
  <Step title="Open the intended connection">
    Open **Settings > Integrations** and connect IT Glue. For an existing account, use **Configure** on its saved connection.
  </Step>
  <Step title="Choose Region and IP restriction">
    Select the IT Glue **Region**. If your key or account permits only approved caller addresses, select **My API key only allows approved IP addresses**. Add the exact MSPortal static IP range displayed by this wizard to the applicable IT Glue allowlist before saving. That range follows the MSPortal deployment; do not substitute an IP from another tenant or a generic example.
  </Step>
  <Step title="Save and test">
    Enter **API Key**, then select **Save and Test Connection**. The new-connection control saves and verifies the connection; there is no required separate Test button first. With IP restrictions selected, verification uses the displayed approved range. Wait for the result before moving on.
  </Step>
  <Step title="Map Organizations">
    After discovery, review organization names and any PSA ID or Type information. Review **Quick Match** proposals or choose companies manually. Save pending links with **Import Selected**, or **Next** to save pending mappings and request follow-on content sync.
  </Step>
</Steps>

Creating a missing MSPortal company persists that company immediately and stages its link. Removing a saved organization mapping takes effect immediately. Closing setup does not undo either operation.

## Configure Sync & Sharing

| Control | Save behavior and scope |
| --- | --- |
| **Documents**, **Configurations**, **Checklists** | Each switch saves immediately. Enabled data still needs a successful background sync. |
| **Flexible Asset Types** | Each type switch saves immediately. **Enable All** and **Disable All** apply to all types for this connection, including types hidden by search. |
| **Password Sharing** | Saves immediately; also controls password-metadata sync. Disabling it removes synchronized IT Glue password metadata from MSPortal. It does not delete passwords in IT Glue. |
| **Warranty Writeback** | Separate draft; requires **Save warranty settings**. Writes warranty dates to IT Glue configurations, and optionally to flexible assets. |

Client visibility is separate from synchronization. Use **Settings > Documentation** to configure company and role sharing for documents, assets, configurations, procedures and passwords. A synchronized name or a successful setup does not prove a Company user can view or reveal its contents.

Document sync refreshes IT Glue folder information before collecting documents from those folders. See [IT Glue document folders](/user-guides/integrations/itglue-sync-folders) for folder coverage and missing-document checks.

**Complete Setup** returns to Integrations. It is not a universal Save button for other drafts and does not prove that all background work has completed.

## Rotate the key

Open **Connect** on the saved integration. Its Region is locked. Enter the replacement and select **Update API Key**, then use **Retest Connection** with the now-empty replacement field. The update stores the key; the retest verifies the saved credentials. Check password access and IP restrictions on the replacement too.

If creation reports an error, inspect the saved Integrations list before retrying. A previous partially completed attempt may already have a connection. Avoid disconnecting a working account merely to retry a test.

## Troubleshooting

| Symptom | What to check |
| --- | --- |
| 403 Forbidden | API plan/access, key status, correct IT Glue region and IP allowlist. A 403 alone does not identify which prerequisite failed. |
| Unsupported key characters | Copy only the raw API key, without surrounding quotes or extra text. |
| Save and test fails with IP restrictions | Add the exact range displayed by your MSPortal wizard to the applicable provider access list. |
| Password metadata appears but values cannot be revealed | Provider **Password Access**, current key, and portal sharing and role permissions. |
| No company documents | Saved mapping, Documents enabled, successful folder/document sync and visibility rules. |
| Search hid types but Enable All changed them | Bulk type controls operate on the whole connection, not just search results. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Do I test a new IT Glue key before saving it?">
    Use **Save and Test Connection** on the new connection. If the key is IP restricted, select that option and add the displayed range before saving.
  </Accordion>
  <Accordion title="Does the IT Glue Region selector choose my MSPortal region?">
    No. It chooses the IT Glue API endpoint. The allowlist range displayed by MSPortal follows the MSPortal deployment separately.
  </Accordion>
  <Accordion title="Does a 403 always mean my IT Glue plan is wrong?">
    No. Check API entitlement, key status, endpoint region and IP restrictions. More than one prerequisite can cause denied access.
  </Accordion>
  <Accordion title="Does searching Flexible Asset Types limit Enable All?">
    No. **Enable All** and **Disable All** save changes for all flexible asset types in this connection, including hidden search results.
  </Accordion>
  <Accordion title="What happens when I turn off IT Glue password sharing?">
    It saves immediately, disables password-metadata sync and removes synchronized IT Glue password metadata from MSPortal. It does not delete provider passwords.
  </Accordion>
  <Accordion title="Does Update API Key test my replacement IT Glue key?">
    It stores the replacement. Use **Retest Connection** afterward to verify the saved key. Check its password access and IP restrictions too.
  </Accordion>
  <Accordion title="Does Complete Setup save my warranty mapping draft?">
    Warranty settings require their own **Save warranty settings**. Complete Setup exits the wizard; it is not a universal save or sync-completion check.
  </Accordion>
  <Accordion title="Does mapping an IT Glue organization invite its users?">
    No. It associates provider data with an MSPortal company. Portal invitations and role access are separate MSP tasks.
  </Accordion>
  <Accordion title="Can the IT Glue connection reveal every synced password automatically?">
    No. Provider Password Access, enabled sharing, company mapping and the user permissions must all allow the requested reveal.
  </Accordion>
</AccordionGroup>
