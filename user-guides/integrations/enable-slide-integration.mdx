Connect Slide Backup, select optional data, and map Slide clients to portal companies before reviewing their backup coverage.

Open **Settings > Integrations**, find the provider in the directory, and open its setup. You need an MSP staff account with permission to manage integrations. Company users should ask their MSP to connect the service.

## Before you start

Create an API token in the **Slide Console**. A read-only token is sufficient. Copy the token when it is created; Slide shows it only once.

## Set up the connection

1. In **Connect**, enter **API token** and select **Test Connection**.
2. Review the appliance count, then select **Save connection** to save access and start the first sync.
3. In **Choose data**, review **Alerts** and **Snapshot verification**. Clients, appliances, protected systems, and backup status always sync.
4. Each switch saves immediately. Wait for the save result; the choices apply to subsequent syncs.
5. In **Import or match companies**, link each Slide client to its portal company. Review proposed matches before applying them.
6. Open **Review** and inspect appliances, protected systems, and alerts. Select **View backup devices** to inspect individual records.

Only mapped clients appear in Backup. Setup can finish while the first sync runs. Turning off snapshot verification means verification problems no longer mark a protected system as Warning, so choose that setting deliberately.

## Troubleshooting

- **No data has been synced yet:** use **Start first sync** when shown.
- **A client has no data in Backup:** verify its company mapping and the current company scope.
- **A changed option has no effect:** check that the switch saved successfully and allow another sync to complete.
- **Token rejected:** confirm it has read access in the intended Slide account.
