Open **Settings > Integrations**, find the provider in the directory, and open its setup. You need an MSP staff account with permission to manage integrations. Company users should ask their MSP to connect the service.

## Before you start

Request an MSP SmartAPI key from Check Point or Avanan Support. Each key works only in its own region. Use a separate connection for each region where your managed tenants reside.

## Set up the connection

1. In **Connect**, choose **API region** and enter **Application ID (Client ID)** and **Client Secret**.
2. Select **Test Connection** and review the customer tenant count returned by the test.
3. Select **Create Integration**. For an existing connection, use **Update Credentials**.
4. Continue to **Map tenants** and match each Avanan customer tenant to the company it protects. Review suggested matches before saving.
5. In **Review data**, inspect mapped tenants, licensed users, threat events, and allow/block list entries. Setup can finish while synchronization continues.

The region cannot change after saving the connection. Add another connection to use a key from a different region.

## Verify the result

Use **View Email Security** to review the mapped data. **View SAT Coverage** shows relevant coverage; a SAT license count does not itself prove training completion. Threat events cover the last 30 days. Previously saved data is retained if a later sync fails.

## Troubleshooting

- **Test rejected:** confirm that the key is an MSP SmartAPI key for the selected region.
- **A company has no data:** check its tenant mapping and the selected company scope.
- **Sync needs attention:** fix the connection issue and use the available data-sync action; a partial failure does not mean all previously collected records disappeared.
