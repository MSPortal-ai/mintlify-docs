Provide API access for the MSPortal team to develop the Ingram Micro integration. This is a **credential intake**: submitting credentials does not connect live data, validate the vendor credentials, import devices, or complete company mapping.

Open **Settings > Integrations**, find the provider in the directory, and open its setup. You need an MSP staff account with permission to manage integrations. Company users should ask their MSP to connect the service.

## Before you start

Provide your Ingram Micro reseller API Client ID and Client Secret for integration development.

## Submit your credentials

1. Open the Ingram Micro setup form.
2. Complete the fields below.
3. Select **Save and continue** in the guided connection page, or **Secure credentials** in the single-screen form.
4. Wait for the saved confirmation. A successful first submission notifies the MSPortal integration team. They will contact you if more information is needed.

| Field | What to enter |
| --- | --- |
| **Client ID** | Your reseller API client ID. |
| **Client Secret** | The matching reseller API client secret. |

## Replace or remove access

Open the existing intake to replace credentials. In the single-screen form, select **Update credentials** after entering the replacements. In the guided connection page, use its save action. A successful replacement notifies the integration team; simply reopening an unchanged record does not resubmit it.

Use the connection removal control to remove the intake and its stored credentials. Removing them from MSPortal does not revoke the key at Ingram Micro; revoke vendor access there when it is no longer needed.

## Troubleshooting

- **No test or mapping step:** this is expected for this credential intake. A saved confirmation means the credentials were received, not that the integration is running.
- **Cannot edit:** ask an MSP administrator for integration management access.
- **Missing data after submission:** live data synchronization is not part of this intake. Contact MSPortal support about integration availability.
