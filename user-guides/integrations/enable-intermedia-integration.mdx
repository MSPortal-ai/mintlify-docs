This guide walks you through connecting Intermedia Unite to MSPortal.ai through the Unite Extend Analytics API.

<Note>
Intermedia is currently a **Pilot** integration available to selected tenants. If you don't see Intermedia in **Settings > Integrations**, contact support@msportal.ai. The pilot secures and validates the API connection and notifies the MSPortal integration team. It does not sync call or usage data yet; data sync features build on this connection.
</Note>

## Prerequisites

- An Intermedia Unite account with HostPilot admin access
- MSPortal.ai integration management permission

## Part 1: Create a Unite Extend Service Account

<Steps>
  <Step title="Open HostPilot">
    Log in to HostPilot, Intermedia's admin portal.
  </Step>
  <Step title="Create a Service Account">
    Go to **Intermedia Unite > Apps & Integrations > Unite Extend API access** and create a Service Account with **Analytics API** access.
  </Step>
  <Step title="Copy the Credentials">
    Copy the **Client ID** and **Secret Key**.
  </Step>
</Steps>

## Part 2: Connect in MSPortal

<Steps>
  <Step title="Open the Setup Page">
    Go to **Settings > Integrations**, find **Intermedia**, and click **Connect**.
  </Step>
  <Step title="Enter Your Credentials">
    | Field | Value |
    |-------|-------|
    | **Client ID** | The service account's client ID |
    | **Secret key** | The service account's secret key |
  </Step>
  <Step title="Test the Connection">
    Click **Test Connection**. On success you'll see **Connection verified** with the message "Intermedia issued an Analytics API access token for this service account." You must pass the test before you can save.
  </Step>
  <Step title="Secure Your Credentials">
    Click **Secure credentials** to save. Both values are stored only in Vault, and the MSPortal integration team is notified that your account is connected.
  </Step>
</Steps>

## Managing the Connection

- To update credentials later, click **Configure** on your Intermedia connection, enter the new values, click **Test Connection**, then click **Update credentials**. Changing a field clears the earlier test result, so test again before you save.
- To disconnect, click **Disconnect** and confirm in the **Remove Intermedia credentials?** dialog. This removes the connection and its stored Vault credentials and cannot be undone. It does not delete the service account in HostPilot.
- Users without integration management permission see the connection read-only.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Credentials rejected | The client ID or secret key was rejected, or the Analytics API scope is not enabled on the service account. Recheck the service account in HostPilot |
