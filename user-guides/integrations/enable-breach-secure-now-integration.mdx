This guide walks you through connecting Breach Secure Now (BSN) to MSPortal.ai using the guided setup wizard.

## Overview

Breach Secure Now is a security awareness training and dark web monitoring platform for MSPs. By integrating BSN with MSPortal.ai, you can:

- View security awareness training progress for every client in one place
- Track Employee Secure Score (ESS), phishing fail rates, and micro training completion
- Monitor dark web breach exposure per client and per user
- Include security awareness metrics in client reports and QBRs

## Prerequisites

- An active Breach Secure Now partner account
- The MSPortal integration enabled for your partner account in Breach Secure Now
- An MSPortal.ai account with integration management permissions

## Part 1: Enable the Integration in Breach Secure Now

Before connecting, you need your **Partner Integration Key** from Breach Secure Now.

<Steps>
  <Step title="Log into the Breach Secure Now Partner Portal">
    Sign in to your Breach Secure Now (PII Protect) partner portal with a partner administrator account.
  </Step>

  <Step title="Open the Integrations Section">
    Navigate to the integrations area of your partner configuration and locate **MSPortal** in the list of available integrations.
  </Step>

  <Step title="Enable MSPortal">
    Enable the MSPortal integration for your partner account.

    <Note>
      If MSPortal does not appear in your integrations list, contact Breach Secure Now support and ask them to enable the MSPortal API integration for your partner account.
    </Note>
  </Step>

  <Step title="Copy Your Partner Integration Key">
    Copy the **Partner Integration Key**, the secret key generated when the integration is enabled. This is the only value you enter in MSPortal.

    <Note>
      You do not need your Partner ID. MSPortal identifies your partner account from the Partner Integration Key automatically.
    </Note>

    <Warning>
      Treat the Partner Integration Key like a password. Anyone with the key can read your client and user training data.
    </Warning>
  </Step>
</Steps>

## Part 2: MSPortal Setup Wizard

MSPortal.ai provides a guided 3-step wizard to connect and configure your Breach Secure Now integration.

### Starting the Wizard

<Steps>
  <Step title="Navigate to Integrations">
    In MSPortal.ai, go to **Settings > Integrations**.
  </Step>

  <Step title="Find Breach Secure Now">
    Locate the **Breach Secure Now** card under **Add integration**. You can type "breach" in the search box or use the **Security** filter to find it quickly.

    ![Breach Secure Now card on the Integrations page](/images/bsn/search-for-bsn.png)
  </Step>

  <Step title="Start Setup">
    Click **Connect** on its row to launch the setup wizard.
  </Step>
</Steps>

---

### Step 1: Connect

Enter the Partner Integration Key you copied from the Breach Secure Now portal.

<Steps>
  <Step title="Enter Your Partner Integration Key">
    Fill in the connection fields:

    | Field | Value |
    |-------|-------|
    | **Partner integration key** | The integration key from the BSN portal |
    | **API base URL** | Pre-filled with `https://api.pii-protect.com/securedapiaccess`. Leave the default unless Breach Secure Now has given you a different endpoint. |

    ![Connect step with the Partner integration key and API base URL fields](/images/bsn/connect-step-empty.png)
  </Step>

  <Step title="Test Connection">
    Click **Test Connection** to verify your key.

    When the test passes, a green confirmation shows your partner name and a client count. This confirms MSPortal matched your key to the right partner account.

    <Note>
      The test reads only the first five clients, so the count tops out at 5. Your full client list appears on the Map Companies step.
    </Note>

    ![Connect step showing a verified Breach Secure Now connection](/images/bsn/connection-verified.png)

    If the connection fails:
    - Verify the Partner Integration Key was copied in full, without extra spaces
    - Confirm the MSPortal integration is enabled for your partner account in the BSN portal
    - If you see "That Partner Integration Key was not recognized by Breach Secure Now," return to Part 1, enable MSPortal for that partner account, copy the key again, then test again
  </Step>

  <Step title="Connect">
    Once the test passes, click **Connect** to save your credentials and proceed.

    <Note>
      Your credentials are stored with encryption and are never exposed in logs or API responses.
    </Note>
  </Step>
</Steps>

---

### Step 2: Map Companies

Map your Breach Secure Now clients to MSPortal companies. This determines which data syncs to which company.

<Steps>
  <Step title="Sync Your Clients">
    If this is your first time on this step, you'll see **No Clients Found**. Click **Sync Clients** to pull your client list from Breach Secure Now. The sync usually takes less than a minute. Click **Check for Clients** if the list has not appeared yet.

    ![No Clients Found message with the Sync Clients button](/images/bsn/map-no-clients-sync.png)
  </Step>

  <Step title="Review the Client List">
    Once clients are synced, the page shows a summary of total, mapped, and unmapped clients, with each BSN client listed below.

    ![Map companies step showing synced clients and mapping controls](/images/bsn/map-companies.png)
  </Step>

  <Step title="Use Quick Match">
    Click **Quick Match** to automatically match BSN clients to MSPortal companies based on name similarity.

    Use the confidence slider to auto-select matches, review the suggestions, and check or uncheck individual matches. Then click **Apply Matches**. The matches appear as **Pending** in the client list until you save them.

    ![Quick Match results dialog with the confidence slider](/images/bsn/quick-match-results.png)
  </Step>

  <Step title="Manual Mapping">
    For clients that were not automatically matched:

    1. Find the client in the list
    2. Click the **Select company** dropdown in the "Mapped" column
    3. Search for and select the correct MSPortal company
  </Step>

  <Step title="Create New Companies">
    If a BSN client does not have a corresponding MSPortal company yet, click the **+** button next to the client, or select clients and use **Create new company**. New companies are automatically mapped to their BSN clients.

    <Note>
      MSPortal creates the new company right away, even before you save its mapping. Closing the wizard does not remove it.
    </Note>
  </Step>

  <Step title="Save Your Mappings">
    Click **Import Selected** to save pending mappings. Saving a mapping also starts a user training sync for that client.

    <Note>
      Removing a saved mapping takes effect immediately.
    </Note>
  </Step>

  <Step title="Proceed">
    Once your clients are mapped, click **Next** to continue. **Next** also saves any mappings that are still pending.

    <Warning>
      You must map at least one client before proceeding. Only data from mapped clients syncs to MSPortal.
    </Warning>
  </Step>
</Steps>

---

### Step 3: Status

Review the connection status and start the first sync.

<Steps>
  <Step title="Start the Initial Sync">
    Click **Sync all** to pull clients and user training data from Breach Secure Now.

    The sync runs in the background. Depending on how many clients and users you have, the first sync can take several minutes.
  </Step>

  <Step title="Review Sync Stats">
    The Status step shows a live summary of your synced data:

    | Stat | Description |
    |------|-------------|
    | **Linked clients** | Mapped clients out of total BSN clients |
    | **Active users** | Active users out of total synced users |
    | **Avg. employee secure score** | Average ESS across linked clients |
    | **Training completion** | Overall training completion percentage |
    | **Users with breaches** | Users with at least one dark web breach |
    | **Total user breaches** | Total dark web breaches attributed to synced users |

    ![Status step showing sync stats and sync buttons](/images/bsn/status-step.png)

    <Info>
      User-level stats show "Not synced" until the first user sync finishes. Check back after a few minutes and the scores will fill in.
    </Info>
  </Step>

  <Step title="Complete Setup">
    Click **Complete Setup** to finish the wizard and return to the Integrations page. The background sync keeps running after you leave.
  </Step>
</Steps>

## What Gets Synced

The Breach Secure Now integration syncs the following data for mapped clients:

### Client Metrics

- Average Employee Secure Score (ESS)
- Average phishing fail rate
- Dark web breach counts (breached employees and total breaches)
- Active user count and product type

### User Training Data

Per-user security awareness details, including:

- Security training courses available and completed
- Micro training completion percentage and average score
- Employee Secure Score (ESS)
- Phishing simulation results (emails sent, clicked, captured data, phish caught)
- Dark web breach count and last breach date
- Last login and enrollment status

---

## Synchronization Schedule

After the initial setup, data syncs automatically once per day. Clients sync first, followed by user training data.

<Note>
You can trigger a manual sync at any time: go to **Settings > Integrations**, open the Breach Secure Now wizard, and use **Sync clients**, **Sync users**, or **Sync all** on the Status step.
</Note>

## Managing Your Integration

After setup, manage your integration from **Settings > Integrations**:

| Action | Description |
|--------|-------------|
| **Configure** | Re-open the wizard to update credentials or add more client mappings |
| **Test Connection** | Verify your credentials are still valid. The saved key is retested without re-entering it. |
| **Save connection** | On the Connect step, enter a new Partner Integration Key and click **Save connection** to replace the stored key. Testing alone does not save it. |
| **Sync** | Trigger a manual data refresh from the Status step |
| **Delete** | Remove the integration from the wizard footer. After you confirm, MSPortal deletes the connection, synced BSN data, and stored credentials. |

### Adding More Client Mappings

As you onboard new clients in Breach Secure Now:

<Steps>
  <Step title="Open the Wizard">
    Go to **Settings > Integrations** and click **Configure** on the Breach Secure Now card.
  </Step>
  <Step title="Go to Map Companies">
    Click **Map companies** in the wizard stepper.
  </Step>
  <Step title="Map New Clients">
    Use Quick Match or manual mapping to link new BSN clients to companies, then click **Next** and **Complete Setup**.
  </Step>
</Steps>

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection test fails | Re-copy the Partner Integration Key from the BSN portal, checking for extra spaces |
| "That Partner Integration Key was not recognized" | Confirm the key was copied in full, and that the MSPortal integration is enabled for your partner account in the Breach Secure Now portal, then test again |
| "Breach Secure Now returned a web page instead of API data" | The API base URL points at the BSN portal website. Set it back to `https://api.pii-protect.com/securedapiaccess` |
| "The Breach Secure Now API base URL must be a pii-protect.com address" | Only `pii-protect.com` addresses are accepted. Restore the default API base URL |
| No clients appear on the Map step | Click **Sync Clients**, wait a moment for the background sync, then refresh the list |
| Stats show "Not synced" | Run **Sync all** and allow a few minutes for the background sync to finish |
| A client's data is missing | Confirm the client is mapped to a company; only mapped clients sync |
