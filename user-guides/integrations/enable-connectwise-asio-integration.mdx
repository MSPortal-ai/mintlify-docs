ConnectWise Asio (formerly ConnectWise RMM) is a remote monitoring and management platform. This guide is for MSP staff who connect Asio so its companies, devices, hypervisors and network devices appear in MSPortal. The setup steps are **Connect**, **Map**, **Map Locations** and **Import**.

## Before you start

- You are MSP staff with permission to manage integrations. Company users cannot set this up.
- You have admin access to ConnectWise Asio.
- Your companies already exist in MSPortal, usually from your PSA integration. Asio companies are mapped to those existing companies.
- ConnectWise PSA keys do not work here. Asio uses its own API Client ID and Client Secret.

<Note>
The first sync can take hours, or even days, for a large account. Companies appear on the **Map** step as they sync, and devices appear in staging as the sync progresses.
</Note>

## Create API credentials in Asio

<Steps>
  <Step title="Open API Access">
    Sign in to ConnectWise Asio as an admin and go to **Integrations > API Access**.
  </Step>
  <Step title="Add an API key">
    Select **Generate API Access** (or **+ Add** if you already have keys) and enter **MSPortal** as the **API Key Name**.
  </Step>
  <Step title="Choose the scopes">
    Grant these scopes.

    | Scope | Permission |
    | --- | --- |
    | Platform - Agent | Read |
    | Platform - Assets | Read |
    | Platform - Companies | Read |
    | Platform - Custom Fields values | Read |
    | Platform - DataMapping | Read |
    | Platform - DeviceGroups | Read |
    | Platform - Devices | Read |
    | Platform - Sites | Read |
    | Platform - Tickets | Create, Read and Update |
  </Step>
  <Step title="Save and copy the credentials">
    Select **Save**. Copy the **Client ID** and **Client Secret** now. Asio does not show them again after you close the dialog.
  </Step>
</Steps>

## Connect Asio to MSPortal

<Steps>
  <Step title="Start the setup">
    In MSPortal, go to **Settings > Integrations**, find **ConnectWise Asio** and select **Connect**. To change an existing connection, select **Configure** on its row instead.
  </Step>
  <Step title="Enter the connection details">
    On the **Connect** step, fill in these fields.

    | Field | What to enter |
    | --- | --- |
    | **Environment** | The region your Asio account runs in: **Production - AU**, **Production - NA**, **Production - EU** or **QA**. |
    | **Client ID** | The Client ID you copied. It must start with the prefix for your environment: NA `0e30`, EU `0e31`, AU `0e32`, QA `0e11`. |
    | **Client Secret** | The matching Client Secret. |

    <img src="/images/product/asio-setup-connection.png" alt="ConnectWise Asio setup in MSPortal with blank credential inputs" width="1024" height="908" />
  </Step>
  <Step title="Test the connection">
    Select **Test Connection**. A **Connection tested successfully** message means the credentials work. If it fails, check the environment, the Client ID prefix, the secret and the scopes.
  </Step>
  <Step title="Create the integration">
    Select **Create Integration**. A successful test alone does not save the connection. The secret is stored in encrypted vault storage.
  </Step>
</Steps>

If your account shows a **Sync** step after **Connect**, use it to choose which data to import. The choices are **Companies**, **Locations**, **Devices**, **Networks**, **Tickets** and **Software**. Select **Next** to save them. Turning a category off stops future syncs of it. Turning **Software** off removes that integration's software inventory, and turning it back on starts a new inventory sync.

## Map companies

<Steps>
  <Step title="Open the Map step">
    Continue to **Map**. The list shows each Asio company and whether it is mapped. Use the filter to show **All**, **Mapped** or **Unmapped** companies.
  </Step>
  <Step title="Match companies">
    Select **Quick Match** to suggest matches by name, then review each suggestion. For the rest, use **Select company...** on each row to pick the MSPortal company.
  </Step>
  <Step title="Save the mappings">
    Select **Import Selected** to save the pending mappings, check that the rows show saved links, then select **Next**. **Next** also tries to save pending mappings.
  </Step>
</Steps>

<Tip>
Map Asio companies to companies you already have. Creating a new company from this screen adds it immediately, so check for an existing one first.
</Tip>

Removing a pending suggestion discards it. Removing a saved link takes effect immediately.

## Map locations (optional)

<Steps>
  <Step title="Open Map Locations">
    Only locations for mapped companies appear. If you do not need location mapping, select **Skip**.
  </Step>
  <Step title="Match locations">
    Use **Quick Match** to suggest matches by name within each company, or pick a PSA location on each row. Manual picks and removals save immediately.
  </Step>
  <Step title="Save">
    Select **Save All** to confirm pending **Quick Match** suggestions, then continue.
  </Step>
</Steps>

Location mapping does not create missing PSA locations.

## Import devices

<Steps>
  <Step title="Open the import page">
    On the **Import** step, select **Open Device Import**. You can return later with the **Import Devices** action on the ConnectWise Asio row under **Settings > Integrations**.
  </Step>
  <Step title="Map device types">
    In **Device Type Mappings**, map each Asio device type to an MSPortal device type. Turn on **Auto-Sync** for types you want imported automatically. Select **Ignore** for categories you do not need.
  </Step>
  <Step title="Import the devices you want">
    In **Staged Devices**, select the devices and choose **Import Selected**.
  </Step>
  <Step title="Finish setup">
    Return to the wizard and select **Complete Setup**.
  </Step>
</Steps>

For selections, type mappings and results, see [Import Devices](/user-guides/integrations/import-devices).

## Manage an existing connection

<Steps>
  <Step title="Reopen the connection">
    Go to **Settings > Integrations** and select **Configure** on the ConnectWise Asio row. Use it to review mappings and imports.
  </Step>
  <Step title="Retest if needed">
    The environment and Client ID are locked. You can enter a secret and select **Retest Connection**, but this screen has no button to replace the saved secret.
  </Step>
  <Step title="Delete the connection (optional)">
    Select **Delete Integration** and read the confirmation. Deleting removes the connection and its settings. It does not revoke the API key in Asio, so remove that key in Asio yourself.
  </Step>
</Steps>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Connection test fails | Check the **Environment**, the Client ID prefix, the Client Secret and that every scope above is granted. |
| No companies on the Map step | Wait for the first sync to progress, and confirm the API key has the **Platform - Companies** Read scope. |
| A mapping disappeared | Reopen **Configure** and check which rows show a saved link. Suggestions stay pending until you select **Import Selected**. |
| Devices are missing | Check that the company is mapped, the first sync has finished, the device type is mapped and not set to **Ignore**, and the devices were imported from **Staged Devices**. |
| Inventory is old | Check the last successful sync and any paused or error state on the integration. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Test Connection save the integration?">
    No. After a successful test, select **Create Integration**.
  </Accordion>
  <Accordion title="Does Quick Match save every suggestion?">
    No. Suggestions are pending until you select **Import Selected** (companies) or **Save All** (locations).
  </Accordion>
  <Accordion title="Does Complete Setup mean every device is imported?">
    No. Device sync and import run separately. Open the device import page to check what was imported.
  </Accordion>
  <Accordion title="Can a company user set up Asio?">
    No. Setup is an MSP staff task.
  </Accordion>
  <Accordion title="Does Asio replace my ConnectWise PSA setup?">
    No. Asio is the RMM connection. ConnectWise PSA has its own setup for tickets and company imports.
  </Accordion>
</AccordionGroup>
