This guide walks you through connecting your Cove (N-able Backup) instance to MSPortal.ai using our streamlined setup wizard.

## Prerequisites

- Active Cove (N-able Backup) account with administrative access
- MSPortal.ai account with integration management permissions

## Part 1: Configure Cove

Before connecting to MSPortal.ai, you need to create an API user in Cove with the appropriate permissions.

### Create API User

<Steps>
  <Step title="Access User Management">
    Log into your Cove (N-able Backup) management console and navigate to **Users** in the main menu.
  </Step>

  <Step title="Navigate to API Users">
    Click on **API Users** to access the API user management section.
  </Step>

  <Step title="Add New API User">
    Click **Add API Users** to begin creating your API user.
  </Step>

  <Step title="Select Customer">
    In the customer selection dropdown, select your **top-level reseller name** (the account at the very top of the Customer hierarchy), not an individual client. This is the account that the API user will be associated with, and it gives the API user visibility into all of your sub-customers.
  </Step>

  <Step title="Configure User Details">
    Configure the following settings:

    | Field | Value |
    |-------|-------|
    | **Login Name** | `MSPortal` (or any descriptive name) |
    | **Role** | `Supporter` |

    <Tip>
      The Supporter role provides the necessary read permissions for MSPortal to sync your backup data without granting excessive access.
    </Tip>
  </Step>

  <Step title="Save and Copy Token">
    Click **Save** to create the API user. The system will generate an API token.

    <Warning>
      **Copy the API token immediately!** You will not be able to retrieve it again after leaving this page. Store it securely for use in MSPortal.ai.
    </Warning>
  </Step>
</Steps>

### Required Information

Before proceeding to MSPortal, ensure you have the following:

| Information | Description |
|-------------|-------------|
| **Partner Name** | Your **top-level reseller name** exactly as shown in the Cove management console (see below) |
| **API User Name** | The login name you created (e.g., `MSPortal`) |
| **API Token** | The token generated when creating the API user |

#### Finding your Partner Name

The Partner Name is your **top-level reseller account**, found at the top of the **Customer** dropdown in the Cove management console. It is the parent account that your individual clients are nested under, not one of those clients.

In the example below, the Partner Name is `MSPortal.ai` (the top-level reseller). `Acme Corp` is a sub-customer nested beneath it and would **not** be used as the Partner Name.

<Frame>

</Frame>

<Warning>
  Enter the **top-level reseller name**, not an individual client name. Using a sub-customer name is the most common cause of a failed connection test.
</Warning>

## Part 2: MSPortal Setup Wizard

MSPortal.ai provides a guided setup wizard that walks you through connecting and configuring your Cove integration in 2 easy steps.

### Starting the Wizard

<Steps>
  <Step title="Navigate to Integrations">
    In MSPortal.ai, go to **Settings** > **Integrations**.
  </Step>

  <Step title="Start Setup">
    Find the **Cove Data Protection** row and click **Connect** (or **Configure** if it is already connected) to launch the setup wizard.
  </Step>
</Steps>

---

### Step 1: Connect

Enter your Cove API credentials to establish the connection.

<Steps>
  <Step title="Enter API Credentials">
    Fill in the following fields:

    | Field | Description |
    |-------|-------------|
    | **Partner Name** | Your **top-level reseller name** exactly as shown at the top of the Customer hierarchy in the Cove management console (e.g., `MSPortal.ai`), not an individual client |
    | **API User Name** | The login name of your API user (e.g., `MSPortal`) |
    | **API Token** | The token you copied when creating the API user |

    <Frame>
      <img src="/images/product/cove-connection-fields.png" alt="Blank Cove API Token field and its explanation in MSPortal setup." width="892" height="172" />
    </Frame>

    <Note>
      The Partner Name is your top-level reseller account, not one of your individual clients. The API User Name is the login name you created, not an email address.
    </Note>
  </Step>

  <Step title="Test Connection">
    Click **Test Connection** to verify your credentials. You'll see a **Connection successful!** message and a green banner when the test passes.

    If the connection fails:
    - Verify your Partner Name is your **top-level reseller name** (not an individual client) and matches exactly as shown in Cove
    - Check that your API User Name is correct (the login name, not email)
    - Ensure the API token is copied correctly without extra spaces
    - Verify the API user has the Supporter role
  </Step>

  <Step title="Create Integration">
    Once the connection test passes, click **Create Integration** to save your credentials.

    <Note>
      **Test Connection** does not save anything. If you change a field after testing, test again before you click **Create Integration**.
    </Note>
  </Step>

  <Step title="Continue to Mapping">
    Click **Next** to move to the Map step.
  </Step>
</Steps>

---

### Step 2: Map Partners

Map Cove partners (clients/customers) to your MSPortal companies. This determines which backup data syncs to which company.

<Steps>
  <Step title="Sync Partners">
    Partners do not load until you request them. Click **Sync Partners** (or **Sync** above the list) to fetch partners from your Cove account. The initial sync may take a few minutes depending on your account size.
  </Step>

  <Step title="Use Quick Match">
    Click **Quick Match** to automatically match Cove partners to MSPortal companies based on name similarity. This saves time when you have many partners with matching names.

    <Tip>
      Quick Match uses intelligent name matching to find likely matches. Review the results and make manual adjustments as needed.
    </Tip>
  </Step>

  <Step title="Manual Mapping">
    For partners that weren't automatically matched or need adjustment:

    1. Find the partner in the list
    2. Click the **Select company...** dropdown in the **Mapped** column
    3. Search for and select the correct MSPortal company

    If the company does not exist yet, click the **+** button next to the dropdown to create it and map the partner in one go. MSPortal creates the company right away, so check for an existing match first to avoid duplicates.

    To remove a mapping, click the **X** button next to the company badge. Removing a saved mapping takes effect immediately.
  </Step>

  <Step title="Save Your Mappings">
    New matches show as **Pending** until you save them. Click **Import Selected** to save pending mappings. **Complete Setup** also saves any pending mappings before it closes the wizard.
  </Step>

  <Step title="Filter Partners">
    Click the summary cards above the list to filter the view:
    - **Total Items** - Show all synced partners
    - **Mapped** - Show only partners linked to companies
    - **Unmapped** - Show partners that still need mapping
  </Step>

  <Step title="Complete Setup">
    Once you've mapped the partners you need, click **Complete Setup** to finish the wizard and return to **Settings** > **Integrations**.

    <Info>
      Only backup data from mapped partners syncs to MSPortal. You can return to add more mappings at any time.
    </Info>
  </Step>
</Steps>

## Managing Your Integration

After setup, you can manage your integration from **Settings** > **Integrations**:

| Action | Description |
|--------|-------------|
| **Configure** | Re-open the setup wizard to retest the connection or add more partner mappings |
| **Resync** | Trigger a manual sync of data from Cove |
| **Rename** / **Disconnect** | In the row's **...** menu. Rename labels the connection; Disconnect removes it |
| **Delete** | In the setup wizard footer. Removes the integration and its stored credentials |

Cove supports more than one connection, so you can add a second Cove account as its own row.

### Checking Your Credentials

After the integration is created, the **Partner Name** and **API User Name** fields are locked. To check the stored token, click **Configure**, then click **Retest Connection** on the Connect step.

<Warning>
  **Retest Connection** does not save a new token. To move the integration to a new API user, contact support@msportal.ai before you delete the old API user in Cove.
</Warning>

## Synchronization Process

### Initial Sync
- Partner data syncs when you first click **Sync Partners** on the Map step, or at the next scheduled partner sync
- Backup data syncs separately and may take a few minutes
- Only backup data from mapped partners syncs to MSPortal

### Ongoing Sync

| Data Type | Sync Frequency |
|-----------|----------------|
| Partners | Every 4 hours |
| Devices | Every 30 minutes (at :10 and :40) |
| Backup statistics | Every 30 minutes (at :15 and :45) |

- Partner mappings persist until you change them
- New partners appear after the next partner sync, or right away if you click **Sync** on the Map step

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection test fails | Verify Partner Name (your top-level reseller name, not a client), API User Name, and Token are correct |
| No partners appear | Click **Sync Partners** on the Map step to fetch data from Cove |
| Backup data not showing | Ensure the partner is mapped to a company first |
| Quick Match didn't work | Use manual mapping for partners with different names in Cove vs MSPortal |
| Token expired/invalid | Create a new API user in Cove, then contact support@msportal.ai to move the integration to it |

---

## Important Notes

- **Token Security**: Store your API token securely. If compromised, delete the API user in Cove and create a new one
- **Partner Mapping**: Only backup data from mapped partners will sync to MSPortal
- **Role Permissions**: The Supporter role provides read-only access, which is sufficient for MSPortal integration
- **Sync Timing**: Initial synchronization may take several minutes depending on your account size
