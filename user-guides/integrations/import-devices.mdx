After you connect an RMM or PSA integration, MSPortal syncs devices into a staging area. MSP staff then choose which devices are imported into the asset inventory, using device type matches, auto-import and ignored types.

Every integration that reports devices has an **Import devices** task on its connection page. The task names the records the provider sends, and some controls differ slightly by provider. For example:

## Before you start

- An active integration connected in **Settings > Integrations**
- Companies/sites matched to MSPortal companies (devices from unmatched companies cannot be imported)
- At least one device sync has finished. Check the integration's last synced time. The first sync can take a while for a large account.

Importing or matching at least one company opens the device task for the connected companies. You can leave other companies for later and return to import more devices. Each device still needs its own company match and a device type.

## Open Import devices

<Steps>
  <Step title="Open Integrations">
    Go to **Settings > Integrations** and open the **Active** tab.
  </Step>
  <Step title="Open your connection">
    Click your integration's connection.
  </Step>
  <Step title="Open the device task">
    Select **Import devices** in the **Setup guide**. The workspace is titled for the provider's records, for example **Import Halo PSA assets** or **Import ConnectWise Manage configurations**.
  </Step>
</Steps>

Every change on this page saves immediately.

## Match device types

**Match device types** lists each device type discovered from your integration, with the number of staged devices of that type. Each row shows the MSPortal device type it becomes when imported.

<Note>
Datto RMM uses a two-level classification (for example Category "Server", Type "Virtual Machine"), so its staged devices also show the Datto category.
</Note>

<Steps>
  <Step title="Accept the suggestions">
    Click **Match all suggested** to accept the suggested device type for every type that has one, or accept a suggestion on a single row.
  </Step>
  <Step title="Match the rest with AI">
    Click **Match the rest with AI** to have AI match the types that name matching could not resolve. The matches save right away, so review the result. PSA integrations (ConnectWise Manage, Autotask, Halo PSA and Syncro) do not offer this button.
  </Step>
  <Step title="Adjust manually">
    On any row, choose **Choose device type…** or **Change** to select or change the MSPortal device type. Choose **No device type** to remove a match.
  </Step>
</Steps>

The footer shows how many types still need a device type. If you change a matched type after importing, click **Update imported devices** to apply the new device type to devices already imported.

### Turning on Auto-import

Turn on **Auto-import** for device types you want imported automatically. When it is on:

- New devices of this type are imported automatically after each sync
- No manual review is needed for these device types, so check the match before you turn it on
- The type needs a device type match first

<Tip>
Turn on Auto-import for device types you always want imported (workstations, servers). Leave it off for types you prefer to review manually.
</Tip>

### Ignoring types

Click **Ignore** on a device type you never want to import. This is useful for categories like printers, UPS devices, sensors, or other equipment you don't track in MSPortal.

When a type is ignored:

- The row shows **Ignored**
- Unimported devices of that type are hidden from the staged list
- Pending import counts no longer include devices of that type
- Future syncs automatically mark new devices of that type as ignored

<Info>
Ignoring a type does not affect devices that have already been imported. It only hides unimported devices from the staging area.
</Info>

To bring an ignored type back, click **Restore** on its row. Its hidden devices reappear in the staged list.

## Staged devices

Below the type matches, **Staged devices** lists individual devices the provider sent that are waiting to be imported. For PSA integrations the list is **Staged assets** or **Staged configurations**.

The list shows device details including name, type, company and import status. Use its search and filters to find devices in large lists. A device on a company or site that is not matched shows **Match company first**.

### Importing devices

<Tabs>
  <Tab title="Import all matched">
    Click **Import all matched** to import every unimported device whose type has a device type match. The button is unavailable until at least one type is matched.
  </Tab>
  <Tab title="Import selected">
    1. Check the boxes next to specific devices
    2. Click **Import N selected**, which shows the number of devices you have selected (for example, **Import 5 selected**)
  </Tab>
  <Tab title="Auto-import">
    Turn on **Auto-import** on matched device types to import new devices of those types after each sync. No manual action needed.
  </Tab>
</Tabs>

### Ignoring individual devices

In addition to ignoring entire types, you can ignore individual devices:

1. Select specific devices using the checkboxes
2. Click **Ignore N selected**, which shows the number of devices you have selected (for example, **Ignore 3 selected**)
3. The devices are hidden from the staging list and pending counts

## Syncing new devices

Use **Run sync** in the connection page header to request a sync from the integration. New devices appear in staging after the background sync finishes.

<Note>
Importing NinjaOne devices queues installed-software synchronization when **Software** is enabled for that connection. The software job finishes separately from the device import. Review the imported record in **Devices**, then open **Software** once its inventory is available. See [NinjaOne setup](/user-guides/integrations/enable-ninjaone-integration).
</Note>

- **Auto-import types**: New devices are imported automatically
- **Ignored types**: New devices are automatically marked as ignored
- **Other types**: New devices appear in staging for manual review

For ConnectWise, Autotask, Halo and IT Glue with an RMM connected, Auto-import also decides which records may own a device. A record whose type has Auto-import on and is not ignored can keep or create a device. Other types add their details to devices your RMM reports. See [ConnectWise](/user-guides/integrations/enable-connectwise-integration#devices-from-connectwise-configurations), [Autotask](/user-guides/integrations/enable-autotask-integration#devices-from-autotask-configuration-items) and [Halo](/user-guides/integrations/enable-halo-integration#devices-from-halo-assets) for how devices are removed when the PSA no longer lists them.

## Saving and recovering

Matches, Auto-import, ignored types and imports all save as you make them. **Match the rest with AI** saves its matches, not a preview.

<Warning>
Before you click **Import all matched**, check every matched type. A search or filter on the staged list does not limit that action.
</Warning>

If an action fails, check the saved matches and the Devices inventory before you retry. Staged rows do not mean a device was imported. Ignoring a type never deletes devices that are already imported.

## Best Practices

<CardGroup cols={2}>
  <Card title="Match Types First" icon="diagram-project">
    Set up device type matches before importing individual devices. This ensures devices get the correct type classification.
  </Card>
  <Card title="Turn on Auto-import for Common Types" icon="rotate">
    Turn on Auto-import for workstations and servers to reduce ongoing manual work.
  </Card>
  <Card title="Ignore Unwanted Types" icon="eye-slash">
    Ignore device types you never manage (printers, sensors, UPS). This keeps pending import counts accurate and avoids noise.
  </Card>
  <Card title="Review Before Bulk Import" icon="magnifying-glass">
    Before clicking **Import all matched**, review the type matches to ensure everything is matched correctly. Incorrect matches can be fixed after import with **Update imported devices**, but it's easier to get right the first time.
  </Card>
</CardGroup>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| No devices in staging | Check the company or site is matched to an MSPortal company, then use **Run sync** and wait for it to finish. |
| A device will not import | Match its type to a device type first, and check its company is matched. A device showing **Match company first** needs a company match. |
| A type's devices vanished | The type is ignored. Click **Restore** on its row to bring them back. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Is Match the rest with AI an unsaved preview?">
    No. It saves the generated matches immediately. Review them before you import.
  </Accordion>
  <Accordion title="Do I need to save device type matches?">
    No. Every change on the **Import devices** task saves immediately.
  </Accordion>
  <Accordion title="Does ignoring a type delete devices I already imported?">
    No. It only hides unimported devices and marks future ones as ignored.
  </Accordion>
  <Accordion title="Does a finished sync mean the devices were imported?">
    No. A sync fills the staging list. Import the devices, then check the Devices page.
  </Accordion>
</AccordionGroup>
