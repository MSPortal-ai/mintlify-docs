This guide walks you through connecting QuoteWerks Web to MSPortal.ai. Setup happens on the QuoteWerks connection page, where the **Setup guide** lists three tasks: **Connect**, **Import or match companies** and **Review**. Map customers to the correct portal companies before checking their quotes. See [Connect and manage integrations](/user-guides/integrations/index#connect-match-and-verify) for the shared connection tasks.

## Overview

QuoteWerks is a quoting and proposal platform used by MSPs to create and deliver sales quotes. By integrating QuoteWerks with MSPortal.ai, you can:

- View QuoteWerks quotes, including line items, on the MSPortal **Quotes** page
- Map QuoteWerks customers to your MSPortal companies for a unified view
- Optionally surface customer-facing QuoteValet links directly on each quote

## Prerequisites

Before you begin, ensure you have:

- An active QuoteWerks Web account with access to Setup options. This integration supports QuoteWerks Web only, not QuoteWerks Desktop.
- A QuoteWerks Web user with **MasterRights** to create the API key
- Admin access to MSPortal.ai with the **manage_settings_integrations** permission
- Companies already set up in MSPortal (from your PSA integration or manually created), or permission to import new companies while matching

## Part 1: Create an API Key in QuoteWerks

<Steps>
  <Step title="Log into QuoteWerks Web">
    Open your QuoteWerks Web instance in the browser, for example `https://na.quotewerks.com/`.
  </Step>

  <Step title="Open the API Settings">
    Go to **Setup > Options > Zapier and API**.
  </Step>

  <Step title="Create a New Key">
    Click **Create a New Key** and name it `MSPortal` so you can identify its purpose later.
  </Step>

  <Step title="Copy the API Key">
    Click on the API key to copy it. Copy only the key value, without an `X-API-Key:` or `Bearer` prefix. It should look like this:

    ```
    qww_live_0a1BcDeF2gHiJkLmN3oPqRsT4uVwXyZ5aBcDeF6gHiJ
    ```

    <Warning>
      Treat this key like a password. Anyone with the key can read your QuoteWerks data.
    </Warning>
  </Step>
</Steps>

## Part 2: Connect QuoteWerks in MSPortal

### Open the connection page

<Steps>
  <Step title="Navigate to Integrations">
    In MSPortal, go to **Settings > Integrations**.
  </Step>

  <Step title="Start Setup">
    On the **Directory** tab, find **QuoteWerks** and select **Connect**. If you already have a QuoteWerks connection, open it from the **Active** tab instead.
  </Step>
</Steps>

---

### Task 1: Connect

<Steps>
  <Step title="Confirm the Base URL">
    The **Base URL** field is prefilled with the QuoteWerks Web cloud default (`https://qwwapi.quotewerks.com`). Most users can leave it as is. If you run a self-hosted QuoteWerks Web instance, replace it with your instance's API URL.
  </Step>

  <Step title="Paste Your API Key">
    Paste the API key you copied from QuoteWerks into the **API Key** field.
  </Step>

  <Step title="Add a QuoteValet Link (Optional)">
    If you use QuoteValet to deliver quotes to customers, paste any QuoteValet quote link into the **QuoteValet link (optional)** field. MSPortal extracts your QuoteValet account id from the link and uses it to build customer-facing quote links on the Quotes page.

    <Note>
      You can skip this field and add it later. It only affects whether QuoteValet links appear on quotes; the quote sync works without it.
    </Note>
  </Step>

  <Step title="Test Connection">
    Select **Test connection**. You must test before you can save. On success, MSPortal shows **Connection verified** and the QuoteWerks user the key authenticates as. Testing does not save anything and does not import quotes.

    If the connection fails:
    - Check that the API key is copied exactly, with no extra spaces
    - Verify the key is still active under **Setup > Options > Zapier and API** in QuoteWerks
  </Step>

  <Step title="Save and Continue">
    Select **Save and continue**. MSPortal tests the key again, saves the connection, and starts a background customer sync for the matching task.

    <Info>
      Credentials are stored in the vault and never shown again. They are only used by server-side sync jobs.
    </Info>
  </Step>
</Steps>

---

### Task 2: Import or match companies

Match your QuoteWerks customers to MSPortal companies. This determines which company each quote is attached to in MSPortal. The workspace is titled **Import or match QuoteWerks customers**.

<Steps>
  <Step title="Wait for the Customer Sync">
    After connecting, MSPortal fetches your customers from QuoteWerks. This may take a few moments depending on the size of your account. If no customers have arrived yet, select **Sync customers**.
  </Step>

  <Step title="Accept Strong Matches">
    The workspace opens on the **Import** view, which lists every customer that still needs a company, with a suggestion where MSPortal found one. **Suggested** narrows the list to suggestions. Select **Accept N strong matches** to review and accept every suggestion with 90% confidence or more, or select **Accept** on a single row. Each accepted match saves immediately.
  </Step>

  <Step title="Match or Import the Rest">
    In the **Import** view, select **Choose company…** to pick the correct MSPortal company for a customer without a suggestion, or select **Import** on the row to create a new portal company from the customer. Use **Ignore** for customers you never want matched.
  </Step>

  <Step title="Continue">
    Select **Continue to Review**. For more detail, see [Map QuoteWerks customers](/user-guides/integrations/map-quotewerks-customers).
  </Step>
</Steps>

<Note>
  Quotes only appear in MSPortal for customers that are matched to a company. You can return to this task at any time to match newly added customers.
</Note>

---

### Task 3: Review

<Steps>
  <Step title="Check Each Task">
    **Review** lists each setup task with its status and how many customers are matched.
  </Step>

  <Step title="Finish Setup">
    Select **Finish setup**. This records that setup is complete. It does not start a quote sync on its own.
  </Step>

  <Step title="Start the Quote Sync">
    In the connection page header, select **Run sync**, then **Quotes** (or **All data**) to pull your QuoteWerks quote headers and line items into MSPortal. Check **Sync activity**, then open **Quotes** and check a known quote's company, number, line items and totals.
  </Step>
</Steps>

<Info>
  After setup, QuoteWerks syncs automatically in the background. Quotes refresh every 4 hours and customers refresh daily (02:30 UTC). Historical import windows and provider data can limit results. Ask support to investigate a missing older quote rather than assuming a manual sync imports all history.
</Info>

## What Gets Synced

| Data Type | Direction | Description |
|-----------|-----------|-------------|
| Customers | QuoteWerks → MSPortal | Customer records for mapping to MSPortal companies |
| Quotes | QuoteWerks → MSPortal | Quote headers shown on the Quotes page |
| Line Items | QuoteWerks → MSPortal | Products and services on each quote |

## Managing Your Integration

After setup, open your QuoteWerks connection from the **Active** tab in **Settings > Integrations**. Use the **Setup guide** to return to any task, and the header for these actions:

| Action | Description |
|--------|-------------|
| **Run sync** | Start a sync for **All data**, **Customers** or **Quotes** |
| **More actions > Rename** | Give the connection a nickname |
| **More actions > Disconnect…** | Remove the stored credentials, the matches between QuoteWerks customers and your companies, and the synced QuoteWerks data |

If you have more than one QuoteWerks connection, confirm you have the intended one open before changing credentials.

### Rotating the API Key

If you need to replace the API key, create a new key in QuoteWerks under **Setup > Options > Zapier and API**. Then open **Connect** on the connection, type the new key into **API Key**, select **Test connection**, then **Save changes**. Leaving the stored key unchanged keeps it.

### Changing the Base URL or QuoteValet Link

<Steps>
  <Step title="Open Connect">
    Open your QuoteWerks connection and select **Connect** in the **Setup guide**. The stored API key is not shown.
  </Step>
  <Step title="Edit the Settings">
    Change the **Base URL** or paste a new link into **QuoteValet link (optional)**. Changing the **Base URL** asks for the API key again, because a stored key is only sent to the URL it was saved with. A blank QuoteValet field keeps the existing QuoteValet setting; it does not remove it.
  </Step>
  <Step title="Save Changes">
    Select **Test connection**, then **Save changes**, and wait for the success message before you leave. Testing alone does not save. Saving tests the connection again and starts a customer sync.
  </Step>
</Steps>

### Disconnecting the Integration

Select **More actions > Disconnect…** and confirm. This removes the stored credentials, the customer matches and the synced QuoteWerks data from MSPortal. It cannot be undone. It does not delete quotes in QuoteWerks or the MSPortal companies you matched to. To fix a single wrong match, change it in **Import or match companies** instead of disconnecting.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection test fails">
    **Causes:**
    - The API key was copied incorrectly or has extra whitespace
    - The key includes an `X-API-Key:` or `Bearer` prefix
    - The key was deleted or regenerated in QuoteWerks
    - The QuoteWerks Web user does not have **MasterRights**, or the key is from QuoteWerks Desktop

    **Solutions:**
    1. Copy the key again by clicking on it in **Setup > Options > Zapier and API**
    2. Create a new key named `MSPortal` and enter it on the **Connect** task
  </Accordion>

  <Accordion title="No customers appear in the matching task">
    **Causes:**
    - The initial customer sync is still in progress

    **Solutions:**
    1. Wait a few minutes, or select **Sync customers** and wait for new customers to arrive
    2. Verify the connection test passes on the **Connect** task
  </Accordion>

  <Accordion title="Quotes are missing from the Quotes page">
    **Causes:**
    - The customer on the quote is not matched to an MSPortal company
    - No quote sync has run yet

    **Solutions:**
    1. Open **Import or match companies** and match the customer to a company
    2. Select **Run sync > Quotes**, or wait for the background sync, which refreshes quotes every 4 hours
    3. See [Troubleshoot QuoteWerks quotes](/user-guides/quotes/troubleshoot-quotewerks-quotes) for more checks
  </Accordion>

  <Accordion title="QuoteValet links do not appear on quotes">
    **Causes:**
    - No QuoteValet link was provided during setup

    **Solutions:**
    1. Open **Connect**, paste any QuoteValet quote link into the **QuoteValet link (optional)** field, then select **Test connection** and **Save changes**
  </Accordion>

  <Accordion title="Does Finish setup confirm quote synchronization?">
    No. **Finish setup** records that setup is complete. Use **Run sync** and inspect the resulting quotes and **Sync activity**.
  </Accordion>

  <Accordion title="Can a company user change QuoteWerks credentials?">
    No. Company users ask their MSP to manage the integration. The MSP also handles user permissions and company access.
  </Accordion>
</AccordionGroup>
