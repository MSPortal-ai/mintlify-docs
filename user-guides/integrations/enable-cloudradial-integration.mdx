This guide walks you through connecting your CloudRadial account to MSPortal.ai using our streamlined setup wizard.

## Overview

CloudRadial is a client portal platform where many MSPs maintain a service catalog of request forms. By integrating CloudRadial with MSPortal.ai, you can:

- Import CloudRadial service catalog items directly as MSPortal ticket templates
- Preserve each item's name, description, category, and PSA routing details
- Import client-specific catalog items and assign them to the matching company
- Choose exactly which items to bring over, one time or in batches

## Prerequisites

- Active CloudRadial partner account with API access
- CloudRadial public and private API keys
- MSPortal.ai account with integration management permissions
- Permission to write Ticket Settings, which the import itself requires

## Part 1: Generate CloudRadial API Keys

Before connecting to MSPortal.ai, you need API credentials from CloudRadial.

<Steps>
  <Step title="Log into CloudRadial">
    Access your CloudRadial Partner Portal.
  </Step>

  <Step title="Navigate to API Keys">
    Go to **Settings > API Keys** in the Partner Portal.
  </Step>

  <Step title="Create an API Key">
    Create a new API key. CloudRadial issues a **Public Key** and a **Private Key** pair; MSPortal needs both.
  </Step>

  <Step title="Copy Both Keys">
    Copy the public and private keys.

    <Warning>
      **Store the private key securely!** Treat it like a password. If you lose it, create a new key pair.
    </Warning>

    <Tip>
      Note which region your CloudRadial account is hosted in (United States, Canada, United Kingdom, Australia, or Europe). You will select this region in the MSPortal wizard so requests go to the correct API endpoint.
    </Tip>
  </Step>
</Steps>

## Part 2: MSPortal Setup Wizard

MSPortal.ai provides a guided 2-step wizard to connect CloudRadial and import catalog items.

### Starting the Wizard

<Steps>
  <Step title="Navigate to Integrations">
    In MSPortal.ai, go to **Settings > Integrations**.
  </Step>

  <Step title="Find CloudRadial">
    Locate the **CloudRadial** card under **Add integration**.
  </Step>

  <Step title="Start Setup">
    Click **Connect** to launch the setup wizard.
  </Step>
</Steps>

---

### Step 1: Connect

Enter your CloudRadial API credentials to establish the connection.

<Steps>
  <Step title="Select Your Region">
    Choose your CloudRadial hosting region from the **Region** dropdown: United States, Canada, United Kingdom, Australia, or Europe.

    The wizard shows the API endpoint that will be used for the selected region. Confirm it matches your region before you test.

    ![CloudRadial Connect step with the Region dropdown and blank Public Key and Private Key fields](/images/product/cloudradial-region-fields.png)
  </Step>

  <Step title="Enter Your Keys">
    Paste your credentials into the **Public Key** and **Private Key** fields.

    <Note>
      Your private key is stored securely using Supabase Vault encryption. It is never exposed in logs or API responses.
    </Note>
  </Step>

  <Step title="Test Connection">
    Click **Test Connection** to verify your credentials.

    You'll see a "Connection verified successfully" message when the test passes.

    If the connection fails:
    - Verify both keys were copied fully without extra spaces
    - Confirm you selected the region that matches your CloudRadial account
    - Check that the API key has not been revoked in CloudRadial
  </Step>

  <Step title="Create Integration">
    Once the connection test passes, click **Create Integration** to save your credentials, then click **Next**. A successful test on its own does not save anything.
  </Step>
</Steps>

---

### Step 2: Import

Select the catalog items you want to bring into MSPortal as ticket templates.

<Steps>
  <Step title="Browse the Catalog">
    The Import step lists every catalog item from your CloudRadial account with sortable columns for **Name**, **Category**, **Template Pack**, and **PSA Board**.

    Use the search box to filter by name, description, or category. **Refresh** re-fetches the catalog from CloudRadial, and **Export** downloads the current filtered view as a CSV file (all rows shown, not only the checked ones).
  </Step>

  <Step title="Choose a View">
    Two tabs control which items you see:

    | Tab | Description |
    |-----|-------------|
    | **All Items** | Every catalog item, deduplicated across companies |
    | **Client-Specific** | Items that exist for only a single company; imports from this tab assign the template to that company |

    Switching tabs clears your selection and search.
  </Step>

  <Step title="Select Items">
    Check the items you want, or use **Select All** / **Deselect All**. Items flagged as partner managed show a **Partner** badge.

    <Warning>
      Searching does not clear items you already checked. Clear the search and review the selected count before you import, so hidden items are not imported by accident.
    </Warning>
  </Step>

  <Step title="Import">
    Click **Import** to convert the selected items into ticket templates. Imported templates are active right away.

    The results panel lists each item's outcome. Templates that imported successfully stay in place even if other items in the batch fail.

    <Warning>
      Importing an item again does not skip it. If a template with the same name already exists, MSPortal creates a renamed copy. Check your existing templates before you re-import.
    </Warning>
  </Step>

  <Step title="Review the Imported Templates">
    Open your [ticket templates](/user-guides/ticketing/how-to-create-a-ticket-template) and check each imported template's fields, defaults, PSA routing, and company settings before clients use it.
  </Step>

  <Step title="Complete Setup">
    Click **Complete Setup** to finish the wizard and return to the Integrations page. Completing setup does not undo any import.
  </Step>
</Steps>

## What Gets Imported

CloudRadial catalog items are imported as MSPortal ticket templates, including:

- Item name and description
- Category and template pack
- PSA routing details: board, type, subtype, status, and priority
- Company assignment for client-specific items

Client-specific items are assigned to the MSPortal company whose name matches the CloudRadial company name (ignoring case). The template is turned off for every other company. If no company name matches, the template imports with no company restriction and is available to every company, so check its company settings after import.

<Note>
The import creates templates in MSPortal; it does not modify anything in CloudRadial.
</Note>

## Synchronization Schedule

CloudRadial is an on-demand import, not a recurring sync:

| Data Type | Sync Frequency |
|-----------|----------------|
| Catalog items | On demand, when you click **Import** in the wizard |

<Note>
When you add new catalog items in CloudRadial, open the integration again, go to the Import step, click **Refresh**, and import only the new items. Re-importing an existing item creates a renamed copy.
</Note>

## Managing Your Integration

After setup, manage your integration from **Settings > Integrations**:

| Action | Description |
|--------|-------------|
| **Configure** | Re-open the wizard to import more items or update credentials |
| **Test Connection** | Verify your API keys are still valid |
| **Delete** | Remove the integration (available in the wizard footer) |

### Updating Your API Keys

<Steps>
  <Step title="Open the Integration">
    Go to **Settings > Integrations** and click **Configure** on the CloudRadial row.
  </Step>
  <Step title="Enter New Keys">
    On the Connect step, enter the new public key. Leave the private key blank to keep the existing one, or enter a new private key to replace it.
  </Step>
  <Step title="Test and Update">
    Click **Test Connection**, then **Update Integration** to save.
  </Step>
</Steps>

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection test fails | Verify both keys are correct and the selected region matches your CloudRadial account |
| No catalog items found | Confirm your CloudRadial account has catalog items and click **Refresh** |
| Duplicate or renamed templates appear | The item was imported more than once. Delete the extra copies in Ticket Templates and edit the original instead of re-importing |
| Import fails with a permission error | You need permission to write Ticket Settings in addition to integration access |
| A client-specific template is available to every company | No MSPortal company name matched the CloudRadial company name. Restrict the template to the right company in its settings |
| Some items failed to import | Check the per-item error in the import results panel, then re-select and re-import only the failed items |
| New CloudRadial items missing | Click **Refresh** on the Import step to re-fetch the catalog |

## Security & Privacy

- **Credential Storage**: Your CloudRadial private key is encrypted using Supabase Vault and never exposed in logs or responses
- **Data Isolation**: All imported templates are tenant-isolated and only visible to your organization
- **Read-Only Access**: MSPortal only reads your CloudRadial catalog; it never modifies your CloudRadial configuration
