Connect your Auvik service account, match its sites to portal companies, then review the imported network data.

Open **Settings > Integrations**, find the provider in the directory, and open its setup. You need an MSP staff account with permission to manage integrations. Company users should ask their MSP to connect the service.

## Before you start

Use an Auvik API service account with read access to tenants, inventory devices, and alert history. Find the region code in your dashboard URL, immediately before `.my.auvik.com`.

## Connect and map sites

1. In **Connect**, choose **Auvik region** and enter **Account username** and **API key**.
2. Select **Test Connection**. After verification, select **Create Integration**. For an existing connection, use **Save connection**.
3. Continue to **Map sites**. Allow the first sync to discover your sites.
4. Link each site to its MSPortal company. Several sites may map to one company. Review proposed matches before saving them.
5. Continue to **Review and import**. Inventory is collected only for mapped sites. At least one mapped site and a successful sync are required to finish setup.

## Review and import

Map device types before selecting **Import selected**. Selected devices that match existing records are linked; unmatched selections create new devices. Existing company, name, and RMM details on matched devices are retained.

Recent alert history covers alerts detected in the last 30 days, including resolved or paused alerts. It is not a list of currently open incidents. Device and alert tables follow your selected companies; connection and mapping totals cover the integration.

## Troubleshooting

- **No sites yet:** wait for discovery to finish; large accounts can take a few minutes.
- **No devices:** verify the site-to-company mapping and run the next sync before importing.
- **Setup cannot finish:** map at least one site and wait for a successful sync.
- **Connection rejected:** check the region code, username, API key, and account read permissions.
