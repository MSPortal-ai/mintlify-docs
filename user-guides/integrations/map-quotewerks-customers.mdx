Use the **Map** step in QuoteWerks setup to link each imported QuoteWerks customer to the right MSPortal company. A saved link decides which company a customer's quotes and line items belong to.

## Before you start

- You are MSP staff with integration-company mapping access. Company users ask their MSP to fix a mapping.
- QuoteWerks is connected and its customers have been imported. See [Connect and manage QuoteWerks](/user-guides/integrations/enable-quotewerks-integration).
- To create a new portal company from this page you also need company-write access and active billing.

## Find the customer

<Steps>
  <Step title="Open the Map step">
    Go to **Settings > Integrations**, manage the **QuoteWerks** connection and open **Map**.
  </Step>
  <Step title="Find the row">
    Wait for the customer table to load. Use the **Name** and **Mapped** filters to find the customer. The **QuoteWerks ID** column shows the source record. You never type it in.
  </Step>
  <Step title="Import missing customers">
    If a new customer is missing, select **Sync** and wait for the customer import to finish.
  </Step>
</Steps>

The **Total Items**, **Mapped** and **Unmapped** cards count pending choices too. Check each row's **Pending** or **Saved** status to see what is really stored.

## Link one customer to an existing company

<Steps>
  <Step title="Choose the company">
    In the customer's company selector, search for the MSPortal company and select it. Check the name carefully when several companies look alike.
  </Step>
  <Step title="Review the pending choice">
    The row shows **Pending**. Nothing is saved yet. Clear any unrelated row checkboxes, because **Import Selected** can create new companies for selected unmapped rows.
  </Step>
  <Step title="Save the link">
    Select **Import Selected** and wait for the row to show **Saved**. This saves pending mappings even when no row is checked.
  </Step>
  <Step title="Check the result">
    Reopen the **Map** step to confirm the company, then open a quote for that customer under **Quotes**. Saving a link also moves the customer's already imported quotes and line items to the company, so you do not need to reimport.
  </Step>
</Steps>

## Assign several customers to one company

<Steps>
  <Step title="Select the customers">
    Check the boxes for only the customers you want.
  </Step>
  <Step title="Choose the company">
    In the bulk company selector, pick the existing company.
  </Step>
  <Step title="Assign">
    Select **Assign**. The rows show **Pending** and the selection clears.
  </Step>
  <Step title="Save">
    Review the pending company names, select **Import Selected** and check the rows show **Saved**.
  </Step>
</Steps>

Several customers can share one company. Check that all their quotes belong under that company first.

## Use Quick Match

<Steps>
  <Step title="Open Quick Match">
    Select **Quick Match** while unmapped customers remain.
  </Step>
  <Step title="Review the suggestions">
    Check each customer and company pair and its confidence score. A narrowed search can hide suggestions that are still selected, so review the full selection. Adjust the threshold or selections if needed.
  </Step>
  <Step title="Apply and save">
    Apply the suggestions you want. They appear as **Pending**. Select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

A high score is only a name match. Confirm the two records are the same organization.

## Create a company when none exists

<Steps>
  <Step title="Open Create Company">
    Use the add-company control on the customer's row.
  </Step>
  <Step title="Name and create it">
    Confirm the company name and submit. The company is created right away and the customer's link stays **Pending**.
  </Step>
  <Step title="Save the link">
    Select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

<Warning>
**Import Selected** both saves pending mappings and creates companies for selected unmapped customers. To reuse existing companies, choose them first with the row selector or **Assign**, and clear unrelated selections.
</Warning>

## Clear or change a link

<Steps>
  <Step title="Click the x on the row">
    On a **Pending** row, the **x** clears the unsaved choice. On a **Saved** row, it removes the saved link right away, with no confirmation.
  </Step>
  <Step title="Choose the correct company">
    Pick the right company in the row selector.
  </Step>
  <Step title="Save">
    Select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

Removing a saved link leaves the quotes and line items already imported without a company, so the previous company's users can no longer see them. It does not delete the QuoteWerks customer, the quotes or the company. Clearing a pending link does not delete a company you just created.

## Finish the step

<Steps>
  <Step title="Save first">
    Select **Import Selected** and check that every intended row shows **Saved**.
  </Step>
  <Step title="Continue">
    Select **Next**. It tries to save pending work, so check for any error. Clicking a step heading instead can discard unsaved choices.
  </Step>
  <Step title="Start the quote sync">
    On **Complete**, select **Start quote sync** to import quotes from QuoteWerks.
  </Step>
</Steps>

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A customer is missing | Select **Sync** and wait for the import to finish. |
| Counts changed but nothing saved | Counts include pending choices. Select **Import Selected** and check for **Saved**. |
| New companies appeared that you did not want | **Import Selected** created them for selected unmapped rows. Clear unrelated selections and pick existing companies first next time. |
| A company's quotes disappeared from its users | A saved link was removed. Relink the customer and save. |
| You cannot create a company | Creating a company needs company-write access and active billing. Ask an MSP administrator. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does choosing a company save the mapping?">
    No. The row shows **Pending** until you select **Import Selected** and it shows **Saved**.
  </Accordion>
  <Accordion title="Does bulk Assign save?">
    No. It stages pending choices and clears the selection. Save with **Import Selected**.
  </Accordion>
  <Accordion title="Does Quick Match save its suggestions?">
    No. Applied suggestions are **Pending** until you save them.
  </Accordion>
  <Accordion title="Do I need to check a row to save a pending link?">
    No. **Import Selected** saves pending mappings without any checked rows. Checked unmapped rows are used to create new companies.
  </Accordion>
  <Accordion title="Do I need to sync quotes again after fixing a mapping?">
    No. Saving a mapping moves the quotes and line items already imported. Sync only brings in new or changed data from QuoteWerks.
  </Accordion>
  <Accordion title="Can several QuoteWerks customers map to one company?">
    Yes. Use the row selector or **Assign**, then save.
  </Accordion>
</AccordionGroup>
