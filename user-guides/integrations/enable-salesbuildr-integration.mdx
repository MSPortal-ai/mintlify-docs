This guide walks you through connecting Salesbuildr to MSPortal.ai. Setup happens on the Salesbuildr connection page, where the **Setup guide** lists **Connect**, **Import or match companies**, the optional **Configure client quotes** and **Review**. Salesbuildr supplies company records for matching, quotes and line items for matched companies, and products that MSP staff can import into their budget catalog. See [Connect and manage integrations](/user-guides/integrations/index#connect-match-and-verify) for the shared connection tasks.

## Overview

Salesbuildr is a quoting and sales platform for MSPs. By integrating Salesbuildr with MSPortal.ai, you can:

- Show Salesbuildr quotes, including line items and totals, on the MSPortal **Quotes** page for your team and for client portal users
- Map Salesbuildr companies to your MSPortal companies so each client only sees their own quotes
- Open any quote in the Salesbuildr customer quote portal, or download its PDF, straight from MSPortal
- Import Salesbuildr products into your budget catalog so budgets use your real sell prices and billing cadence

<Note>
Salesbuildr is in beta. If the integration is not available in **Settings > Integrations**, contact support@msportal.ai.
</Note>

## Prerequisites

Before you begin, ensure you have:

- Salesbuildr administrator access, with the **Public API** feature enabled on your Salesbuildr account
- Your Salesbuildr account URL, which ends in `.salesbuildr.com` (for example `https://acme.salesbuildr.com`)
- Admin access to MSPortal.ai with the **manage_settings_integrations** permission
- Companies already set up in MSPortal (from your PSA integration or manually created), or permission to import new companies while matching

## Part 1: Create an API Key in Salesbuildr

<Steps>
  <Step title="Open API settings">
    In Salesbuildr, go to **Settings > Integrations > API Key**.
  </Step>
  <Step title="Create the key">
    Create an API key named `MSPortal` and copy it to a secure location.

    <Warning>
      Treat this key like a password. Anyone with the key can read your Salesbuildr data.
    </Warning>
  </Step>
  <Step title="Copy the account URL">
    Note the `.salesbuildr.com` address you use to sign in. A custom quote portal domain does not serve the API and will not work here.
  </Step>
</Steps>

---

## Part 2: Connect Salesbuildr in MSPortal

### Task 1: Connect

<Steps>
  <Step title="Open the connection page">
    In MSPortal, go to **Settings > Integrations**. On the **Directory** tab, find **Salesbuildr** and select **Connect**. To continue an existing connection, open it from the **Active** tab.
  </Step>
  <Step title="Enter the connection details">
    Enter the **Account URL** and the **API key**. You can paste the full URL from your browser; everything after the host name is ignored. Paste only the key value, without an `api-key:` prefix.
  </Step>
  <Step title="Test the connection">
    Select **Test connection**. You must test before you can save. MSPortal verifies the API key and reports the number of companies it can see. That count is not the number of companies matched or quotes imported. Testing does not save anything.
  </Step>
  <Step title="Save and continue">
    Select **Save and continue** and wait for success. MSPortal tests the connection again, stores the API key in the vault, and starts importing your Salesbuildr company list in the background. If that import cannot start, the saved connection still exists; check **Import or match companies** rather than creating another connection.
  </Step>
</Steps>

### Task 2: Import or match companies

Link each Salesbuildr company to the matching MSPortal company. The workspace is titled **Import or match Salesbuildr companies**.

- The workspace opens on the **Import** view, which lists every company that still needs a match. **Suggested** narrows it to proposed matches.
- Select **Accept** on a correct suggestion, or **Accept N strong matches** to review and accept every suggestion with 90% confidence or more.
- For anything without a suggestion, select **Choose company…**, or select **Import** on the row to create a new MSPortal company from the Salesbuildr record.
- Each match saves immediately. There is no separate save step.
- Only quotes for matched companies are imported. Unmatched Salesbuildr companies are skipped until you match them.

Select **Continue to Review** when you are done. For more detail, see [Map Salesbuildr companies](/user-guides/integrations/map-salesbuildr-companies).

### Task 3 (optional): Configure client quotes

Choose what clients get when they open a Salesbuildr quote in the portal. New connections start with **Show the PDF**. Connections created before this choice was added keep **Link to Salesbuildr** until you change it.

<Steps>
  <Step title="Open Configure client quotes">
    In the **Setup guide**, select **Configure client quotes**. It opens once **Connect** is complete.
  </Step>
  <Step title="Choose an option">
    Under **How clients open quotes**, choose **Show the PDF** so clients view and download the quote PDF in the portal without a Salesbuildr login. Choose **Link to Salesbuildr** to open quotes in your Salesbuildr customer portal, only if your clients have Salesbuildr logins.
  </Step>
</Steps>

Your choice saves as soon as you select it. Your staff always see both the Salesbuildr link and the PDF download. With more than one Salesbuildr connection, the choice on the oldest active connection applies to every client.

### Task 4: Review

Select **Finish setup** once the required tasks are complete. Finishing records that setup is complete. It does not start a quote sync.

### Start and verify the quote sync

Quotes are only staged for matched companies, so newly matched companies have no quotes until a quote sync runs. In the connection page header, select **Run sync**, then **Quotes** (or **All data**). A started message confirms the request, not that every quote imported. Check **Sync activity**, then open **Quotes** and check a known quote's company, number, status, line items, totals and document.

---

## What Gets Synced

| Data | Schedule | Notes |
|------|----------|-------|
| Companies | Nightly, plus after the connection is saved and from **Run sync** | Source list for company matching (customers, leads, and your own record; suppliers, manufacturers, vendors and distributors are skipped) |
| Quotes and line items | Every 4 hours, plus from **Run sync** | Only for matched companies; deleted quotes are removed on the next sync |
| Products | Nightly, plus from **Run sync** | Available in **Budgets > Products > Import**; products removed in Salesbuildr stop being offered |

Each quote shows its number, title, status, the Salesbuildr contact and owner, and monthly, annual, and one-time totals calculated from its line items. **Open in Salesbuildr** opens the customer quote portal for that quote, and **Download PDF** fetches the current quote PDF from Salesbuildr.

## Using Salesbuildr Products in Budgets

<Steps>
  <Step title="Open the import dialog">
    Go to **Budgets**, open **Budgets Menu > Products**, and click **Import from Integrations**. Salesbuildr products appear alongside products from your PSA, with their name, SKU, category, vendor, and unit price.
  </Step>
  <Step title="Import or link">
    Select the products you want in your catalog and import them, or link a Salesbuildr product to a catalog product you already maintain. Imported products keep their billing cadence (monthly, annual, or one-time), setup price, unit, and product type from Salesbuildr.
  </Step>
  <Step title="Add to a budget">
    In the budget builder, the **Products and Services** panel lists your catalog. Adding a Salesbuildr product creates a line with the right recurrence; a product with a setup fee also adds a one-time setup line so onboarding costs land in the first month.
  </Step>
</Steps>

Importing products does not change existing budget lines. Review product prices and recurrence in your budgets separately.

## Managing the Connection

- Open your Salesbuildr connection from the **Active** tab in **Settings > Integrations**. Use the **Setup guide** to return to any task.
- To rotate the API key or change the account URL, open **Connect**. The stored key is not shown; leave it unchanged to keep it, or type a new one. Changing the **Account URL** asks for the key again, because a stored key is only sent to the address it was saved with. Select **Test connection**, then **Save changes**. Navigating away does not save edited fields.
- Matches can also be managed with **Map companies** on **Settings > Integrations**, alongside your other integrations. Removing a match removes that company's imported quotes; matching it to a different company moves them to the new company.
- To change how clients open quotes, select **Configure client quotes** in the **Setup guide**.
- To rename the connection, select **More actions > Rename**.
- To remove the integration, select **More actions > Disconnect…** and confirm. This removes the stored credentials, the company matches and the data synced from Salesbuildr. It does not change anything in Salesbuildr or delete the MSPortal companies you matched to.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Account URL is rejected | Enter your `.salesbuildr.com` address. A custom quote portal domain does not serve the API. |
| API key is rejected | Confirm the **Public API** feature is enabled in Salesbuildr and the user has the Admin role. Create a new key under **Settings > Integrations > API Key**, paste it on **Connect** without extra spaces, then select **Test connection** and **Save changes**. |
| A client sees no quotes | Confirm their Salesbuildr company is matched to their MSPortal company and that a quote sync has run since the match was saved. |
| Supplier or manufacturer records are missing from matching | Salesbuildr supplier, manufacturer, vendor and distributor companies are excluded. Check the record type in Salesbuildr. |
| The integration shows as paused | The API key was revoked or Salesbuildr was unreachable for an extended period. Open **Connect**, enter a working key, then select **Test connection** and **Save changes** to resume syncing. Check the next quote sync in **Sync activity**. |
| An existing connection opens as a blank setup form | The saved connection may have failed to load. Return to **Settings > Integrations** and check its status before creating another connection. |
