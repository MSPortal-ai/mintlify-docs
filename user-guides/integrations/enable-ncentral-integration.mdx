Connect N-able N-central to MSPortal.ai to synchronize customers, map them to MSPortal companies, and import managed devices. The setup wizard has three steps: **Connect**, **Map** and **Import**.

<Note>
N-central setup is available only for MSP tenants where it has been enabled. If **N-able N-central** does not appear in **Settings > Integrations**, contact support@msportal.ai.
</Note>

## Prerequisites

- An N-central account with permission to create an API-only user and generate an API token
- The HTTPS URL for your N-central server
- MSPortal.ai integration management permission
- Companies in MSPortal to map to N-central customers

## Create an N-central API Token

<Steps>
  <Step title="Create an API-only user">
    In N-central, create a dedicated API-only user for MSPortal. Disable MFA for this API user and use a non-expiring password so scheduled synchronization can continue. Give the user access to the customers you want to sync.
  </Step>
  <Step title="Open API Access">
    Go to **Administration > User Management > Users**, open the API user, and select **API Access**.
  </Step>
  <Step title="Generate the token">
    Click **Generate JSON Web Token** and copy the token. Store it securely until you enter it in MSPortal.
  </Step>
</Steps>

## Connect N-central in MSPortal

<Steps>
  <Step title="Open the setup page">
    In MSPortal, go to **Settings > Integrations**, find **N-able N-central**, and click **Connect**. For an existing connection, click **Configure**.
  </Step>
  <Step title="Enter the connection details">
    Enter your **Server URL**, such as `https://ncentral.example.com`, and the **API Token (JWT)** generated in N-central.
  </Step>
  <Step title="Test the connection">
    Click **Test Connection**. Resolve any authentication or server URL error before continuing.
  </Step>
  <Step title="Create the integration">
    After the test succeeds, click **Create Integration**. MSPortal stores the token securely and starts customer discovery. A successful test alone does not save the connection.
  </Step>
</Steps>

## Map Customers and Import Devices

<Steps>
  <Step title="Wait for customers to load">
    In the **Map** step, MSPortal shows your N-central customers once discovery finishes. This usually takes less than a minute. If the list is still empty, click **Check for Customers** or **Sync Customers**.
  </Step>
  <Step title="Map N-central customers">
    Link each N-central customer to the company it belongs to in MSPortal. Click **Quick Match** to suggest mappings by name, review the suggested matches and their confidence scores, then click **Apply Matches**. You can also pick a company from the dropdown in each row.
  </Step>
  <Step title="Save the mappings">
    New links show as **Pending**. Click **Import Selected** to save them, or click **Next**, which also saves pending links. Removing a saved link with the **X** button takes effect immediately.
  </Step>
  <Step title="Open device import">
    In the **Import** step, click **Open Device Import**.
  </Step>
  <Step title="Review device types">
    Map the N-central device categories to your MSPortal device types. Use **Quick Match**, **Map with AI** or **Quick Create** to speed this up. Turn on **Auto-Sync** for types you always want imported, and check **Ignore** for types you never want.
  </Step>
  <Step title="Import devices">
    Select the devices you want to import and click **Import Selected**, or click **Import All** on a device type row. Only devices belonging to mapped customers can be associated with the correct MSPortal company.
  </Step>
  <Step title="Complete setup">
    Return to the wizard and click **Complete Setup**. Completing setup does not mean every background sync or import has finished.
  </Step>
</Steps>

## Sync Schedule

| Sync Type | Schedule | Details |
|-----------|----------|---------|
| Customer Sync | Daily at 2:20 AM UTC | Refreshes the list of N-central customers |
| Device Sync | Daily at 3:35 AM UTC | Syncs devices from mapped customers, then auto-imports types with Auto-Sync on |
| Auto-Import Catch-Up | Daily at 2:55 AM UTC | Imports any auto-sync devices that were missed |

You can trigger a manual sync at any time with **Sync Now** on the device import page.

## Managing the Connection

<Steps>
  <Step title="Open the Connect step">
    Go to **Settings > Integrations**, click **Configure** on the N-central connection, and open **Connect**.
  </Step>
  <Step title="Enter the current or replacement values">
    Update the **Server URL** if needed, and enter the current or replacement token in **API Token (JWT)**.
  </Step>
  <Step title="Retest the connection">
    Click **Retest Connection** and wait for the success message.
  </Step>
  <Step title="Save changes">
    Click **Update API Key** to save the new server URL or token. Retesting alone does not save replacements.
  </Step>
</Steps>

Return to the import step at any time to review newly discovered devices or adjust device type mappings. The wizard's **Delete** button opens a **Delete N-able N-central Integration?** confirmation. Deleting removes the integration from MSPortal and does not revoke the token in N-central.

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection test fails | Confirm the server URL uses HTTPS and points to the root of your N-central server. Then generate a new JSON Web Token for the API user. |
| Authentication stops working | Confirm the API user is still active, MFA remains disabled for that API-only account, and its password has not expired. |
| Customers are missing | Allow the initial customer synchronization to finish, then click **Check for Customers** in the mapping step. Confirm the API user can see those customers in N-central. |
| A mapping disappeared | The link was still **Pending**. Re-select the company and click **Import Selected**. |
| Devices cannot be imported | Map the device's N-central customer to an MSPortal company first, and save the mapping. |
