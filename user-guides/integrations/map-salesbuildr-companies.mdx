Use the **Map** step in Salesbuildr setup to link each imported Salesbuildr company to the right MSPortal company. Salesbuildr quotes are imported only for mapped companies. Mapping is separate from each company user's permission to see those quotes.

## Before you start

- You are MSP staff with integration-company mapping access. Company users ask their MSP to fix a link or quote permission.
- Salesbuildr is connected. See [Connect and manage Salesbuildr](/user-guides/integrations/enable-salesbuildr-integration).
- To create a new portal company from this page you also need company-write access and active billing.

## Map a company

<Steps>
  <Step title="Open the Map step">
    Go to **Settings > Integrations**, manage the **Salesbuildr** connection and select **Map**.
  </Step>
  <Step title="Find the source company">
    Wait for the table. Use the **Name** and **Mapped** filters. The **Type** column helps identify the Salesbuildr record. If the company is missing, select **Sync**, wait for it to finish and check for connection errors.
  </Step>
  <Step title="Choose the portal company">
    In the row's company selector, pick the existing MSPortal company. The row shows **Pending**.
  </Step>
  <Step title="Save">
    Clear unrelated row checkboxes, then select **Import Selected**. Check that the row shows **Saved**.
  </Step>
  <Step title="Continue and check quotes">
    Select **Next** and let the quote sync finish. Then open a known quote under the company to confirm it arrived.
  </Step>
</Steps>

The **Mapped** count includes pending choices, so rely on the row's **Saved** status and on what you see when you reopen the step.

## Assign several companies to one portal company

<Steps>
  <Step title="Select the rows">
    Check only the Salesbuildr companies you want.
  </Step>
  <Step title="Choose the company and assign">
    Pick an existing company in the bulk selector and select **Assign**. The rows show **Pending** and the selection clears.
  </Step>
  <Step title="Save">
    Review each target, select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

Several source companies can share one portal company. Confirm their quotes should appear under it first.

## Use Quick Match

<Steps>
  <Step title="Open Quick Match">
    Select **Quick Match**.
  </Step>
  <Step title="Review the pairs">
    Check each Salesbuildr company and portal company pair. A name score is not proof of the same organization. A narrowed search can hide suggestions that are still selected, so review the full selection.
  </Step>
  <Step title="Apply and save">
    Apply the pairs you want, select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

Quick Match does not import quotes.

## Create a portal company

<Steps>
  <Step title="Open Create Company">
    Use the add-company control on the row.
  </Step>
  <Step title="Create it">
    Confirm the name and submit. The company is created right away and its mapping stays **Pending**.
  </Step>
  <Step title="Save the mapping">
    Select **Import Selected** and check for **Saved**.
  </Step>
</Steps>

<Warning>
**Import Selected** both saves pending mappings and creates companies for selected unmapped rows. To reuse existing companies, choose them first and clear unrelated selections.
</Warning>

## Remove or correct a mapping

<Steps>
  <Step title="Click the x on the row">
    On a **Pending** row, the **x** clears the unsaved choice. On a **Saved** row, it removes the link right away, with no confirmation.
  </Step>
  <Step title="Choose the correct company">
    Pick the right existing company in the row selector.
  </Step>
  <Step title="Save and resync quotes">
    Select **Import Selected**, then request a quote sync and check that the quotes appear under the right company.
  </Step>
</Steps>

<Warning>
Unlinking a Salesbuildr company deletes its imported quotes and line items from MSPortal. QuoteWerks behaves differently and keeps its quotes unassigned. The original quotes in Salesbuildr and the portal company are not deleted. Saving a new link does not bring the deleted rows back, so run a quote sync after you relink.
</Warning>

If a batch shows an error, some changes may already be saved. Reopen the table, check which rows show **Saved** and retry only the rest.

## Leave the step

**Next** and the step headings try to save pending Map work and request a quote sync. **Complete Setup** also requests a quote sync. Check for errors and confirm the rows show **Saved**. The footer **Back** does not save pending work, so select **Import Selected** before you use it. Connect form changes are separate. Select **Save settings** or **Update credentials** before you leave Connect.

A paused integration keeps its saved mappings but refuses to sync. Ask an MSP administrator to restore the connection, then request the quote import again.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| A company is missing from the table | Select **Sync**, wait, and check for connection errors. |
| Mapped but no quotes appear | Request a quote sync and check the integration is not paused. |
| Quotes vanished after an unlink | Relink the company, save, then run a quote sync. |
| Unwanted companies were created | **Import Selected** created them for selected unmapped rows. Clear unrelated selections next time. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does choosing a portal company save it?">
    No. The row shows **Pending** until you select **Import Selected** and it shows **Saved**.
  </Accordion>
  <Accordion title="Does bulk Assign save mappings?">
    No. It stages pending choices. Save with **Import Selected**.
  </Accordion>
  <Accordion title="Can Import Selected create companies?">
    Yes, for selected unmapped rows. Pick existing companies first if you only want to link.
  </Accordion>
  <Accordion title="What does the x on a Saved link do?">
    It removes the link and the company's imported quotes and line items right away. The original Salesbuildr quotes and the portal company stay.
  </Accordion>
  <Accordion title="Will relinking restore deleted quotes?">
    Relinking makes the company eligible for import again. Run a quote sync and check that the quotes reappear.
  </Accordion>
  <Accordion title="Does Back save pending mappings?">
    No. Use **Import Selected** before **Back**.
  </Accordion>
  <Accordion title="Why did only part of my batch save?">
    A batch can fail after earlier rows saved. Reopen **Map** and check which rows show **Saved**.
  </Accordion>
</AccordionGroup>
