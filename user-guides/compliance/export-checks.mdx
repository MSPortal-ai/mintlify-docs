Use this page to download the compliance items in the Compliance List as a CSV. It is for company users and MSP staff who can read the list. Your role and company scope decide which records you can export.

## Before you start

- You need Compliance read access.
- The export covers every item that matches the List's current filters, company selection, run filter and sort. It is not limited to the page you are looking at.

## Export to CSV

<Steps>
  <Step title="Open the List">
    Open **Compliance** and click **List** in the page header.
  </Step>
  <Step title="Set the scope">
    Check the company selector and choose **Active**, **Completed**, or **All** runs.
  </Step>
  <Step title="Filter and sort">
    Set the column filters and the status filter, and click a column heading to sort. The CSV uses the same filters and order. The page size and the page you are on do not matter.
  </Step>
  <Step title="Click Export">
    Click **Export** in the page header. On a phone, open the header **Actions** menu and click **Export**. A message reads "Preparing an export of every matching compliance item…" while MSPortal gathers the rows.
  </Step>
  <Step title="Wait for the download">
    When the file is ready, a message reads "Compliance items exported:" followed by the number of rows. The file downloads as `compliance-list-` followed by the date.
  </Step>
  <Step title="Check the file">
    Open the CSV and check the rows and fields before you share it.
  </Step>
</Steps>

Checking a row's box does not limit the export.

## What the CSV includes

The columns are always the same, in this order:

| Column | What it holds |
| --- | --- |
| **Title** | The compliance item's name. |
| **Status** | The status name, such as **New** or **Not Compliant**. |
| **Result** | What the status means: **Compliant**, **Non-Compliant**, **In Progress** or **Excluded**. |
| **Score** | The credit the status earns toward the compliance score, such as 100%, 0%, or 50% for a custom partial status. Blank when the status is excluded from scoring. |
| **Priority** | The item's priority. |
| **Category** | The item's category. |
| **Due Date** | The due date, when one is set. |
| **Company**, **Run**, **Group**, **Device**, **Location** | Where the item belongs. |
| **Flagged** | **Yes** or **No**. |
| **Public Notes**, **Private Notes** | Notes on the item, as plain text. |
| **Why Important**, **Remediation**, **Remediation Impact** | The item's guidance, as plain text. |
| **Last Updated** | When the item last changed. |

Hiding a column in the table does not remove it from the CSV. Company users never receive private notes. MSP staff exports can include private notes, so check the file before you share it with company users.

The CSV does not include uploaded files or custom fields. Open the item to see those. See [Read compliance guidance, evidence, and history](/user-guides/compliance/read-evidence-and-history).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Export** is not in the header | Open the **List** view. The button does not appear in **Tree** or **Risks**. On a phone, open the header **Actions** menu. |
| The CSV has fewer rows than I expect | Check the company selector, the **Active**, **Completed**, or **All** choice, and the column filters. The export follows all of them. |
| The CSV is empty | Clear the filters and export again. |
| "The compliance export failed. Try again." appears | Click **Export** again. If it keeps failing, narrow the filters or the company selection, then tell your MSP. |
| The List fails to load | Click **Retry** or reload. If it keeps failing, tell your MSP. |
| I need a report for a client | Use the Reports module. The **Compliance Report** block can print every item across several pages. See [Print every item in a Compliance Report block](/user-guides/reporting/index#print-every-item-in-a-compliance-report-block). |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Export download every matching item?">
    Yes. It downloads every item that matches the current filters, company selection, run filter and sort, across all pages of the List.
  </Accordion>
  <Accordion title="Can I export only the rows I checked?">
    No. Checkboxes are for bulk actions. Use filters to narrow the export.
  </Accordion>
  <Accordion title="Why is the Score column blank for some rows?">
    Those rows have a status that is excluded from scoring, so they earn no credit and the Result column reads **Excluded**.
  </Accordion>
  <Accordion title="Does hiding Private Notes remove it from the CSV?">
    No. The CSV always has the same columns. Company users' exports never contain private notes. Check MSP staff exports before you share them.
  </Accordion>
  <Accordion title="Does the CSV include evidence files?">
    No. Download files from the item's **Uploads** tab.
  </Accordion>
  <Accordion title="Why are note and guidance formatting and images missing?">
    Notes and guidance are exported as plain text.
  </Accordion>
</AccordionGroup>
