Use this page to download the checks you see in the Compliance List as a CSV. It is for company users and MSP staff who can read the list. Your role and company scope decide which records you can export.

## Before you start

- You need Compliance read access.
- The export covers only the rows loaded on the current page of the List. To export more records, change pages and export again.

## Export to CSV

<Steps>
  <Step title="Open the List">
    Open **Compliance** and click **List** in the page header.
  </Step>
  <Step title="Set the scope">
    Check the company selector and choose **Active**, **Completed**, or **All** runs.
  </Step>
  <Step title="Filter and page">
    Set the column filters. Choose a page size of 25, 50, 100, or 250 rows, and go to the page you want to export.
  </Step>
  <Step title="Click Export">
    Click **Export** in the page header. The file downloads as `compliance-list-` followed by the date.
  </Step>
  <Step title="Check the file">
    Open the CSV and check the rows and fields before you share it.
  </Step>
</Steps>

Checking a row's box does not limit the export.

## What the CSV includes

The columns are always the same:

- Title, Status, Priority, and Due Date.
- Company, Run, Group, Device, and Location.
- Flagged, Public Notes, Private Notes, and Last Updated.

Hiding a column in the table does not remove it from the CSV. Notes become plain text. MSP exports can include internal notes, so check the file before you share it with company users.

The CSV does not include guidance text, uploaded files, or custom fields. Open the check to read those. See [Read compliance guidance, evidence, and history](/user-guides/compliance/read-evidence-and-history).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Export** is not in the header | Open the **List** view. The button does not appear in **Tree** or **Risks**. |
| The CSV has fewer rows than I expect | It holds only the current page. Raise the page size or export each page. |
| The CSV is empty | Wait for the List to finish loading, then clear the filters. |
| The List fails to load | Click **Retry** or reload. If it keeps failing, tell your MSP. |
| I need a report for a client | Use the Reports module. A CSV is a data extract. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does Export download every matching check?">
    No. It exports the rows on the current List page.
  </Accordion>
  <Accordion title="Can I export only the rows I checked?">
    No. Checkboxes are for bulk actions. Use filters to narrow the export.
  </Accordion>
  <Accordion title="Does hiding Private Notes remove it from the CSV?">
    No. The CSV always has the same columns. Check the file before you share it.
  </Accordion>
  <Accordion title="Does the CSV include evidence files?">
    No. Download files from the check's **Uploads** tab.
  </Accordion>
  <Accordion title="Why are note formatting and images missing?">
    Notes are exported as plain text.
  </Accordion>
</AccordionGroup>
