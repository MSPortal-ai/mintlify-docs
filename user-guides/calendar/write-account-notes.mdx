Use this page to add, edit and delete account notes and QBR log entries for a company. It is for MSP staff. Company users cannot see or write account notes.

## Before you start

- You need Write access to Calendar, Meetings or Companies settings for the company. Deleting needs Manage access.
- To copy a note to Autotask, the company must be linked to an active Autotask integration and its note types must have synced.

## Create an account note

<Steps>
  <Step title="Open the company's Notes tab">
    Go to **Settings > Companies**, open the company and select **Notes**.
  </Step>
  <Step title="Click Add note">
    The **New account note** dialog opens. Under **Kind**, leave **Account note** selected.
  </Step>
  <Step title="Enter the title and date">
    Type a **Title** (required, up to 250 characters). **Date** starts as today. Change it to back-date the note.
  </Step>
  <Step title="Write the note">
    Type the text in **Note**. The editor supports rich text.
  </Step>
  <Step title="Click Save">
    A **Note saved** message appears and the note moves to the list. **Cancel** closes the dialog and drops the draft.
  </Step>
</Steps>

<Note>
If the dialog clears while you type, wait a moment and enter the text again. The dialog resets once when the Autotask settings finish loading.

## Record a QBR entry by hand

<Steps>
  <Step title="Open the dialog">
    In the company **Notes** tab, click **Add note** and set **Kind** to **QBR log**. On a meeting's **QBR Log** tab, click **Add entry** instead. That entry links to the meeting and starts with the meeting's title and date.
  </Step>
  <Step title="Fill in Title and Date">
    Use a recognizable title, such as the quarter being reviewed.
  </Step>
  <Step title="Write Discussed">
    Describe the topics covered in the review.
  </Step>
  <Step title="Add decisions">
    Under **Agreed**, click **Add decision** and type one decision per row. Click the trash icon to remove a row.
  </Step>
  <Step title="Add commitments">
    Under **Actioned**, click **Add commitment**. Enter what will be done, an optional **Owner** and an optional **Due date**. Tick **Done** if it is already finished.
  </Step>
  <Step title="Click Save">
    Empty decision rows and commitments without a description are dropped. The dialog accepts up to 50 decisions and 50 commitments.
  </Step>
</Steps>

**Owner** is plain text. It does not assign a user, send a notification or create a meeting action item. Add action items on the meeting itself.

A meeting can have one QBR entry. If one exists, the **Add entry** button is hidden. Edit the existing entry instead. A QBR entry added from company settings is not linked to a meeting.

## Edit a note or commitment

<Steps>
  <Step title="Click Edit">
    Find the note and click **Edit**. Only notes written in MSPortal have this button. The **Kind** cannot change once a note exists.
  </Step>
  <Step title="Change the fields">
    Update the title, date, note text, or the QBR fields.
  </Step>
  <Step title="Click Save">
    **Cancel** discards your changes.
  </Step>
</Steps>

To tick a commitment without opening the dialog, tick **Done** on the saved card. That change saves immediately. Inside the edit dialog, the tick is saved with the dialog's **Save**.

Any saved edit, including a **Done** tick, protects a QBR entry from automatic regeneration after later summaries. Edits do not update meeting action items or the Autotask copy.

## Copy a note to Autotask

<Steps>
  <Step title="Open the note dialog">
    Create a note or click **Edit** on an existing one. The Autotask section appears when your account has an active Autotask integration.
  </Step>
  <Step title="Choose an Autotask note type">
    Pick a type from **Autotask note type**. The list is disabled when the company is not linked to Autotask or Autotask has no note types yet. Choosing a type alone does not send the note.
  </Step>
  <Step title="Turn on the push option">
    Tick **Push to Autotask when saved**. On a note that was already pushed, the option reads **Update the Autotask copy when saved**. The box starts unticked each time the dialog opens.
  </Step>
  <Step title="Click Save">
    A **Note synced to Autotask** message confirms the push. MSPortal files the note in Autotask as a Company Note of that type.
  </Step>
</Steps>

What Autotask receives:

- The body is sent as plain text, cut at 32,000 characters. Formatting is dropped.
- A QBR entry is sent as text with the Discussed, Agreed and Actioned parts.
- An update sends the title, body and note type. It does not change the note's date in Autotask.
- The note is filed under your Autotask resource, or the integration's fallback resource.

### Retry a failed push

If the push fails, the note still saves in MSPortal. It shows an **Autotask sync failed** badge, and hovering the badge shows the error. Fix the cause, such as a missing note type or an unlinked company. Then click **Sync to Autotask** on the note.

Notes imported from Autotask are marked **From Autotask** and are read-only here.

## Delete a note

<Steps>
  <Step title="Click Delete">
    Click **Delete** on the note.
  </Step>
  <Step title="Confirm">
    The **Delete this note?** dialog names the note. Click **Delete** to remove it or **Cancel** to keep it.
  </Step>
</Steps>

There is no undo. Deleting does not remove a copy already pushed to Autotask or any meeting action items. A pushed note can reappear in the list as a **From Autotask** note after you delete the MSPortal copy.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Enter a title** appears | Fill in **Title**. It is required. |
| A message says you do not have permission to edit account notes | You need Write access to Calendar, Meetings or Companies settings for that company. Ask an administrator. |
| **This meeting already has a QBR log entry** | Edit the existing entry from the meeting's **QBR Log** tab. |
| **Note not found or no permission to delete it** | You need Manage access to delete. Ask an administrator. |
| The Autotask section is missing | Connect Autotask and link the company. See [Autotask integration](/user-guides/integrations/enable-autotask-integration). |
| The sync reports no Autotask resource for this user | Link your user to an Autotask resource, or ask an administrator to set a fallback resource in the Autotask integration settings. Then click **Sync to Autotask**. |
| The note type list is empty | The integration has not synced its note types yet. Types refresh with the daily sync. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Do I need Autotask to save an internal note?">
    No. Account notes and manual QBR entries stay in MSPortal unless you push them.
  </Accordion>
  <Accordion title="Does adding a commitment row save it?">
    No. Rows are part of the draft until you click **Save**. Only the **Done** tick on an already saved card saves on its own.
  </Accordion>
  <Accordion title="Is my draft kept if I click Cancel?">
    No. **Cancel** closes the dialog and discards the draft.
  </Accordion>
  <Accordion title="Can I change an Account note into a QBR log?">
    No. **Kind** is fixed once the note exists. Create a new entry of the other kind.
  </Accordion>
  <Accordion title="Will later edits update the Autotask copy automatically?">
    No. Tick **Update the Autotask copy when saved** on each save that should update it.
  </Accordion>
  <Accordion title="Does Delete remove the Autotask copy?">
    No. It removes the MSPortal note only.
  </Accordion>
</AccordionGroup>
