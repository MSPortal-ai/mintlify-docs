Use this page to set up the wrap-up your staff see after a meeting: the survey, the transcript and the summary email. It is for MSP administrators. The settings apply to your whole MSP, not to one company or person. Company users do not use the wrap-up. They can [read a meeting summary](/user-guides/calendar/understand-meeting-summary).

## Before you start

- You need Calendar settings access and permission to manage Calendar settings.
- The **Post-meeting survey questions** card on the same tab saves separately. See [Manage survey questions](/user-guides/calendar/manage-meeting-survey-questions).

## Choose when wrap-up is available

<Steps>
  <Step title="Open Settings > Operations > Calendar">
    Select the **Post-Meeting** tab. The **Post-Meeting Flow** card is on the left.
  </Step>
  <Step title="Turn on Enable post-meeting flow">
    <Frame caption="The main wrap-up switch. Save changes in the page header.">
      <img src="/images/product/post-meeting-flow-control.png" alt="Enable post-meeting flow switch shown on, with its survey, transcript and summary description" width="772" height="196" />
    </Frame>
    This shows the survey, transcript and summary workflow for completed meetings.
  </Step>
  <Step title="Pick the event types">
    Open **Event Types** and tick the types that offer wrap-up. The choices are **QBR**, **On-site Tech Visit**, **Internal Meeting**, **Client Call**, **Project Milestone**, **Compliance Review**, **Business Review**, **Service Call** and **Other**. Keep at least one. To turn wrap-up off, switch off **Enable post-meeting flow** instead.
  </Step>
  <Step title="Choose the completion prompt">
    **Prompt when a meeting is completed** asks staff to start the wrap-up when they mark a meeting **Completed**. Turning it off removes the prompt only. Staff can still click **Wrap-Up**.
  </Step>
  <Step title="Click Save">
    The **Save** button is in the page header. It is disabled until you change something. **Post-meeting settings saved** confirms it.
  </Step>
</Steps>

Switching tabs does not save your changes. Save first, or reload the page to discard them.

## What each control does

| Control | What it does |
| --- | --- |
| **Enable post-meeting flow** | Turns the wrap-up on or off. |
| **Event Types** | Chooses which meeting types offer wrap-up. It does not decide QBR logging. |
| **Prompt when a meeting is completed** | Shows the wrap-up prompt on completion. |
| **AI transcript processing** | Lets staff generate notes and action items from a saved transcript. |
| **Update the QBR log automatically** | Writes a QBR entry after a summary is sent. |
| **Push QBR log entries to Autotask as** | Sets the Autotask note type for automatic QBR entries. Shown only with an Autotask integration. |

Each switch is separate. Turning off the main flow does not turn off **Update the QBR log automatically**.

## Set transcript AI

Turn **AI transcript processing** on or off and click **Save**. With it off, staff can still save a transcript. It only removes **Generate notes & action items**. It does not turn off other AI features. See [Add a meeting transcript](/user-guides/calendar/add-meeting-transcript).

## Set automatic QBR logging

<Steps>
  <Step title="Set Update the QBR log automatically">
    Turn it on to write a QBR entry after each eligible summary. It is on by default.
  </Step>
  <Step title="Choose the Autotask note type (optional)">
    With Autotask connected, set **Push QBR log entries to Autotask as** to a note type. Choose **Do not push to Autotask** to keep entries in MSPortal. The list is disabled while automatic logging is off.
  </Step>
  <Step title="Click Save">
    Use the page-header button.
  </Step>
  <Step title="Check a result">
    After a summary is sent, open the company's [Account Notes and QBR Log](/user-guides/calendar/read-account-notes).
  </Step>
</Steps>

Automatic QBR logging skips **Internal Meeting**, **On-site Tech Visit** and **Service Call** meetings, meetings with no company, and entries edited by hand. Ticking every wrap-up event type does not change this. Saving a note type does not push anything by itself.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Save** fails | Viewing settings and managing them are separate permissions. Ask an administrator to check your role. |
| Staff see no **Wrap-Up** button | Check the flow switch, the meeting's event type and your Calendar access. |
| No completion prompt | Check **Prompt when a meeting is completed**, and whether staff chose **Don't ask for this meeting**. |
| No QBR entry appeared | Check the meeting type, that the meeting has a company, and whether the entry was edited by hand. A sent email does not prove the QBR was written. Do not resend the email to fix it. |
| No Autotask note type list | It shows only when an Autotask integration and its note types are available. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can company administrators change these settings?">
    No. This is an MSP administration task.
  </Accordion>
  <Accordion title="Can I turn off wrap-up by clearing every event type?">
    No. Keep at least one. Switch off **Enable post-meeting flow** instead.
  </Accordion>
  <Accordion title="Does turning off the prompt turn off wrap-up?">
    No. It only removes the prompt.
  </Accordion>
  <Accordion title="Does turning off the main flow stop QBR logging?">
    No. Turn off **Update the QBR log automatically** as well and save.
  </Accordion>
  <Accordion title="Can staff save a transcript when transcript AI is off?">
    Yes. Only AI generation is off.
  </Accordion>
  <Accordion title="How do I stop automatic QBR entries going to Autotask?">
    Choose **Do not push to Autotask** and save.
  </Accordion>
</AccordionGroup>
