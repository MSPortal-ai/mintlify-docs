A playbook is a ready-made set of compliance checks. This guide shows MSP staff how to go from choosing a playbook to running an assessment. Company users see the finished assessments their IT provider shares. They do not import playbooks.

## Before you start

- You need `read_settings_playbooks` to browse and `manage_settings_playbooks` plus an active billing account to import.
- Your tenant needs at least one status list. The import asks you to choose one.
- Importing copies checks into your tenant. It does not change any endpoint, start an assessment or assign checks to a company.

## From playbook to assessment

<Steps>
  <Step title="Open the Playbooks library">
    Go to **Settings > Compliance > Playbooks**. Click **Best Practices** for broad operational and technology reviews, or **Security Frameworks** for **CIS Benchmarks**, **CAN/DGSI 104** and **NIS2**. Or type in **Search all playbooks...**.

    <Frame caption="The Playbooks home page with the Best Practices and Security Frameworks cards.">
      <img src="/images/product/playbooks-library-paths.png" alt="The Playbooks home page with the Best Practices and Security Frameworks cards" width="1856" height="506" />
    </Frame>
  </Step>
  <Step title="Read the checks">
    Click the playbook's name to open its details. The window is read-only. Click **Cancel** to close it. Check the card's version and check count.
  </Step>
  <Step title="Import the playbook">
    Click **Add** on the card. In **Add Playbooks to Tenant**, check the folder, choose a **Status list**, review the **Device types** if shown, then click **Add to Tenant**. A card marked **Imported** was imported before, and importing again makes a second copy. See [Playbook settings](/user-guides/settings/playbooks) for every dialog option.
  </Step>
  <Step title="Tune the imported checks">
    Open **Settings > Compliance > Checks** and find the folder named in the import message. Edit the guidance and which companies and devices each check applies to. See [Compliance settings](/user-guides/settings/compliance).
  </Step>
  <Step title="Put the group in a run template">
    Open **Settings > Compliance > Runs**. Create a template, or open one, then add the imported group on its **Groups** tab.
  </Step>
  <Step title="Run the assessment">
    Run the template against the companies you choose, collect evidence and review the results in [Compliance](/user-guides/compliance/index).
  </Step>
</Steps>

A playbook standardizes the questions you ask every client. It does not supply evidence or certify a client. Check the product version and the client's scope before you assign a benchmark.

## Keep imported content current

Importing a newer catalog version does not update your earlier copies. Note which version you imported and review what changed before you import again. The **Imported** badge only shows that a playbook was imported once. If you are unsure what an earlier import did, check **Settings > Compliance > Groups** before you import again.

For CIS product families and L1 or L2 profiles, see [Adding CIS Benchmarks](/user-guides/compliance/adding-cis-benchmarks). CIS benchmark profiles are different from CIS Controls Implementation Groups. For clients under the EU NIS2 directive, see [Adding NIS2 playbooks](/user-guides/compliance/adding-nis2-playbooks).

## Troubleshooting

| Problem | What to do |
| --- | --- |
| **Add** is disabled | Ask an administrator for `manage_settings_playbooks` and check that billing is active. |
| The Playbooks tab is missing | Ask an administrator for `read_settings_playbooks`. |
| The imported group exists but a company has no assessment | Add the group to a run template and run it against that company. |
| You cannot find the imported checks | Look in the folder the import message named, under **Settings > Compliance > Checks**. |

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Is a playbook a finished assessment?">
    No. It is check content. You still run the assessment and record evidence.
  </Accordion>
  <Accordion title="Can company users import playbooks?">
    No. Importing is an MSP settings task.
  </Accordion>
  <Accordion title="Does importing change endpoint settings?">
    No. It adds checks and a group to your tenant. Fixing a client's configuration is separate work.
  </Accordion>
  <Accordion title="Are all frameworks and the latest benchmarks always available?">
    Use the catalog your account shows, with its names, versions and check counts.
  </Accordion>
  <Accordion title="Does an imported group give every company a review?">
    No. Add it to a run template and run it for the companies you choose.
  </Accordion>
</AccordionGroup>
